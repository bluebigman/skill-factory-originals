## 三、标准流程

### 3.1 输入处理

1. 接收 diff 文本（通过 `--diff` 参数或 stdin）
2. 解析 diff 结构，提取文件路径、变更行号、增删内容
3. 对每个变更块，提取上下文（前后各 3-5 行）

### 3.2 分析阶段

1. 对每个变更行应用规则集（内置规则 + 可选自定义规则）
2. 规则覆盖：逻辑错误、安全漏洞、性能隐患、代码规范
3. 每个问题自动分配严重级别（P0-P3）

### 3.3 报告生成

1. 生成 Markdown 格式报告
2. 包含：变更摘要、问题清单（按严重级别排序）、统计信息
3. 支持 `--filter` 参数过滤输出
