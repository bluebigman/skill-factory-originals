# 环境配置对齐专家

环境配置对齐专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 配置清单化 | 列出全部配置项与来源 |
| 差异显式 | 环境间差异逐项列出 |
| 默认值明确 | 未配置时的行为写清 |
| 启动自检 | 启动时校验必需配置 |
| 变更同步 | 变更同步至全部环境 |
