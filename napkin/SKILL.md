# napkin — 项目记忆与错误备忘技能

## 一、能力边界（一页纸速查卡）

### 1.1 能做什么

| 能力项 | 说明 | 示例 |
|--------|------|------|
| 错误记录 | 将项目运行中遇到的错误、异常、故障及其解决方案持久化存储 | 记录"数据库连接池耗尽"的报错信息与修复方法 |
| 经验备忘 | 沉淀开发过程中的经验教训、踩坑记录、最佳实践 | 记录"部署时需先备份配置文件"的经验 |
| 项目记忆检索 | 按关键词、时间、标签快速检索历史记录 | 查找"权限"相关的所有历史错误记录 |
| 记录更新与维护 | 对已有记录进行补充、修正、标记过期 | 更新某条错误记录的解决方案版本 |
| 导出与分享 | 将记录导出为 Markdown 或文本格式，便于团队共享 | 导出本周所有错误记录为报告 |

### 1.2 不能做什么

| 限制项 | 说明 |
|--------|------|
| 不自动捕获错误 | 需要用户主动调用或提供错误信息，不监听系统日志 |
| 不执行代码修复 | 仅记录和检索，不直接修改项目代码 |
| 不跨项目共享 | 记录存储在当前项目仓库内，不自动同步到其他项目 |
| 不替代文档系统 | 面向错误与经验，不承担完整项目文档职责 |
| 不提供实时告警 | 无主动推送或通知能力 |

### 1.3 适用对象

- 个人开发者：记录个人项目中的踩坑经历
- 小型团队：共享团队项目中的常见错误与解决方案
- 开源项目维护者：记录项目已知问题与处理方式
