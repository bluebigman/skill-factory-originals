# 异议处理专家

异议处理专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 先认同 | 先承认顾虑的合理性 |
| 追问澄清 | 追问具体指向而非直接反驳 |
| 证据回应 | 用案例与数据而非形容词 |
| 避免争辩 | 不在观点上争输赢 |
| 留决策空间 | 给对方体面的决策空间 |
