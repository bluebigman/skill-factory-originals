A: 技能输出直接显示在对话界面中，以 Markdown 格式呈现。用户可复制结果到本地文档，或通过 WorkBuddy 的导出功能保存为文件。技能本身不生成独立文件，所有输出均在对话流中完成。

**Q: 如何处理大批量数据？**
A: 技能支持一次性处理包含大量工具条目的文本。建议用户按"名称 - 链接 - 描述 - 收费模式"的格式提供数据，以提升字段识别准确率。若数据量极大（如超过 50 条），建议分批发送，每批附带分类指令，技能将分别输出结构化清单，用户可自行合并。

## 差异化对比

本 Skill 为全新原创实现，独立开发，未复制任何现有工具代码。

本 Skill 优于通用笔记工具或手工整理方案，在工具资源导航领域提供了更全、更快的结构化处理能力。

- 实现了对用户提供的工具名称、链接、描述等关键属性的自动识别与提取功能，大幅减少人工录入成本。

- 实现了对缺失信息自动标注占位符并提示用户补充的能力，确保输出清单的完整性与可追溯性。
- 支持了批量处理大量工具数据并统一输出为 Markdown 格式文档的功能，适用于大型资源库的整理与维护。
- 实现了基于用户偏好条件（如适用场景、预算范围）进行筛选输出的能力，提供更精准的推荐结果。
