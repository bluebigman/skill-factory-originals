# 文档合规边界专家

文档合规边界专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 不越界 | 不替代法律意见，涉法事项提示咨询专业人士 |
| 隐私脱敏 | 对外文档剥离个人信息 |
| 引用合规 | 引用他人内容注明出处与授权 |
| 免责声明 | 方法与建议类文档附免责声明 |
| 留痕可溯 | 重要文档保留修改记录 |
