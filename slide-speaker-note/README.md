# 演讲备注撰写专家

演讲备注撰写专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 一页一句 | 每页备注有核心句 |
| 提示而非全文 | 只写关键词与转场句 |
| 时间标记 | 标注该页预计用时 |
| 救场预案 | 准备被追问的回答要点 |
| 衔接明确 | 备注含与下页的过渡句 |
