# illo-skill 技能文档

## 一、能力边界速查卡

本技能面向「需要将文字内容转化为编辑风格插画方案」的使用场景，适用于公众号编辑、杂志美编、内容策划、独立创作者等角色。

### 1.1 能做与不能做

| 维度 | 能做 | 不能做 |
|------|------|--------|
| 输入处理 | 接受文章正文、创意关键词、URL链接、PDF/Word提取文本 | 不接受纯图片文件（无文字说明的JPG/PNG） |
| 输出内容 | 插画概念方案、构图建议、色彩搭配、风格参考、元素清单 | 不生成实际位图图像（不产出PNG/JPG成品图） |
| 信息处理 | 提取核心主题、情绪基调、关键意象、叙事结构 | 不进行事实核查、不补充外部知识 |
| 格式交付 | 结构化Markdown方案文档、可导入设计工具的提示词包 | 不输出PSD/AI源文件 |
| 批量操作 | 支持一次提交多篇文章（≤5篇）分别产出方案 | 不支持合并多篇文章为一个方案 |

### 1.2 适用对象

- **适用**：已有文字稿件，需要视觉方向参考的编辑团队；需要快速验证插画概念的独立作者；教学场景中的视觉叙事练习。
- **不适用**：需要最终成稿的商业插画委托；对图像质量有像素级要求的印刷输出；需要版权授权的既有插画风格模仿。

## 三、标准工作流程

### 3.1 前置条件

- 输入内容不少于50字（少于50字时输出 `[需核实:输入长度]` 并请求补充）
- 明确告知输出格式偏好（默认Markdown表格+段落混排）
- 如有风格偏好（如极简、复古、赛博朋克），请提前说明

### 3.2 执行步骤

**步骤1：内容解析**

- 读取输入文本，识别以下要素：
  - 核心主题（1-3个关键词）
  - 情绪基调（如：温暖/冷峻/幽默/沉重）
  - 关键意象（名词性元素，如"雨""玻璃""旧信件"）
  - 叙事结构（线性/对比/递进/循环）

**步骤2：视觉转译**

- 将抽象概念映射为视觉符号（示例）：
  - "时间流逝" → 沙漏、年轮、褪色照片
  - "社会压力" → 重叠的日历、拥挤的楼梯、压缩的弹簧
- 确定构图类型：居中/三分法/对角线/框架式
- 选择色彩策略：单色/互补/类似/分裂互补

**步骤3：方案生成**

- 输出包含以下模块的方案文档：
  1. 主题提炼（一句话概括画面核心）
  2. 构图描述（文字说明+ASCII示意）
  3. 色彩方案（色值+比例）
  4. 元素清单（主元素/辅助元素/背景元素）
  5. 风格参考（描述性文字，不指定具体艺术家）

**步骤4：置信度标注**

- 对每个判断给出置信度：
  - 高置信度（≥85%）：文本中有明确依据
  - 中置信度（60-84%）：有部分依据但需推断
  - 低置信度（<60%）：纯推测，标注 `[需核实:具体依据]`

**步骤5：输出与自查**

- 检查字段完整性：主题/构图/色彩/元素/风格五项齐全
- 检查格式正确性：表格对齐、列表层级清晰
- 检查置信度标注：所有推测性内容均有标注

### 3.3 输出规范

```markdown
## 插画方案：{主题}

### 主题提炼
{一句话描述画面核心}

### 构图描述

|------|------|------|

### 元素清单
- 主元素：{元素}（置信度：{高/中/低}）
- 辅助元素：{元素}（置信度：{高/中/低}）
- 背景元素：{元素}（置信度：{高/中/低}）

```
