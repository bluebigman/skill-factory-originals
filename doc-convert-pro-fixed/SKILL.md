## 六、FAQ 反模式对照

### 常见坑与正确做法

| 反模式（错误做法） | 问题 | 正确做法 |
|--------------------|------|----------|
| 直接覆盖原文件 | 处理失败后无法恢复 | 始终输出到独立目录，保留原件 |
| 不校验磁盘空间 | 处理中途磁盘满，文件损坏 | 前置检查，预估所需空间 |
| 忽略 EXIF 信息 | 隐私泄露风险 | 默认清理，除非明确要求保留 |
| 压缩质量设 100 | 文件几乎不缩小，浪费算力 | 合理范围 60-85，平衡质量与体积 |
| 处理中不记录日志 | 失败后无法定位问题 | 每文件记录日志，支持断点续跑 |
| 一次性加载全部文件 | 大目录内存溢出 | 流式处理，逐文件读取 |
