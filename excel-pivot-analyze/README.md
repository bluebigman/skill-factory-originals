# 透视分析构建专家

透视分析构建专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 源表规范 | 源表必须单行表头无合并单元格 |
| 维度度量分离 | 先分维度后放度量 |
| 口径标注 | 每个数值标注统计口径 |
| 异常先看 | 分析前先看最大值最小值是否合理 |
| 刷新机制 | 数据变动后手动刷新并记录时间 |
