# 视觉调优专家

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 字号下限 | 正文不小于十八号，小于即删内容 |
| 对比度 | 深浅对比至少四级，浅灰字必改 |
| 对齐网格 | 所有元素对齐同一网格 |
| 配色不超三 | 主色辅色点缀色各一 |
| 留白优先 | 每页留白不少于三成 |
