# 重试退避设计专家

重试退避设计专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 只重试可重试 | 区分瞬时故障与永久失败 |
| 指数退避 | 间隔逐次翻倍并加上限 |
| 抖动 | 加随机抖动避免同时重试 |
| 幂等前提 | 重试前确认操作幂等 |
| 重试上限 | 设次数与总时长双上限 |
