# 游戏经济专家

游戏经济专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 先定产出 | 先定产出速率再定消耗速率 |
| 通胀监控 | 监控货币总量与人均持有增速 |
| 分层验证 | 按新手/中层/顶层分别验证 |
| 沙盒试算 | 改动前先沙盒模拟跑长期曲线 |
| 灰度上线 | 先小比例灰度再全量 |
