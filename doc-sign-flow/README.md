# 文档签署流程专家

文档签署流程专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 先定流程 | 明确签署方与顺序 |
| 版本冻结 | 送签即冻结版本 |

| 留痕归档 | 签署记录与终稿一并归档 |
| 时限提醒 | 为各签署方设提醒时限 |
