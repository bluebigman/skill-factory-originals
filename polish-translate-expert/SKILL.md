## 三、标准流程

### 3.1 前置条件

| 条件项 | 要求 | 检查方式 |
|--------|------|----------|
| 原文存在 | 必须提供源语言文本 | 输入中是否包含原文标记 |
| 译文存在 | 必须提供目标语言文本 | 输入中是否包含译文标记 |
| 段落对应 | 原文与译文段落数一致（或按编号对应） | 自动比对段落数量 |
| 语言对明确 | 需指定源语言和目标语言 | 用户声明或从文本自动推断 |

### 3.2 执行步骤

**Step 1：输入解析（耗时约 1 秒）**

- 识别输入中的原文块与译文块
- 按段落/编号建立对应关系
- 若无法自动识别，返回错误码 `E1001` 并附正确输入格式示例

**Step 2：术语一致性扫描（耗时约 2 秒）**

- 提取原文中的关键术语（专有名词、技术词汇、品牌名）
- 对比译文中对应位置的翻译
- 标记不一致项，生成术语对照表

**Step 3：语感优化（耗时约 3 秒）**

- 逐段检查译文句式结构
- 识别以下问题并给出修改建议：
  - 欧化句式（如被动语态滥用、从句过长）
  - 连接词生硬（如"然而"使用频率过高）
  - 语气不当（如正式文档中出现口语化表达）
  - 冗余表达（如"进行"、"一个"等多余词汇）

**Step 4：格式规范化（耗时约 1 秒）**

- 标点符号：统一全角/半角
- 数字格式：统一千分位、小数点、百分号
- 日期格式：统一为 YYYY-MM-DD 或目标语言习惯格式
- 单位符号：统一为国际标准单位

**Step 5：生成输出（耗时约 1 秒）**

- 按约定格式生成润色后的译文
- 生成修改说明（每条修改附原因）
- 标注置信度（高/中/低）

译文润色 术语统一 语感优化——对译文进行术语统一、语感优化与格式调整，输出对照版本和修改说明。。输入任务，输出结果，全程可校验、可追溯，适合日常高频使用与批量处理场景。 支持参数化控制、自检验证、多编码容错与预览模式，工程化程度高，开箱即用。

## 安装（Setup）

```bash
# 1. 进入 Skill 目录
cd translation-polish

# 2. 运行自检确认环境
python run.py --selftest

# 3. 开始使用
python run.py 命令行参数(详见 --help)
```

## 使用（Usage）

```bash
python run.py <命令> [参数]    # 执行核心功能
python run.py --selftest      # 运行自检
python run.py 命令行参数(详见 --help)       # 预览模式
python run.py --verbose       # 详细输出
```

## 常见问题（FAQ）

**Q: 支持中文文件吗？**
A: 支持，内置 utf-8/gbk/gb18030 多编码容错。

**Q: 运行报错怎么办？**
A: 工具内置异常降级，错误会有明确提示；可先用 命令行参数(详见 --help) 预览。

**Q: 如何确认功能正常？**
A: 运行 --selftest，全部通过即核心功能正常。
