## 三、标准流程

### 3.1 前置条件

| 条件项 | 要求 | 检查方式 |

| 文件格式 | CSV / JSON / Excel（.xlsx, .xls） | 查看文件扩展名 |

| 目录结构 | 待处理文件需放在同一目录下，且该目录无其他无关文件 | 查看目录列表 |
| 备份要求 | 原始文件需保留副本，建议复制至 `backup/` 子目录 | 检查备份目录 |

### 3.2 执行步骤

#### 步骤一：准备输入（耗时约 1 分钟）

1. 创建工作目录，例如 `marketing_platform_review/`
2. 将所有待处理文件复制到该目录
3. 确认文件命名符合规范（含日期或批次标识）
4. 执行备份：`mkdir backup && cp *.csv backup/`

#### 步骤二：试运行（耗时约 2 分钟）

1. 选取单个样本文件执行转换命令
2. 核对输出字段是否完整（应包含：文件标识、条款编号、条款内容、风险标记）
3. 检查字段格式是否符合预期（日期格式、编号规则等）
4. 如有偏差，调整参数后重新执行

#### 步骤三：批量执行（耗时视文件量而定）

1. 确认试运行无误后，对全量文件执行批量处理
2. 输出结果按原文件名生成对应结构化文件，存放于 `output/` 目录
3. 处理完成后生成汇总报告 `summary_report.md`

#### 步骤四：校验结果（耗时约 3 分钟）

1. 随机抽取 3-5 条输出条目
2. 与源文件对应内容进行比对，核对关键字段一致性
3. 确认风险标记的准确性（抽查标记条目）
4. 如有异常，记录并修正后重新输出
