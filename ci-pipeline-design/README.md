# 持续集成流程专家

持续集成流程专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 快速反馈 | 单元测试前置并控制在十分钟内 |
| 阶段分明 | 构建-测试-扫描-制品分阶段 |
| 失败即停 | 任阶段失败不进入下一阶段 |
| 缓存复用 | 依赖与构建产物做缓存 |
| 产物可溯 | 制品带提交号与构建时间 |
