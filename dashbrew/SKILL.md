## 四、置信度门控机制

### 4.1 置信度等级定义

| 等级 | 置信度范围 | 含义 | 处理方式 |
|------|------------|------|----------|
| 高 | 0.90 - 1.00 | 字段提取明确，无歧义 | 直接输出 |
| 中 | 0.70 - 0.89 | 字段存在但格式略有差异 | 输出并提示 |
| 低 | 0.50 - 0.69 | 字段模糊或存在多种可能 | 输出并标记 [需核实] |
| 不可用 | < 0.50 | 无法确定字段值 | 输出 [需核实:字段名] 占位 |

### 4.2 占位符规则

- 格式：`[需核实:字段名]`
- 示例：`[需核实:日期]`、`[需核实:金额]`
- 规则：占位符不参与后续计算，不进行猜测填充

### 4.3 信息不足处理

当输入信息不足以确定字段值时：

1. 输出 `[需核实:字段名]` 占位
2. 在 `errors` 数组中记录原因
3. 在报告中统计低置信度占比
4. 向用户询问补充信息（如适用）

## 八、参数配置参考

### 8.1 常用参数表

| 参数名 | 类型 | 默认值 | 可选值 | 说明 |
|--------|------|--------|--------|------|
| output_format | string | json | json/csv/md | 输出格式 |
| confidence_threshold | float | 0.70 | 0.50-0.95 | 置信度阈值，低于此值标记 |
| batch_size | int | 10 | 1-100 | 批量处理每批条数 |
| backup_original | bool | true | true/false | 是否备份原始文件 |
| field_mapping | object | {} | 自定义映射 | 字段映射关系 |
| include_meta | bool | true | true/false | 是否包含元数据 |

### 8.2 边界值说明

- `batch_size` 最小 1，最大 100，超过 100 自动截断
- `confidence_threshold` 低于 0.50 时所有字段均标记为需核实
- 单次处理最大记录数：10,000 条（超过需分批）
