### 执行步骤（分步编号）

#### 第1步：样本接收与哈希计算

```bash
# 计算样本哈希
sha256sum sample.exe
md5sum sample.exe
```

**输出规范**：
```
SHA256: <64位十六进制>
MD5: <32位十六进制>
文件大小: <字节数>
```

#### 第2步：静态扫描

```bash
# DIE检测文件类型和壳
diec sample.exe

# pestudio分析PE结构（Windows环境）
pestudio.exe sample.exe

# Floss提取字符串（含反混淆）
floss sample.exe > strings.txt
```

**关键检查点**：
- 文件类型是否与扩展名一致
- 是否加壳（UPX、Themida等）
- 导入表是否有可疑API（如`VirtualAlloc`、`CreateRemoteThread`）
- 字符串中是否有URL、IP、注册表路径

#### 第3步：动态分析（可选）

```bash
# 在沙箱中运行（超时3-5分钟）
cuckoo submit sample.exe --timeout 300

# 或手动运行并监控
strace -f -o trace.log ./sample.exe  # Linux
procmon.exe  # Windows
```

**安全警告**：仅在隔离环境中执行，确保网络被监控或阻断。

#### 第4步：IOC提取

从静态和动态分析结果中提取：

| IOC类型 | 提取来源 | 示例 |
|---------|----------|------|
| IP地址 | 字符串、网络流量 | 192.168.1.100:8080 |
| 域名 | 字符串、DNS查询 | malicious.com |
| URL | 字符串、HTTP请求 | http://evil.com/payload |
| 文件路径 | 文件操作监控 | C:\Users\Public\svchost.exe |
| 注册表项 | 注册表监控 | HKCU\Software\Microsoft\Windows\CurrentVersion\Run |

#### 第5步：ATT&CK映射

将观察到的行为映射到MITRE ATT&CK框架：

| 战术 | 技术 | 观察到的行为 | 置信度 |
|------|------|--------------|--------|
| 执行 | T1059.001 PowerShell | 调用powershell.exe执行命令 | 高 |
| 持久化 | T1547.001 注册表Run键 | 写入HKCU\...\Run | 中 |
| 防御规避 | T1027 混淆 | 使用Base64编码字符串 | 高 |

**置信度标注规则**：
- **高**：直接观察到明确行为
- **中**：间接证据支持，需人工确认
- **低**：推测性关联，仅供参考

#### 第6步：生成报告

报告结构建议：

