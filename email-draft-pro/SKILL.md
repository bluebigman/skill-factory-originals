## 三、标准流程

### 前置条件

在发起请求前，请确认以下信息（缺失项会用 `[需核实:字段]` 占位，不影响生成）：

| 参数 | 是否必填 | 说明 |
|------|----------|------|
| 场景 | 必填 | 如催款、询价、道歉、感谢、通知 |
| 收件人身份 | 建议 | 客户/供应商/同事/上级/面试者 |
| 语言 | 可选 | 默认中文，可指定英文或中英对照 |
| 语气 | 可选 | 正式/半正式/亲切/诚恳 |
| 关键信息 | 可选 | 金额、日期、项目名、姓名等 |
| 批量数量 | 可选 | 默认 1 封，最大 5 封 |

### 执行步骤（分步编号）

1. **解析输入**：识别场景、收件人、语言、语气、关键信息。
2. **匹配模板骨架**：从内置场景库中选取对应结构（如催款=提醒→说明→要求→致谢）。
3. **填充内容**：将关键信息填入骨架，缺失部分标注 `[需核实:字段]`。
4. **语气校准**：根据收件人身份调整敬语、句式长度、用词正式度。
5. **语言转换**：若指定英文，则整体翻译并适配英文商务邮件习惯。
6. **批量展开**：若指定批量，则按不同收件人/场景逐条生成。
7. **输出结果**：按下方「输出规范」格式化输出。

### 输出规范

每封邮件输出包含以下结构：

```
【邮件 N / 共 M 封】
主题：[主题行]
称呼：[收件人称呼]
正文：
[正文内容，分段清晰]
结尾敬语：[敬语 + 署名占位]
---
```

批量输出时，邮件之间用 `---` 分隔。
