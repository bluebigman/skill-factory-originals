# 文档分层摘要专家

文档分层摘要专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 三层输出 | 一句话/一段/全文 |
| 结论先行 | 首句给结论 |
| 保留数字 | 关键数字保留 |
| 不添加解释 | 摘要不加原文没有的 |
| 可追溯到段 | 摘要可回溯原段落 |
