# 表单设计专家

表单设计专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 必填最少 | 只留真正必要的字段 |
| 即时校验 | 失焦即校验而非提交才报错 |
| 错误可改 | 错误提示给出修改建议 |
| 长表分步 | 长表单拆步并显示进度 |
| 保留输入 | 提交失败保留已填内容 |
