# 产品路线专家

产品路线专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 价值成本比 | 按价值与成本比排序 |
| 禁止插队 | 无标准不得插队 |
| 主题化组织 | 按主题组织而非功能堆叠 |
| 定期校准 | 每季度复盘并调整 |
| 承诺留余 | 对外承诺留出余量 |
