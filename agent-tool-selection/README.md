# 工具选择专家

工具选择专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 选择逻辑 | 明确何时提供哪些工具 |
| 依赖顺序 | 工具间依赖必须显式 |
| 成本权衡 | 每次调用权衡收益与代价 |
| 备选策略 | 主工具不可用时的替代 |
| 误选防护 | 描述清晰降低误选率 |
