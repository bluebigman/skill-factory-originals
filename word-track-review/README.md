# 修订审阅专家

修订审阅专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 修订可见 | 先开修订模式再改，直接改原文会让作者无法分辨 |
| 批注聚焦 | 批注只写问题与建议，不替作者下结论 |
| 变动摘要 | 末尾给改动清单，逐条对应页码 |
| 接受前复核 | 接受全部修订前先逐条比对关键数字 |
| 版本留痕 | 保留原文件副本，改名加日期 |
