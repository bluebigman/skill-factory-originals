## 三、标准流程

### 3.1 前置条件

| 条件 | 要求 |
|------|------|
| 输入文本 | 纯文本格式，无特殊编码 |
| 文本长度 | 建议 50~2000 字，超出 2000 字建议分段处理 |
| 语言 | 中文或英文（混合亦可） |
| 文件准备 | 若从文件读取，需确保文件为 `.txt` 或 `.md` 格式 |

### 3.2 执行步骤

**第一步：解析输入**

1. 接收原始指令文本。
2. 识别文本中的核心要素：
   - **动作**（动词短语）
   - **对象**（名词短语）
   - **约束**（条件、限制、格式要求）
   - **优先级**（必须/可选/禁止）

**第二步：压缩转换**

3. 删除所有修饰性形容词、副词（如"非常""极其""仔细地"）。
4. 删除所有客套语（如"请""麻烦""谢谢"）。
5. 将复合句拆分为简单句，每句只保留一个动作。
6. 将被动语态转为主动语态。
7. 用短词替换长词（如"使用"→"用"，"执行"→"做"）。
8. 合并重复信息。

**第三步：输出规范**

9. 输出格式：每行一个动作指令，使用 `>` 前缀标记。
10. 输出末尾附压缩统计：`[压缩率: XX%]`。
11. 若存在不确定信息，使用 `[需核实:字段名]` 占位。

### 3.3 输出示例

**输入：**

```
请帮我分析一下这份市场报告，重点关注竞争对手的定价策略，特别是他们最近三个月的价格调整情况。另外，如果可能的话，也请顺便看看他们的促销活动频率，但这不是最重要的，最重要的是定价策略部分。
```

**输出：**

```
> 分析市场报告
> 关注竞品定价策略
> 提取近3月价格调整
> 次要：促销频率
[压缩率: 68%]
```
