| 4 | 批量处理时用户已知晓每份材料独立生成条目 | 交互确认 |

### 执行步骤

**步骤 1：材料接收与分类**

接收输入材料，按内容类型自动分类：

| 材料类型 | 判定依据 | 归属资产类别 |
|---------|---------|-------------|
| 对话记录 | 包含多轮问答、角色标识 | 对话记忆 |
| 技术文档/说明 | 结构化文本、标题层级 | 文档记忆 |
| 代码文件 | 包含编程语言语法 | 代码记忆 |
| 会议纪要/决策记录 | 包含结论、行动项 | 决策记忆 |

**步骤 2：字段提取**

对每份材料提取以下标准字段：

```
来源标识：材料名称或 URL
时间戳：处理时间（ISO 8601 格式）
内容摘要：不超过 200 字的要点概括
关键实体：人物/系统/术语列表
关联标签：3-5 个分类标签
原始内容：保留原文（代码保留语法结构）
```

**步骤 3：资产文件生成**

按类别模板生成独立文件，命名规则：

```
{类别缩写}_{材料名称}_{日期}.md
# 类别缩写：CONV（对话）、DOC（文档）、CODE（代码）、DEC（决策）
```

**步骤 4：索引文件更新**

汇总所有资产条目，生成 `INDEX.md`，包含：

- 资产总览表（类别、数量、时间范围）
- 每项资产的元数据卡片（来源、摘要、标签）
- 检索关键词表

**步骤 5：处理报告输出**

生成处理报告，包含成功条目数、失败条目数、失败原因明细。

### 输出规范

所有输出文件遵循以下格式约定：

