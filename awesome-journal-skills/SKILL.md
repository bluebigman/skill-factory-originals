## 三、标准流程

### 前置条件

| 条件 | 要求 | 缺失处理 |
|------|------|----------|
| 稿件文本 | 至少包含标题和正文 | 提示用户补充 |
| 目标期刊 | 明确指定期刊名称 | 默认输出通用学术格式 |
| 输出格式 | 用户指定或默认 Markdown | 按用户要求调整 |

### 执行步骤

**步骤 1：输入解析**

- 接收用户提供的稿件文本（支持 .txt / .md / .docx 粘贴内容）
- 识别稿件类型（研究论文 / 综述 / 短评 / 快报）
- 提取关键字段：标题、作者、摘要、关键词、正文结构、参考文献

**步骤 2：期刊规则匹配**

- 根据目标期刊调取对应格式规范
- 对照检查稿件结构是否符合要求
- 列出缺失项与多余项

**步骤 3：结构调整建议**

- 按期刊模板重新组织章节顺序
- 标注需要补充的内容（如 AER 需要"数据可用性声明"）
- 对不确定项标注 [需核实:字段名]

**步骤 4：输出生成**

- 生成结构化 Markdown 文件
- 包含：调整后的稿件结构 + 修改建议清单 + 置信度标注
- 自查：字段完整性、格式正确性、置信度标注是否齐全

**步骤 5：用户确认**

- 如有疑问（如期刊版本更新、特殊要求），向用户二次确认
- 根据用户反馈调整输出

### 输出规范

```markdown

## 目标期刊
[期刊名称] [版本/年份]

## 稿件信息
- 标题：[标题]
- 作者：[作者列表]
- 稿件类型：[类型]

## 结构调整建议
| 原章节 | 建议调整 | 优先级 | 置信度 |
|--------|----------|--------|--------|

## 缺失项清单
- [缺失项1] [需核实:具体格式要求]
```
