# 文档版本台账专家

文档版本台账专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 版本号规则 | 主次修订三级 |
| 变更摘要 | 每版写明改了什么 |
| 责任人 | 每版记录作者与审核人 |
| 归档策略 | 旧版归档不删除 |
| 台账可查 | 支持按项目与时间查询 |
