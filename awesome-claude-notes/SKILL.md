# awesome-claude-notes 技能文档

## 一、能力边界：一页纸速查卡

本技能用于将你提供的原始材料（文本、文件、网页链接）转化为结构清晰、字段统一的笔记卡片。它擅长“收拢”和“规整”，不负责“创造”和“分析”。

| 维度 | 说明 |
| :--- | :--- |
| **核心任务** | 解析输入内容，抽取关键信息，按预设模板输出结构化笔记。 |
| **输入类型** | 纯文本粘贴、`.txt` / `.md` 文件、公开网页 URL。 |
| **输出格式** | 默认输出 Markdown 格式的笔记卡片，包含 `主题`、`核心观点`、`关键细节`、`待办/行动项`、`关联概念` 等字段。 |
| **✅ 能做** | 1. 识别输入中的主题、论点、论据、结论。<br>2. 提取人名、地名、机构名、日期、数字等实体。<br>3. 将口语化、碎片化内容改写为书面化、连贯的表述。<br>4. 对内容进行轻度归纳，生成不超过 5 条的要点列表。<br>5. 根据内容自动生成 3-5 个用于检索的标签。 |
| **❌ 不能做** | 1. **不进行深度推理**：不预测趋势、不给出投资建议、不做因果分析。<br>2. **不补充外部知识**：仅基于你提供的内容进行整理，不添加任何背景信息或扩展阅读。<br>3. **不处理非文本信息**：无法识别图片内的文字（OCR）、音频或视频内容。<br>4. **不执行代码**：不会运行输入中的任何代码片段。<br>5. **不保证信息真实性**：仅负责格式整理，不负责事实核查。 |
| **适用对象** | 需要快速整理会议纪要、读书笔记、网页收藏、课程讲义的职场人士、学生、研究者。 |

## 三、标准工作流程

本技能遵循“输入确认 → 内容解析 → 结构化生成 → 自检输出”四步流程。

### 前置条件
- 你提供了明确的输入内容（文本、文件路径或 URL）。
- 输入内容语言不限，但输出默认使用中文。

### 执行步骤

1.  **输入接收与确认**
    - 接收你提供的原始材料。
    - 若输入为 URL，技能会尝试获取网页正文文本。
    - 若输入为文件，技能会读取文件内容。
    - **动作**：向你复述输入来源和字符数量，确认解析范围。

2.  **内容解析与信息抽取**
    - 对输入文本进行分句、分段处理。
    - 识别文本结构（标题、列表、加粗等）。
    - 抽取关键实体（日期、数字、专有名词）。
    - **动作**：在内部生成一个“信息抽取草稿表”，包含 `候选主题`、`关键论点`、`支撑细节`、`行动项`。

3.  **结构化笔记生成**
    - 依据内置模板，将抽取的信息填入对应字段。
    - 对碎片化信息进行合并与去重。
    - 将口语化表达转换为书面语。
    - **动作**：生成 Markdown 格式的笔记卡片。

4.  **自检与输出**
    - 检查必填字段（`主题`、`核心观点`）是否为空。
    - 检查输出格式是否为合法 Markdown。
    - 检查是否存在未处理的明显矛盾信息。
    - **动作**：输出最终笔记卡片，并附带处理置信度。

### 输出规范

输出遵循以下 Markdown 结构：

```markdown
# 笔记卡片：{主题}

> 来源类型：{文本/文件/URL} | 处理时间：{时间戳} | 置信度：{高/中/低}

## 核心观点
- {观点1}
- {观点2}

## 关键细节
- **{细节标题}**：{细节描述}
- **{细节标题}**：{细节描述}

## 待办/行动项
- [ ] {行动项1}
- [ ] {行动项2}

## 关联概念
- {概念1}、{概念2}、{概念3}

## 标签
`{标签1}` `{标签2}` `{标签3}`
```

## 四、置信度门控机制

当输入信息不完整或存在歧义时，本技能不会猜测或编造内容，而是使用特定占位符进行标注。

- **信息缺失**：当输入中未提及某个字段（如“待办/行动项”）所需信息时，输出 `[需核实:待办事项]` 占位符，而非留空或虚构。
- **语义模糊**：当同一句话存在多种理解且无法通过上下文判断时，在对应观点后标注 `[需核实:语义]`。
- **数据异常**：当输入中的数字、日期等信息存在明显矛盾时，输出 `[需核实:数据冲突]`，并列出冲突内容。

**置信度等级说明**：
- **高置信度**：输入信息完整、清晰，无歧义。
- **中置信度**：输入信息基本完整，但存在少量语义模糊或细节缺失。
- **低置信度**：输入信息碎片化严重，或存在大量矛盾点。此时输出结果仅供参考，需人工复核。
