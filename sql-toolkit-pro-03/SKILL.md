## 三、标准流程

### 3.1 前置条件

| 条件 | 要求 | 检查方法 |
|------|------|---------|
| 文件格式 | CSV / TSV / JSON / XLSX | 查看文件扩展名 |
| 文件位置 | 与 Skill 工作目录相同 | `ls` 确认文件存在 |
| 命名规范 | 同一批文件命名前缀一致 | 如 `sales_01.csv`, `sales_02.csv` |
| 数据质量 | 无合并单元格、无空行、列名唯一 | 打开文件目视检查 |

### 3.2 执行步骤

**Step 1：文件准备**
1. 将所有待处理文件放入同一目录（如 `./data/`）
2. 确认文件命名符合规范（如 `表名_序号.扩展名`）
3. 记录文件清单，准备一份样本文件用于试运行

**Step 2：试运行（单样本）**
1. 选取一个样本文件（如 `sales_01.csv`）
2. 执行转换命令：
   ```bash
   sqlgen convert ./data/sales_01.csv --format csv --output ./output/
   ```
3. 检查输出字段：
   - 列名是否完整映射
   - 数据类型是否正确推断
   - 特殊字符（引号、逗号）是否转义

**Step 3：批量执行**
1. 确认试运行无误后，对全量文件执行：
   ```bash
   sqlgen convert ./data/*.csv --format csv --output ./output/ --batch
   ```
2. 保留原始文件备份（建议复制到 `./backup/` 目录）
3. 记录执行日志，包括每个文件的转换状态

**Step 4：结果校验**
1. 从输出中随机抽取 5-10 条记录
2. 与源文件对应行进行字段级比对
3. 核对关键字段（主键、日期、金额）是否一致
4. 生成校验报告，标注通过/失败项
