本技能面向企业法务、合同管理员、业务负责人及需要快速理解合同风险的非法律专业人士。它是一套**结构化分析工具**，而非替代律师出具法律意见的决策系统。

### 1.1 能做什么

| 能力项 | 说明 | 输出形式 |
|--------|------|----------|
| 合同文本结构化 | 将非格式化合同原文拆解为条款序列 | JSON 对象，含条款序号、标题、正文 |
| 风险点识别 | 识别常见合同风险（如付款条件模糊、违约责任缺失、保密期限过长等） | 风险列表，含条款引用、风险类型、风险等级 |
| 条款比对 | 对两份合同（如新旧版本）进行逐条差异比对 | 差异清单，标注新增/删除/修改 |
| 风险分级 | 按高/中/低三档标注风险严重程度 | 风险等级标签 + 简要理由 |

### 1.2 不能做什么（明确边界）

- **不提供最终法律意见**：本技能输出仅为风险提示，不构成法律建议。最终决策须由持证律师作出。
- **不处理非文本输入**：仅接受纯文本合同内容，不支持 PDF、图片扫描件直接解析（需先转为文本）。
- **不保证条款完整性**：若原文存在缺页、乱码或表格内容，结构化结果可能不完整。
- **不识别所有风险类型**：仅覆盖常见商业合同风险点，不包含特定行业（如金融衍生品、跨境并购）的专项风险。
- **不执行自动修改**：本技能只做分析与标注，不提供合同修改建议文本。

### 1.3 适用对象

- 需要快速审阅标准合同（NDA、采购协议、服务合同）的法务专员
- 需要对比合同版本差异的合同管理员

## 三、标准流程

### 3.1 前置条件

- 输入内容须为**纯文本格式**的合同内容（支持中英文）。
- 单次输入建议不超过 15,000 字（超出部分将被截断，建议分段提交）。
- 若需条款比对，请准备两份合同文本，并明确标注"版本A"与"版本B"。

### 3.2 执行步骤（分步编号）

1. **接收输入**：用户粘贴合同文本或指定比对的两份文本。
2. **文本清洗**：去除多余空行、页眉页脚、页码等噪声信息。
3. **条款切分**：按"第X条"、"X."、"1."等常见条款编号模式切分文本，生成条款序列。
4. **风险扫描**：对每条条款执行规则匹配（关键词 + 句式模式），识别风险点。
5. **风险分级**：根据风险类型与影响程度，赋予高/中/低等级。
6. **输出报告**：生成结构化 JSON 报告，包含条款清单与风险列表。

### 3.3 输出规范

输出为 JSON 格式，结构如下：

```json

      "clause_id": 1,
      "clause_title": "保密义务",
      "clause_text": "乙方应对甲方披露的所有信息承担保密义务...",
      "risk_flags": [
        {
          "risk_type": "保密期限过长",
          "risk_level": "中",
          "reason": "保密期限未设上限，可能构成不合理限制"
        }
      ]
    }
  ],
  "risk_summary": {
    "high": 1,
    "medium": 2,
    "low": 3
  }
}
```
