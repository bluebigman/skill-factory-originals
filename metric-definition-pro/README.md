# 指标定义专家

指标定义专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 口径唯一 | 一个指标只有一个口径 |
| 可复算 | 任何人能按口径复算 |
| 维度明确 | 指标的统计维度必须写明 |
| 陷阱标注 | 常见误读须标注 |
| 变更留痕 | 口径变更须记录影响 |
