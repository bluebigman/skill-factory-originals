# 发票整理归集专家

发票整理归集专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 按类归档 | 按费用类型分目录，不按月份 |
| 命名规范 | 日期-类型-金额-单位 |
| 联次核对 | 核对发票联与抵扣联是否齐全 |
| 重复检测 | 按号码去重防重复报销 |
| 汇总清单 | 输出可核对的汇总表与缺失清单 |
