## 三、标准流程

### 前置条件

- 输入文本为纯文本格式（支持 Markdown 格式输入）
- 文本长度建议不超过 10,000 字/次（超出可分批处理）
- 如需保留时间戳，请在输入中保留原始时间戳格式

### 执行步骤

**第一步：接收输入并确认场景**

用户粘贴文本后，系统自动判断场景类型：

| 场景类型 | 判断依据 | 处理侧重 |
|----------|----------|----------|
| 播客 | 有对话轮次、话题跳跃、轻松语气 | 保留对话感，适度书面化 |
| 访谈 | 一问一答结构、有采访者/受访者 | 保留问答结构，标注发言人 |
| 会议 | 多人发言、有议题讨论 | 按议题分段，保留结论性语句 |
| 其他/未知 | 无法判断时 | 按通用规则整理 |

**第二步：执行文本清洗**

按以下优先级依次处理：

1. **语气词删除**：删除句中或句首的"嗯、啊、呃、哦、哎、唉、啧"等无实义语气词
2. **重复词合并**：连续重复的词语合并为一个（"就是就是"→"就是"）
3. **自我修正清理**：识别"不对""不是""我说错了""等等"等修正前缀，删除修正过程，保留最终表述
4. **口头禅过滤**：识别高频出现的口头禅（每段出现≥2次），全部删除
5. **碎片句合并**：将"然后。就是。那个。"等碎片短句合并为完整句子
6. **标点规范化**：统一为全角标点，补全缺失的句号、逗号
7. **段落重排**：按语义逻辑重新划分段落

**第三步：输出整理结果**

输出格式如下：

```markdown

[整理后的正文文本]

---

## 整理说明

- 处理文本长度：X 字 → Y 字（压缩率 Z%）
- 删除语气词：X 处
- 合并重复词：X 处
- 清理自我修正：X 处
- 删除口头禅：X 处
- 标记需核实信息：X 处
```

### 输出规范

- 正文使用标准 Markdown 格式
- 段落间空一行
- 对话场景使用 `**发言人：**` 格式标注
