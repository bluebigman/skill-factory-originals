# 邮件回函工坊（email-reply-craft）使用手册

## 一、能力边界：一页纸速查卡

本 Skill 面向需要快速起草专业邮件的职场人士、自由职业者及行政支持人员。它接收一段原始文本（可能是邮件、聊天记录或对话摘要），输出结构化的回复草稿与配套建议。

| 能力维度 | 支持范围 | 不支持范围 |
|---------|---------|-----------|
| 输入解析 | 邮件正文、微信/短信对话、会议纪要、语音转文字稿 | 加密邮件、图片中的文字（需先 OCR） |
| 语气生成 | 正式、半正式、亲切、紧迫、安抚、拒绝 | 生成欺骗性内容、冒充他人身份 |
| 附件建议 | 基于正文语义推荐附件类型（如合同、报价单） | 实际生成附件文件 |
| 抄送建议 | 基于角色推断（上级、同事、客户） | 读取通讯录或组织架构 |
| 格式校验 | 检查称呼、落款、主题行、段落长度 | 检查拼写错误（需外部拼写工具） |
| 文件输出 | 生成 .eml 格式草稿文本 | 直接发送邮件、连接邮件服务器 |

**适用对象**：需要每日处理大量往来邮件的运营人员、销售助理、项目经理。**不适用**：法律文书最终定稿、涉及机密信息的邮件（请勿将敏感内容输入本工具）。

## 三、标准流程：从输入到输出

### 前置条件

- 输入文本不少于 10 个字，不多于 5000 字
- 明确回复对象（收件人身份或称呼）
- 若输入为对话，需包含至少两轮交流

### 执行步骤

1. **解析输入**：识别发件人意图、核心诉求、情绪基调（积极/中性/消极）。
2. **提取要素**：列出需要回复的 3-5 个关键点，标注不确定项。
3. **生成草稿**：按以下参数表生成 3 个版本：

| 参数 | 正式版 | 半正式版 | 亲切版 |
|------|--------|---------|--------|
| 称呼 | 尊敬的[姓氏]先生/女士 | [名字]你好 | Hi [名字] |
| 句式 | 被动语态、完整从句 | 主动语态、中等长度 | 短句、口语化 |
| 落款 | 此致 敬礼 + 全名 | 祝好 + 名字 | Cheers + 昵称 |
| 用词 | 书面语、无缩写 | 少量缩写（如 FYI） | 自然口语、可带 emoji |

4. **附加建议**：生成附件推荐（如“建议附上：报价单 PDF”）、抄送建议（如“建议抄送：财务部负责人”）。
5. **格式校验**：检查称呼是否匹配、主题行是否超过 50 字符、段落是否超过 5 行、落款是否完整。
6. **输出报告**：汇总草稿 + 建议 + 校验结果，生成 .eml 文件内容。

### 输出规范

输出包含四部分，用分隔线隔开：

```
【草稿 A：正式版】
（邮件全文）

---

【草稿 B：半正式版】
（邮件全文）

---

【草稿 C：亲切版】
（邮件全文）

---

【附件/抄送建议】
- 附件：xxx
- 抄送：xxx

【格式校验报告】
- 主题行：通过/未通过（原因）
- 称呼：通过/未通过（原因）
- 落款：通过/未通过（原因）

【.eml 文件内容】
（Base64 编码的邮件源文件）
```
