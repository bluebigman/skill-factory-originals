# 回复邮件 · 一站式处理专家

> **一页纸速查卡**（30秒上手）
> - **这个技能做什么**：从原始邮件/转发链/草稿箱中提取关键信息，自动生成专业回复邮件，并完成语气、格式、附件、收件人校验，输出可直接发送的 .eml/.txt 文件。
> - **什么时候用**：你手头有一封需要回复的邮件，但不知道怎么写、写多长、语气怎么定、要不要抄送、附件带不带——把原文丢给我即可。
> - **怎么用**：① 粘贴邮件原文或转发链 → ② 回答我 3 个问题（回复目的、语气偏好、截止时间）→ ③ 我输出 3 版草稿 + 1 份校验报告 → ④ 你选一版，我生成 .eml 文件。
> - **输出物**：`reply_draft.md`（草稿+理由）、`reply_checks.md`（校验报告）、`reply.eml`（可直接导入 Outlook/Thunderbird）。
> - **不做什么**：不代发邮件、不伪造发件人、不处理涉密/违法内容、不保证收件人一定会读。

输出时按以下三档处理：

|------------|------|----------|

| **< 85%** | 🔶 [需核实] | 草稿 + 校验报告 + 每个不确定信息标注 `[需核实]` + 提示用户补充 |

**置信度计算规则（`calculate_confidence()`）：**

```python
def calculate_confidence(entities, intent, purpose):
    score = 80  # 基础分
    # 实体完整度：关键实体每缺一个扣 5 分
    required = ['sender_name', 'date', 'subject']
    for r in required:
        if r not in entities or not entities[r]:
            score -= 5
    # 意图明确度：意图置信度 < 0.7 扣 5 分
    if intent['confidence'] < 0.7:
        score -= 5
    # 目的匹配度：用户提供的 purpose 与识别意图一致 +5 分
    if purpose == intent['label']:
        score += 5
    # 信息完整度：有订单号/金额等关键数字 +5 分
    if entities.get('order_no') or entities.get('amount'):
        score += 5
    # 语气匹配：模板与用户要求一致 +5 分
    return min(100, max(0, score))
```

## 六、FAQ（高频问题速查）

**Q1: 这个技能能直接帮我发邮件吗？**
A: 不能。技能只生成邮件内容（.eml 文件），发送需要你在 Outlook/Thunderbird/Gmail 中完成。这是为了安全考虑——技能不接触你的邮箱密码。

**Q2: 回复英文邮件效果怎么样？**
A: 英文回复使用独立的模板库（`templates/en/`），包含 23 个商务英语句式。测试集 200 封英文邮件，语法错误率 < 3%。但建议对英文草稿做一次人工校对。

**Q3: 怎么让回复更像我的个人风格？**
A: 提供你过往 5 封以上已发送邮件（粘贴原文即可），技能会提取你的风格画像：平均长度、称呼习惯、是否用 emoji、结尾敬语。之后生成的草稿会匹配你的风格。

**Q4: 遇到投诉邮件怎么处理？**
A: 投诉邮件自动进入"安抚模式"：先道歉（不认错）→ 共情 → 提出解决方案 → 给出时间表。模板中内置 8 种投诉场景（质量/交期/服务/价格/物流/售后/态度/其他）。

**Q5: 批量回复时每封邮件都要回答 3 个问题吗？**
A: 不需要。批量模式下你可以统一设置"回复目的"和"语气偏好"，技能会逐封处理。但每封邮件的置信度独立计算，低置信度的会单独标注。

## 七、深度技术说明（进阶用户）

### 7.1 意图分类器实现

`intent_classifier.py` 使用两层分类：

1. **关键词层**：`intent_keywords.json` 中定义 5 类意图的关键词权重：
   ```json
   {
     "inquiry": {"价格": 0.8, "多少钱": 0.9, "报价": 0.7, "how much": 0.8},
     "confirm": {"确认": 0.7, "请回复": 0.6, "confirm": 0.8},
     "complaint": {"投诉": 0.9, "不满": 0.8, "太差": 0.7, "complaint": 0.9},
     "invitation": {"邀请": 0.8, "参加": 0.6, "invite": 0.8},
     "notification": {"通知": 0.7, "变更": 0.6, "notice": 0.7}
   }
   ```
2. **句式层**：使用 `spaCy` 依存句法分析，识别疑问句（`?`/`吗`/`怎么`）、祈使句（`请`/`please`）、感叹句（`!`/`太`）。

最终得分 = 关键词得分 × 0.7 + 句式得分 × 0.3，取最高分意图。

### 7.2 模板填充引擎

每个模板文件包含 `{placeholder}` 占位符，填充时使用 `str.format()` 替换。未替换的占位符会被 `validate_email.py` 的 V3 检查捕获。
