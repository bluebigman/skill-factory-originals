# 分支隔离工作区专家

分支隔离工作区专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 一任务一工作区 | 并行任务用独立工作区防互相污染 |
| 目录选定 | 工作区放在主仓同级非仓内 |
| 清理及时 | 任务结束即删除工作区 |
| 命名可读 | 工作区名含任务标识 |
| 安全检查 | 删前确认无未提交改动 |
