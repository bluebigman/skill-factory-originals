- 命令行参数优先级：`--text` > `--file` > 默认内置文本。若同时传入多个，仅使用最高优先级。
- 对于 10-K 等英文财报，当前版本仅支持中文关键词，请将文本预翻译为中文后使用。

## 高频问题排查与典型错误用法
在使用本技能解析年报时，用户常因输入格式或内容不符合预期而遇到错误。为帮助您快速定位问题，以下列举了五个高频场景及对应的排查方法。

| 现象 | 可能原因 | 解决方式 |
|------|----------|----------|
| 输出错误码 `E001` | 输入文件为空或无法读取 | 确认文件路径正确且文件非空；检查文件编码是否为 UTF-8 |
| 输出错误码 `E003` | 文本中未找到“营业收入”或“净利润”等关键字段 | 确保输入为完整的年报正文（而非仅目录或摘要页）；可尝试增加 `--text` 参数直接粘贴文本片段 |
| 输出错误码 `E005` | 数值超出合理范围（如营收为负数或超过 10^13） | 检查原始文本是否存在单位混用（如“亿元”与“万元”混淆）；确认未误选附注中的历史调整数据 |
| 输出结果中风险信号为空 | 文本中无风险相关关键词（如“诉讼”“退市”“质押比例超50%”） | 这属于正常情况，不代表无风险；如需更全面的风险扫描，请确保输入包含“管理层讨论与分析”章节 |
| 命令行执行后无任何输出 | 未使用正确的参数格式 | 参考下方“正确调用示例”，确认至少提供一种输入方式 |

**典型错误用法示例（请勿模仿）：**

```bash
# 错误1：仅提供文件路径，但文件为PDF格式（本技能仅支持纯文本或txt）
python scripts/main.py --input report.pdf

# 错误2：同时使用 --input 和 --text 且内容冲突
python scripts/main.py --input annual_2024.txt --text "另一段不相关文本"

# 错误3：使用未定义的触发词（参见下方“触发词一致性”章节）
python scripts/run.py 帮我看看股票
```

**正确调用方式：**

```bash
# 方式一：从文件读取
python scripts/main.py --input annual_report_2024.txt

# 方式二：直接传入文本
python scripts/main.py --text "公司2024年营业收入为123.45亿元，同比增长10.2%..."

# 方式三：自检模式（验证安装与基础功能）
python scripts/main.py --selftest
```

**错误码速查表（完整定义见 SKILL.md 附录）：**

| 错误码 | 含义 | 常见场景 |
|--------|------|----------|
| E001 | 文件读取失败 | 路径错误、权限不足 |
| E002 | 编码不支持 | 非 UTF-8 文件 |
| E003 | 关键指标缺失 | 文本截断、只输入了封面 |
| E004 | 数值解析异常 | 千分位逗号、中文数字混合 |
| E005 | 数值范围越界 | 单位错误或文本误选 |
| E006 | 风险信号解析冲突 | 同一段落出现矛盾表述 |
| E007 | 输出序列化失败 | 磁盘空间不足或权限限制 |
| E008 | 依赖库缺失 | 未安装 `pandas` 或 `numpy` |
| E009 | 输入为空 | `--text` 后未跟内容 |
| E010 | 未知参数 | 拼写错误或参数未定义 |

> **注意**：若遇到 `E008`，请检查 Python 环境并安装所需依赖（命令示例：`pip install pandas numpy`），但本技能不提供自动安装功能。

## 深入分析引导：超越基础指标提取
本技能默认仅执行规格内的指标提取与计算，不提供投资建议或业绩预测。但您可以通过以下方式，利用输出结果进行更深层次的业务洞察。

### 1. 行业对标手动补充

技能输出的 `metrics` 字段包含营收、净利润、毛利率等核心值。您可以将这些值与同行业公开数据（如行业协会统计、竞争对手年报）进行对比。例如：

| 指标 | 本公司 (2024) | 行业平均 | 差异率 |
|------|---------------|----------|--------|
| 营业收入增长率 | 12.5% | 8.0% | +56.3% |
| 净利率 | 9.2% | 6.5% | +41.5% |
| 资产负债率 | 58.0% | 62.0% | -6.5% |

### 2. 趋势预判辅助决策

技能输出中的 `risk_signals` 字段会标记如“应收账款激增”“存货周转下降”等信号。您可结合连续三年的输出结果，构建简单趋势表：

```text
2022年：营收 +5%，风险信号：无
2023年：营收 +9%，风险信号：应收账款增幅>30%
2024年：营收 +12.5%，风险信号：应收账款增幅>40%，存货周转天数+15天
```

上表显示：营收增长加速的同时，应收账款增速持续高于营收增速，暗示回款质量可能恶化。此类分析虽超出技能默认范围，但基于技能提供的结构化数据可轻松完成。

### 3. 引导性问题清单

当技能输出完成后，建议您带着以下问题审视结果：

- 营收增长主要来自主营业务还是非经常性损益？（技能不会自动拆分，需查阅原始文本附注）
- 毛利率变化是否与原材料价格波动匹配？（可自行收集大宗商品价格指数）
- 风险信号中的“质押比例高”是否已反映在股价中？（需结合市场信息，技能不涉及）
- 连续两年的 `risk_signals` 对比是否显示风险在累积还是释放？

### 4. 输出字段扩展用法

技能默认输出 JSON 结构如下：

```json
{
  "company": "示例公司",
  "period": "2024",
  "metrics": {
    "revenue": 12345000000,
    "net_profit": 890000000
  },
  "risk_signals": ["应收账款增幅超30%"]
}
```

您可以将此 JSON 导入 BI 工具或 Excel，利用数据透视表进行跨年度、跨公司的横向比较。技能本身不限制输出数据的二次处理。

> **合规提醒**：以上所有扩展分析均为用户自主行为，技能不提供任何投资建议、不预测未来业绩，也不对基于这些分析做出的决策承担任何责任。请务必同时参阅 SKILL.md 中【不能做什么】表格的全部条款。

## 灵活输入与配置指南
本技能默认硬编码了部分 API 股票代码（位于 `run.py` 第 37 行附近），但您无需修改代码即可解析任意公司的年报文本。以下是具体方法：

### 场景一：解析非硬编码公司

假设您需要分析“某科技公司”的年报，该公司的股票代码不在默认列表中。您有两种方式：

**方式 A（推荐）**：直接使用文本输入，跳过股票代码解析步骤：

```bash
python scripts/main.py --text "某科技公司2024年实现营业收入98.7亿元，同比增加15.3%..."
```

**方式 B**：若您希望保留代码中的公司名称映射（如用于输出格式化），可临时修改 `run.py` 中的 `TRIGGERS` 或 `COMPANY_MAP` 字典。修改前请备份原文件，且此操作不影响 `main.py` 的核心功能。

### 场景二：统一入口 run.py 与 main.py 的关系

| 文件 | 主要职责 | 推荐使用场景 |
|------|----------|--------------|
| `scripts/main.py` | 核心解析引擎，支持 `--input/--text/--selftest` | 日常单次解析、自动化脚本调用 |
| `scripts/run.py` | 封装层，增加触发词匹配和 API 股票代码映射 | 需要按公司代码快速调取文本时 |

**重要提示**：若您的输入文本中已包含完整公司名称和财务数据，请优先使用 `main.py`，避免 `run.py` 中的股票代码映射干扰解析结果。

### 场景三：代码版本一致性检查

由于 `annual_report.py` 开头存在结构混乱问题（第 2-11 行），不同版本间可能存在细微差异。建议您：

1. 运行自检命令验证当前版本完整性：

```bash
python scripts/main.py --selftest
```

2. 若输出中提示任何 `WARNING` 或版本号不匹配，请以 `main.py` 的输出为准，并忽略 `run.py` 中过时的常量定义。

### 使用示例矩阵

| 您的输入条件 | 推荐命令 | 预期输出 |
|--------------|----------|----------|
| 已下载年报 TXT 文件 | `python scripts/main.py --input ./data/2024_annual.txt` | 指标 JSON + 风险信号数组 |
| 仅有年报 PDF（需先转文本） | 先使用 `pdftotext` 转换，再执行上述命令 | 同上 |
| 从新闻稿复制的一段财务摘要 | `python scripts/main.py --text "..."` | 尝试提取指标（可能因字段不全而报 E003） |
| 批量处理 10 个文件 | 编写循环调用 `main.py`（技能无内置批处理） | 逐个输出 JSON 文件 |

> **注意**：技能不包含 PDF 解析功能，若输入 PDF 将直接报 E001。请提前使用系统自带的文本提取工具（如 `pdftotext`）转换格式。
