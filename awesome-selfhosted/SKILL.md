# awesome-selfhosted 技能文档

## 一、能力边界：一页纸速查卡

本技能面向**学习与参考场景**，帮助你将零散的自托管服务信息（如项目名称、GitHub 链接、功能描述）整理为结构化的速查清单，便于后续检索与对比。

| 维度 | 能做 | 不能做 |
|------|------|--------|
| 输入处理 | 接受用户粘贴的文本、上传的文件（.txt/.md/.csv）、公开 URL 指向的文本内容 | 不抓取需要登录的页面，不解析图片或 PDF 中的文字 |
| 信息提取 | 识别服务名称、官方链接、功能标签、部署方式（Docker/K8s/裸机） | 不评估服务安全性，不验证链接实时可用性 |
| 输出格式 | 生成 Markdown 表格、JSON 数组、CSV 行 | 不生成可执行脚本或配置文件 |
| 批量操作 | 支持一次处理 1-20 条记录，超出部分分批提示 | 不处理超过 100 条的批量请求（防超时） |
