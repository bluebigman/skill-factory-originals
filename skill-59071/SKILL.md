# 手机教程一站式处理 Skill

## 一、能力边界：一页纸速查卡

本 Skill 专注于手机教程类素材的**识别、整理、生成与校验**，输出可直接交付的 Markdown 教程文档。

| 维度 | 能做 | 不能做 |
|------|------|--------|
| 设备识别 | 根据截图 EXIF、系统界面元素、状态栏图标判断常见品牌（华为/小米/苹果/OPPO/vivo/三星）及大致系统版本 | 无法识别定制 ROM 的具体版本号（如 MIUI 14.0.3 内部代号） |
| 操作目标 | 从用户描述或截图中提取核心操作意图（如"设置双卡"、"开启深色模式"） | 无法推测用户未提及的隐藏需求 |
| 素材处理 | 接受 PNG/JPG 截图，支持批量重命名、按步骤排序、生成标注说明 | 不支持视频素材、不支持对模糊截图进行画质修复 |
| 文字提取 | 从清晰截图中提取界面文字（OCR），识别按钮名称与菜单路径 | 无法识别手写文字、艺术字体、非中文界面 |
| 文档生成 | 生成含步骤清单、截图占位、注意事项的教程 Markdown | 不生成 PDF/Word 等二进制格式 |
| 质量校验 | 对每一步骤给出置信度标记（高/中/低），标注信息缺口 | 无法保证操作步骤在目标设备上 100% 可复现 |

**适用对象**：需要快速将零散截图+口述整理为可分享教程的普通用户、客服人员、数码博主、企业内部培训文档编写者。

**不适用场景**：涉及系统底层修改（root、刷机）、需要视频演示的复杂操作、多设备联动教程。

## 三、标准流程：从素材到成品

### 前置条件

| 条件项 | 要求 | 缺失处理 |
|--------|------|----------|
| 设备型号 | 品牌+型号（如"华为 Mate 60 Pro"） | 尝试从截图推断，否则标记 [需核实:设备型号] |
| 系统版本 | 如"HarmonyOS 4.0"、"iOS 17.2" | 从截图"关于本机"页面提取，否则标记 [需核实:系统版本] |
| 操作目标 | 一句话描述（如"设置应用锁"） | 必须向用户追问，不猜测 |
| 素材文件 | 截图（PNG/JPG）或文字描述 | 至少需要一种，两者皆无则拒绝处理 |

### 执行步骤

**Step 1：素材接收与预检**
- 接收用户粘贴的文字或上传的图片文件
- 检查图片格式（非 PNG/JPG 则提示转换）
- 统计截图数量，按文件名或时间戳排序

**Step 2：信息确认（一次性确认，不反复追问）**
- 列出已识别信息：`设备型号：华为 Mate 60 Pro（推断自状态栏）`、`系统版本：HarmonyOS 4.0（推断自设置界面）`、`操作目标：设置双卡双待`
- 请用户确认或修正，回复"确认"或直接给出修正信息

**Step 3：内容解析**
- 对每张截图执行 OCR 提取界面文字
- 识别操作路径（如"设置 → 移动网络 → SIM卡管理"）
- 将截图与操作步骤进行匹配（按时间戳或用户描述）

**Step 4：文档生成**
- 按以下模板输出 Markdown 文档：

```markdown
# 《[操作目标]》教程 — [设备型号] ([系统版本])

## 适用环境
- 设备型号：[设备型号]
- 系统版本：[系统版本]
- 适用人群：[新手/进阶]

## 操作步骤

### 步骤 1：[步骤标题]
![截图占位：步骤1截图](images/step1.png)
**操作说明**：[详细文字描述]
**预期结果**：[操作后界面应显示的内容]

### 步骤 2：[步骤标题]
...

## 注意事项
- [常见错误提示]
- [操作禁忌]

## 故障排查
| 问题现象 | 可能原因 | 解决方法 |
|----------|----------|----------|
| [现象] | [原因] | [方案] |
```

**Step 5：质量校验与交付**
- 检查每个步骤是否包含：标题、截图占位、操作说明、预期结果
- 对信息不完整的字段标注 `[需核实:字段名]`
- 输出置信度总评：高（≥90% 步骤完整）/ 中（70-89%）/ 低（<70%）

### 输出规范

| 输出项 | 格式 | 说明 |
|--------|------|------|
| 教程文档 | Markdown (.md) | 完整教程，含步骤、截图占位、注意事项 |
| 步骤清单 | 有序列表 | 每步含标题与一句话摘要 |
| 截图标注 | 文件名映射表 | 原始截图 → 教程中占位名称的对应关系 |
| 置信度报告 | 文本摘要 | 列出所有 [需核实] 字段及整体置信度 |

## 四、置信度门控：不编造原则

当以下信息缺失时，**必须**输出占位符而非猜测值：

| 缺失字段 | 占位符格式 | 示例 |
|----------|------------|------|
| 设备型号 | `[需核实:设备型号]` | 无法从截图判断品牌时 |
| 系统版本 | `[需核实:系统版本]` | 截图中无"关于本机"页面 |
| 操作路径 | `[需核实:操作路径]` | 截图顺序混乱无法确定先后 |
| 按钮名称 | `[需核实:按钮名称]` | OCR 结果模糊或界面为英文 |
| 步骤数量 | `[需核实:步骤总数]` | 截图不连续，存在跳步 |

**规则**：
1. 每个占位符必须出现在最终文档的对应位置，不得删除
2. 占位符数量超过总字段数的 30% 时，整体置信度标记为"低"，并建议用户补充素材
3. 禁止用"大概"、"可能"、"应该是"等模糊词替代占位符

## 五、错误码体系：常见问题与修正

| 错误码 | 错误描述 | 用户提示话术 | 修正步骤 |
|--------|----------|--------------|----------|
| E001 | 素材格式不支持 | "抱歉，仅支持 PNG/JPG 格式的截图。请转换后重新上传。" | 用户转换格式后重新上传 |
| E002 | 缺少操作目标描述 | "请告诉我您想教用户完成什么操作？例如'设置指纹解锁'。" | 用户补充一句话描述 |
| E003 | 截图顺序混乱 | "检测到截图时间戳不连续，无法确定操作顺序。请按操作先后重新命名图片（如 01.png、02.png）。" | 用户重命名后重新上传 |
| E004 | OCR 识别率过低 | "截图中的文字清晰度不足，识别准确率低于 60%。建议重新截取高分辨率图片。" | 用户提供更清晰的截图 |
| E005 | 设备型号冲突 | "从截图中检测到两种不同品牌的设备界面，请确认教程针对哪款设备？" | 用户指定目标设备 |
| E006 | 步骤信息不完整 | "第 3 步缺少'预期结果'描述，无法判断操作是否成功。" | 用户补充该步骤的界面反馈信息 |
| E007 | 素材量超出限制 | "单次处理最多支持 20 张截图，当前收到 25 张。请分批处理。" | 用户拆分素材后分批提交 |

## 六、FAQ 反模式：常见坑与正确做法

| 常见坑（反模式） | 问题描述 | 正确做法（正模式） |
|------------------|----------|---------------------|
| 忽略版本差异 | 直接套用通用步骤，未考虑不同系统版本菜单名称不同 | 在教程开头明确标注"适用于 [系统版本]，其他版本菜单路径可能略有差异" |
| 截图无标注 | 只贴截图不写说明，用户看不懂图中哪个区域需要操作 | 每张截图配一句"图中红框位置为 [按钮名称]"的说明 |
| 步骤跳跃 | 从步骤 1 直接跳到步骤 5，中间过程缺失 | 保持步骤连续，缺失部分用 `[需核实:步骤X内容]` 标注 |
| 术语堆砌 | 使用"APN 设置"、"VoLTE 开关"等专业术语但不解释 | 首次出现专业术语时加括号注释，如"APN（接入点名称）" |
| 假设用户基础 | 默认用户知道"进入设置"、"下拉通知栏"等基础操作 | 在"适用人群"中注明"新手"或"进阶"，新手教程需补充基础操作说明 |
