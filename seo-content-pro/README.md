# 搜索内容专家

搜索内容专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 意图分类 | 按搜索意图分类再组织内容 |
| 一词一页 | 一个页面聚焦一个主词 |
| 结构可读 | 标题层级与段落结构清晰 |
| 内链闭环 | 相关页之间互相链接 |
| 按数据更新 | 按搜索数据定期更新内容 |
