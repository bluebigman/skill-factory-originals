# 本地化翻译专家

本地化翻译专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 术语统一 | 先建并锁定术语表 |
| 母语终审 | 终审必须由目标语母语者做 |
| 语境适配 | 按界面长度与场景调整表达 |
| 文化核查 | 核查文化敏感与禁忌 |
| 抽检留痕 | 按比例抽检并留记录 |
