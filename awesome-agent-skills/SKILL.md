# awesome-agent-skills 技能导航与检索指南

## 一、能力边界：一页纸速查卡

本 Skill 的核心职能是**帮助你在庞大的技能库中快速定位、筛选并理解某个技能是否适合当前任务**。它本身不执行具体业务逻辑（如写代码、做表格），而是充当“技能地图”和“筛选器”。

| 维度 | 说明 |
|------|------|
| **核心能力** | 根据任务描述，从技能库中匹配并推荐最合适的技能条目 |
| **辅助能力** | 解析技能元数据（名称、描述、标签），提取关键特征供你决策 |
| **输入要求** | 一段自然语言的任务描述，或一个具体的技能名称关键词 |
| **输出形式** | 结构化的技能推荐列表，包含匹配度、简要说明、使用建议 |
| **明确不做** | 不执行技能内部逻辑；不修改技能代码；不保证某个技能在特定环境下的运行结果 |

**适用对象**：正在使用 Claude Code、Codex 等支持技能机制的开发者、AI 应用构建者、自动化流程设计者。

**不适用场景**：需要直接运行代码或处理数据的任务（请直接调用具体技能）；需要深度技术支持的场景（请查阅该技能自身文档）。

## 三、标准流程：从输入到输出的完整链路

### 前置条件

1. 技能库索引已加载（通常由宿主环境自动完成）。
2. 输入内容为文本形式，长度建议不超过 500 字。

### 执行步骤

1. **解析输入**：识别输入是“任务描述”还是“技能名称关键词”。
2. **匹配检索**：在技能库中按名称、描述、标签进行模糊匹配。
3. **排序筛选**：按匹配度（名称 > 描述 > 标签）降序排列，取前 5 条。
4. **生成摘要**：为每条结果提取名称、一句话简介、适用场景、使用前置条件。
5. **输出结果**：按固定格式输出，并附上匹配置信度。

### 输出规范

```markdown
## 技能推荐结果

### 1. [技能名称]（匹配度：高/中/低）
- **一句话简介**：xxx
- **适用场景**：xxx
- **前置条件**：xxx
- **使用建议**：xxx

### 2. [技能名称]（匹配度：中）
...
```

**置信度标注规则**：
- **高**：技能名称或描述与输入关键词高度重合（≥80% 语义相似）。
- **中**：部分重合，或描述中包含相关概念。
- **低**：仅标签或边缘描述相关，需人工确认。

## 四、置信度门控：不编造，不硬凑

当出现以下情况时，本 Skill 会明确输出占位符，而不是猜测：

| 情况 | 输出行为 |
|------|---------|
| 输入信息不足（如仅一个词“处理”） | 输出 `[需核实:任务类型]`，并提示补充动词+对象 |
| 匹配结果少于 3 条 | 输出 `[需核实:技能库覆盖范围]`，并列出已找到的条目 |
| 技能描述存在歧义 | 输出 `[需核实:技能版本]`，建议查阅原始文档 |

**示例**：
> 输入：“有没有处理数据的技能？”
> 输出：“请补充数据类型（如 CSV、JSON、数据库）和处理动作（如清洗、转换、分析）。当前匹配结果：`[需核实:任务类型]`”

## 五、错误码体系：常见问题与修正

| 错误码 | 含义 | 提示话术 | 修正步骤 |
|--------|------|---------|---------|
| `E1001` | 输入为空 | “未检测到有效输入，请提供任务描述或技能名称。” | 重新输入，包含至少一个动词+名词 |
| `E1002` | 匹配结果为零 | “未找到相关技能，请尝试更换关键词或查看技能目录。” | 使用更通用的词（如“文件”代替“PDF”） |
| `E1003` | 输入格式错误 | “输入格式不支持，请使用纯文本描述。” | 移除特殊字符或超长内容 |
| `E1004` | 索引未加载 | “技能库索引不可用，请检查宿主环境配置。” | 重启会话或重新加载技能库 |
