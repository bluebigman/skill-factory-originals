## 六、FAQ 反模式对照

### 6.1 常见坑与反模式

| 坑编号 | 常见错误 | 反模式示例 | 正确做法 |
|--------|---------|-----------|---------|
| F01 | 忽略通配符转义 | `rm *.txt` 在含空格目录中失效 | 使用 `rm -- *.txt` 或引号包裹 |
| F02 | 管道命令未处理错误 | `cmd \| grep error` 忽略非零退出码 | 添加 `set -o pipefail` 或检查 `$?` |
| F03 | 递归删除无确认 | `rm -rf /` 造成灾难 | 使用 `rm -rf --` 并确认路径 |
| F04 | 环境变量未导出 | `VAR=value command` 子进程不可见 | 使用 `export VAR=value` 后执行 |
| F05 | 路径含空格未引用 | `cd /my documents` 报错 | 使用 `cd "/my documents"` |
| F06 | 忽略退出码 | 命令失败但继续执行后续 | 使用 `&&` 或 `\|\|` 控制流程 |
| F07 | 硬编码绝对路径 | 脚本在迁移后失效 | 使用 `$(pwd)` 或相对路径 |

### 6.2 反模式对照表

| 反模式 | 问题 | 替代方案 |
|--------|------|---------|
| 一次性执行复杂管道 | 难以调试和维护 | 拆分为多步，逐步验证 |
| 直接使用 `>` 覆盖文件 | 可能误删数据 | 先备份或使用 `>>` 追加 |
| 忽略 stderr 输出 | 遗漏关键错误信息 | 使用 `2>&1` 合并输出 |
| 在脚本中使用别名 | 非交互环境不生效 | 直接使用完整命令 |
| 不检查命令是否存在 | 脚本在精简环境报错 | 使用 `command -v` 检查 |
