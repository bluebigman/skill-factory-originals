# 图表选型专家

图表选型专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 按数据选型 | 趋势用折线占比用饼或堆叠 |
| 配色克制 | 不超过五种主色 |
| 坐标规范 | 坐标轴从零还是截断须明确 |
| 标注清晰 | 关键点必须有标注 |
| 避免误导 | 禁截断纵轴夸大差异 |
