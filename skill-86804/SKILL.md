## 三、标准流程

### 3.1 前置条件

| 条件 | 要求 |
|------|------|
| 文件格式 | .csv / .xlsx / .xls / .tsv，文件大小 ≤ 50MB |
| 文件路径 | 提供绝对路径或相对路径，或直接拖拽文件到对话框 |
| 需求描述 | 至少说明“想解决什么问题”（如：去重、统一格式、合并） |
| 特殊要求 | 可选，如指定去重列、日期格式模板、输出文件名 |

### 3.2 执行步骤

#### 步骤 1：接收文件与需求

- 确认文件路径可访问，文件存在且非空
- 确认用户需求属于能力边界内（见第一节）
- 若需求不明确，输出以下提示并等待用户补充：

```
请补充以下信息：
1. 文件路径（或直接拖拽文件）
2. 需要解决的具体问题（如：日期格式不统一 / 有重复数据 / 需要合并多个表）
3. 特殊要求（可选，如指定列名、输出格式）
```

#### 步骤 2：文件预检

- 读取文件头部 5 行，探测分隔符（逗号、制表符、分号）
- 检测编码（UTF-8 / GBK / GB2312）
- 统计总行数、总列数
- 输出预检结果：

```
文件预检结果：
- 格式：CSV（逗号分隔）
- 编码：UTF-8
- 行数：1,234（含表头）
- 列数：8
- 列名：日期, 客户名称, 金额, 状态, ...
```

#### 步骤 3：执行清洗操作

根据用户需求，按以下顺序执行（可多选）：

| 操作 | 参数 | 示例 |
|------|------|------|
| 格式统一 | 指定列 + 目标格式 | `日期列 → YYYY-MM-DD` |
| 去重 | 指定列（默认全行） | `按客户名称去重，保留首条` |
| 合并 | 合并方式 + 关联键 | `纵向拼接 / 按ID横向关联` |
| 空值处理 | 填充值或删除行 | `金额列空值填充为 0` |

#### 步骤 4：生成校验报告

- 清洗前后行数对比
- 重复率变化
- 空值率变化
- 格式合规率（如日期格式是否全部达标）

#### 步骤 5：输出结果

- 生成清洗后的文件：`原文件名_cleaned.csv`（或 .xlsx）
- 生成校验报告：`原文件名_report.md`
- 输出文件路径与简要说明

### 3.3 输出规范

| 输出项 | 格式 | 说明 |
|--------|------|------|
| 清洗后文件 | CSV / XLSX | 与输入格式一致，或按用户要求 |
| 校验报告 | Markdown / CSV | 包含清洗前后对比统计 |
| 控制台摘要 | 文本 | 3-5 行总结关键操作与结果 |

## 六、FAQ 反模式

| 常见坑 | 反模式（错误做法） | 正确做法 |
|--------|-------------------|----------|
| 日期格式混乱 | 直接全部替换为同一种格式，不检查是否有异常值 | 先统计格式分布，对无法解析的标记 `[需核实]` |
| 去重 | 默认全行去重，导致业务上重复但全行不完全一致的数据残留 | 先确认业务上的唯一键，按指定列去重 |
| 合并表格 | 直接纵向拼接，不检查列名是否一致 | 先对比列名，不一致时提示用户确认映射关系 |
| 空值处理 | 一律填充为 0 或“无” | 先统计空值率，与用户确认填充策略 |
| 输出格式 | 默认输出 CSV，用户实际需要 Excel | 先询问输出格式偏好 |
