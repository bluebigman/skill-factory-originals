| 能力项 | 说明 | 输入要求 | 输出形式 |
|--------|------|----------|----------|
| 文献分类 | 按主题、方法、时间等维度对文献进行归类 | 至少 3 条文献记录（标题+摘要） | 分类清单表（含类别名、文献条目、归类依据） |
| 空白识别 | 基于分类结果推断研究缺口 | 分类完成后的文献集合 | 空白分析报告（含推断依据、置信度标注） |
| 大纲生成 | 依据分类与空白分析构建论文框架 | 分类结果 + 空白分析（可选） | 章节级大纲（含各节写作要点） |
| 文献清单输出 | 生成规范化参考文献列表 | 文献元数据（标题、作者、年份、来源） | Markdown 表格或标准引用格式文本 |

### 1.2 能力边界（不做的事）

- 不代替用户阅读全文：仅依据标题与摘要进行分析，不深入解读正文内容。
- 不生成完整论文正文：仅输出大纲与要点，不代写具体段落。
- 不验证文献真实性：不核实文献是否存在、数据是否准确。
- 不提供投稿建议：不推荐目标期刊、不评估录用概率。
- 不执行统计分析：不做元分析、不计算效应量。

### 1.3 适用对象

- 硕博研究生：需要快速梳理文献、确定研究定位。
- 科研新手：首次撰写综述或论文，需要结构化引导。
- 课题组成员：需要统一文献分类口径、共享研究框架。
- 学术写作者：已有文献基础，需要从资料到大纲的转化辅助。

## 三、标准工作流程

### 3.1 前置条件

| 条件项 | 要求 | 缺失时的处理 |
|--------|------|--------------|
| 文献数量 | 建议 3-20 篇 | 少于 3 篇：提示用户补充；多于 20 篇：分批处理 |
| 文献信息 | 至少包含标题；摘要可选但推荐提供 | 仅有标题时：分类置信度降低，输出中标注 [需核实:分类依据] |
| 分类维度 | 未指定时默认按主题分类 | 用户可随时指定新维度，重新分类 |

### 3.2 执行步骤（分步编号）

**步骤 1：文献信息整理**

接收用户提供的文献列表，逐条提取以下字段：

| 字段 | 必填 | 说明 |
|------|------|------|
| 标题 | 是 | 文献完整标题 |
| 作者 | 否 | 第一作者或全部作者 |
| 年份 | 否 | 发表年份 |
| 来源 | 否 | 期刊/会议/书籍名称 |
| 摘要 | 否 | 建议提供，用于分类判断 |
| DOI/链接 | 否 | 便于回溯 |

**步骤 2：分类维度确认**

- 若用户未指定维度，默认按「研究主题」分类。
- 可选维度：研究方法（实证/规范/混合）、理论框架、时间阶段、地域范围、研究对象。
- 输出分类结果时，每一条目附带「归类依据」说明。

**步骤 3：执行分类**

- 对每条文献，提取核心关键词与主题特征。
- 计算文献间相似度，形成聚类。
- 为每个类别命名，并列出成员文献。
- 若某文献可归入多个类别，输出时标注「[需核实:多归属]」，由用户裁定。

**步骤 4：空白分析（可选）**

- 统计各类别文献数量与时间分布。
- 识别文献密度低的子领域。
- 输出空白分析报告，包含：
  - 空白领域名称
  - 现有文献覆盖情况
  - 推断依据（基于数量/时间/方法维度）
  - 置信度标注（高/中/低）

**步骤 5：大纲生成（可选）**

- 基于分类结构映射论文章节。
- 每个章节包含：
  - 章节标题
  - 核心论点（1-2 句）
  - 建议引用文献（标注编号）
  - 写作要点（3-5 条）
- 大纲末尾附「创新点建议」，标注 [需用户确认]。

**步骤 6：输出规范**

所有输出遵循以下格式：

```
## 输出标题
（说明性文字，不超过 3 行）

### 分类结果 / 空白分析 / 论文大纲
（表格或列表形式呈现）

### 置信度说明
（列出所有 [需核实] 项及原因）

### 下一步建议
（2-3 条可执行建议）
```

## 四、置信度门控机制

### 4.1 占位符规则

当信息不足时，使用以下占位符，不编造内容：

| 占位符 | 含义 | 使用场景 |
|--------|------|----------|
| [需核实:字段] | 该字段信息缺失或不确定 | 文献年份未知、作者缺失 |
| [需核实:分类依据] | 分类判断缺乏足够信息支撑 | 仅有标题无摘要 |
| [需核实:多归属] | 文献可归入多个类别 | 交叉学科文献 |
| [需核实:空白真实性] | 空白推断缺乏领域知识佐证 | 仅凭文献数量推断 |
| [需用户确认] | AI 建议需用户决策 | 创新方向、章节调整 |

### 4.2 置信度分级

| 级别 | 定义 | 输出表现 |
|------|------|----------|
| 高 | 信息充分，判断依据明确 | 正常输出，无标注 |
| 中 | 信息基本充分，但存在少量不确定性 | 相关位置标注 [需核实] |
| 低 | 信息严重不足 | 输出占位符，并提示用户补充信息 |

### 4.3 禁止行为

- 不猜测缺失的年份、作者等元数据。
- 不虚构不存在的文献。
- 不基于单一维度断言研究空白存在。
