# 学术研究辅助 Skill 文档

## 一、能力边界（一页纸速查卡）

### 1.1 本 Skill 能做什么

| 序号 | 能力项 | 说明 |
|------|--------|------|
| 1 | 文献资料清洗 | 自动去除重复项、修正格式错乱、识别缺失字段 |
| 2 | 文献自动分类 | 基于标题与内容语义，将文献归入预设或自动生成的类别 |
| 3 | 子主题细分 | 对指定分类（如"机器学习"）进行二级主题拆解 |
| 4 | 论文框架生成 | 输出包含章节结构、占位符、写作提示的 Markdown 文档 |
| 5 | 参考文献列表生成 | 根据用户提供的引用格式偏好（如 APA、MLA、GB/T 7714）生成列表 |
| 6 | 多格式输入支持 | 支持粘贴文本、CSV、JSON、HTTP URL 四种输入方式 |

### 1.2 本 Skill 不能做什么

| 序号 | 限制项 | 说明 |
|------|--------|------|
| 1 | 不代写正文 | 不生成完整的论文段落或章节内容，仅提供框架与提示 |
| 2 | 不验证文献真实性 | 不核实文献是否存在、页码是否正确、作者是否真实 |
| 3 | 不提供学术判断 | 不评估文献质量、不推荐投稿期刊、不判断研究价值 |
| 4 | 不处理超过 50 条的批量数据 | 单次处理上限为 50 条文献记录 |
| 5 | 不进行深度语义分析 | 不执行情感分析、论点提取、研究趋势预测等高级 NLP 任务 |

### 1.3 适用对象

- 正在撰写学位论文（本科/硕士/博士）的研究生
- 需要系统整理文献的科研人员
- 准备期刊投稿的学者
- 需要快速搭建论文框架的写作新手

## 三、标准流程

### 3.1 前置条件

| 条件项 | 要求 |
|--------|------|
| 数据格式 | CSV（含 `title` 和 `content` 字段）、JSON（含嵌套结构）、纯文本、URL |
| 数据量 | ≤ 50 条（超出部分将被截断并提示） |
| 字段完整性 | `title` 为必填字段；`content` 缺失时自动标记为 `[需核实:缺少正文]` |
| 引用格式偏好 | 可选，若不提供则默认输出 GB/T 7714 格式 |

### 3.2 执行步骤

**步骤 1：数据输入**

将数据粘贴到对话中，或提供 CSV/JSON 文件路径，或提供 HTTP URL。

**步骤 2：数据清洗**

系统自动执行以下操作：
- 去除重复条目（基于 `title` 字段精确匹配）
- 修正明显的编码错误（如乱码字符）
- 识别并标记缺失字段

**步骤 3：自动分类**

系统根据 `content` 字段的语义特征，将文献归入以下默认分类之一：
- 理论框架
- 方法研究
- 实证分析
- 综述评论
- 其他（需人工确认）

**步骤 4：框架生成**

输出包含以下结构的 Markdown 文档：
- 分类统计表（各类别文献数量与占比）
- 每个分类下的文献列表（含标题、作者、年份、摘要占位符）
- 论文写作框架（含章节标题、段落提示、引用占位符）

**步骤 5：输出交付**

最终输出为一份完整的 Markdown 文档，包含：
- 文档头部（标题、生成日期、数据来源）
- 分类统计表
- 文献列表（按分类分组）
- 论文框架（含 `[需核实:...]` 占位符）
- 下一步建议

### 3.3 输出规范

| 输出项 | 格式要求 |
|--------|---------|
| 分类统计表 | Markdown 表格，含"分类名称 / 文献数量 / 占比"三列 |
| 文献条目 | 每行包含：编号、标题、作者、年份、来源类型 |
| 论文框架 | 使用 `#`、`##`、`###` 标题层级，含 `[需核实:...]` 占位符 |
| 参考文献列表 | 按用户指定格式生成，默认 GB/T 7714 |

当信息不足或无法确认时，系统使用以下占位符标记，**绝不编造**：
