# 报告撰写 结构搭建助手

数据与图表的表达规范 —— 给需要快速定位与处置「该领域」类问题的使用者：把模糊描述转成**归因清单 + 可执行动作**。

## 目录内容

| 文件 | 说明 |
|---|---|
| `SKILL.md` | 能力说明、规则与触发条件 |
| `scripts/main.py` | 可执行实现（含规则表与错误码） |
| `reproduce.py` | 可复现性验证脚本（校验内容未篡改） |
| `manifest.json` | 生成元数据与来源标注 |
| `merkle_root` | 内容 Merkle 根（防篡改比对） |
| `env_snapshot.json` | 生成时的环境快照 |
| `prev_hash` | 前一版本哈希（版本链） |
