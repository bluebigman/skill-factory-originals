# 数据迁移方案专家

数据迁移方案专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 只读演练 | 先在副本上演练完整流程 |
| 分批迁移 | 按业务单元分批而非一次全量 |
| 校验对账 | 迁移后逐表核对条数与合计 |
| 回退可行 | 保留回退窗口与回退脚本 |
| 窗口沟通 | 迁移窗口提前通知相关方 |
