## 三、标准工作流程

### 3.1 前置条件

| 条件项 | 要求 |
|--------|------|
| 文件格式 | .txt / .docx / .pdf（文本型，非扫描件） |
| 文件命名 | 建议使用"合同类型_当事人_日期"格式，如"租赁合同_张三_20250115" |
| 文件放置 | 将待审查文件放入当前工作目录 |
| 文本长度 | 单份合同建议不超过 2 万字（超出将分段处理） |

### 3.2 执行步骤

**第一步：输入确认**

确认待审查文件路径与格式，必要时先进行文本清洗（去除页眉页脚、水印文字等干扰信息）。

**第二步：要素提取**

从合同文本中提取以下核心要素：

| 要素字段 | 说明 | 缺失时处理 |
|----------|------|-----------|
| 当事人信息 | 甲方/乙方全称、统一社会信用代码/身份证号 | 标记为 [需核实:当事人信息] |
| 合同标的 | 交易对象或服务内容的具体描述 | 标记为 [需核实:合同标的] |
| 价款与支付 | 金额、币种、支付节点、支付方式 | 标记为 [需核实:价款条款] |
| 履行期限 | 合同生效日、终止日、关键时间节点 | 标记为 [需核实:履行期限] |
| 违约责任 | 违约情形、违约金计算方式、赔偿范围 | 标记为 [需核实:违约责任] |
| 争议解决 | 管辖法院/仲裁机构、适用法律 | 标记为 [需核实:争议解决] |

**第三步：风险扫描**

逐条检查合同条款，按以下维度进行风险评级：

| 风险等级 | 判定标准 | 示例 |
|----------|----------|------|
| 高风险（红色） | 可能导致重大经济损失或法律纠纷 | 违约金超过合同总额 30%、单方解除权不对等 |
| 中风险（橙色） | 可能引发争议或增加履约成本 | 付款条件模糊、验收标准不明确 |
| 低风险（黄色） | 存在瑕疵但不影响合同整体履行 | 表述不规范、标点错误、条款重复 |

**第四步：合规检查**

对照以下合规维度进行逐项检查：

- 合同主体资格（是否具备签约资格）
- 合同形式合规（是否需书面形式、是否需备案）
- 条款合法性（是否违反法律强制性规定）
- 行业特殊规范（如建设工程合同需符合《建筑法》要求）

- 条款位置：[条款编号/原文摘录]
- 风险描述：[具体风险说明]
- 修改建议：[可操作的修改方案]

### 中风险项
（同上格式）

### 低风险项
（同上格式）

## 三、合规检查结果
（逐项列出合规/不合规/待核实）

## 四、综合评估
（整体风险评级 + 谈判要点提示）
```

## 一、合同基本信息
| 要素 | 内容 |
|------|------|

| 乙方 | [需核实:乙方全称] |
| 合同标的 | 位于XX市XX路XX号的商铺租赁 |
| 价款 | 月租金 8000 元，押二付三 |
| 履行期限 | 2025年2月1日至2027年1月31日 |
| 违约责任 | 违约金为月租金的 300% |
| 争议解决 | 甲方所在地人民法院管辖 |

## 二、风险清单

### 高风险项
- **条款位置**：第十条 违约责任
- **原文摘录**："任何一方违约，应向对方支付月租金三倍的违约金"
- **风险描述**：违约金比例过高（超过合同总额的 30%），根据《民法典》第五百八十五条，可能被法院调减
- **修改建议**：建议调整为"违约金不超过合同总金额的 20%"，或改为"按实际损失赔偿，最高不超过月租金的 200%"

### 中风险项
- **条款位置**：第四条 付款方式
- **原文摘录**："押二付三"
- **风险描述**：押金比例较高（两个月租金），且付款周期较长（三个月一付），对承租方资金压力较大
- **修改建议**：可协商调整为"押一付三"或"押二付一"

## 三、合规检查结果
| 检查项 | 结果 | 说明 |
|--------|------|------|
| 合同主体资格 | 待核实 | 乙方信息缺失，需补充 |
| 形式合规 | 合规 | 书面形式，符合要求 |
| 条款合法性 | 部分不合规 | 违约金条款可能过高 |

## 四、综合评估
**整体风险评级**：中高风险

**谈判要点**：
1. 违约金比例是主要谈判焦点，建议争取调低
2. 乙方信息缺失需在签约前补齐
3. 押金和付款周期可协商调整
```
