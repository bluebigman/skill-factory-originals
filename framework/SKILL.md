## 三、标准流程

### 3.1 前置条件

| 条件 | 要求 | 检查方式 |
|------|------|----------|
| 输入文件 | 数据文件（CSV/JSON）与配置文件（YAML/JSON）位于同一目录 | `ls` 查看目录 |
| 命名规范 | 数据文件命名遵循 `{业务名}_{日期}.csv` 格式 | 目视检查 |
| 环境就绪 | 已安装 framework 且版本 ≥ 1.0.0 | `framework --version` |
| 自检通过 | 执行 `framework --selftest` 返回 `OK` | 命令行输出 |

### 3.2 执行步骤

#### 步骤 1：准备输入

1. 将所有待处理数据文件放入同一工作目录。
2. 确认数据文件命名符合 `{业务名}_{日期}.csv` 规范。
3. 编写或确认配置文件 `config.yaml`，至少包含：
   - `title`：页面标题
   - `data_source`：数据文件路径
   - `components`：组件列表（chart/table/filter）

**配置示例（config.yaml）：**
```yaml
title: "销售月度看板"
data_source: "sales_2026_07.csv"
components:
  - type: chart
    chart_type: bar
    x_field: "月份"
    y_field: "销售额"
  - type: filter
    field: "区域"
```

#### 步骤 2：试运行

1. 从全量数据中抽取 5~10 条记录作为样本文件 `sample.csv`。
2. 修改配置中的 `data_source` 指向样本文件。
3. 执行构建命令：
   ```bash
   framework build --config config.yaml --output ./dist_sample
   ```
4. 打开 `dist_sample/index.html`，核对：
   - 图表是否正常渲染
   - 字段名称与源数据一致
   - 筛选器是否生效

#### 步骤 3：批量执行

1. 将配置中的 `data_source` 改回全量数据文件。
2. 执行正式构建：
   ```bash
   framework build --config config.yaml --output ./dist
   ```
3. 构建完成后，将原始数据文件备份至 `./backup/` 目录：
   ```bash
   cp *.csv ./backup/
   ```

#### 步骤 4：校验结果

1. 随机抽取 3~5 个输出页面，打开检查。
2. 核对关键字段（如日期、数值）与源数据是否一致。
3. 确认所有交互组件（筛选、排序）功能正常。
4. 检查页面在不同浏览器（Chrome/Firefox/Edge）下显示一致。

### 3.3 输出规范

| 输出项 | 规范 |

| 目录结构 | `dist/` 下包含 `index.html` 及 `assets/` 子目录 |
