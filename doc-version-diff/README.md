# 文档版本比对专家

文档版本比对专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 差异分级 | 按实质改动/格式改动/笔误分级 |
| 位置明确 | 每处差异标章节与行号 |
| 忽略格式 | 先剥离格式再比对正文 |
| 批量汇总 | 多版本比对输出汇总表 |
| 确认机制 | 重大差异须由责任人确认后才合并 |
