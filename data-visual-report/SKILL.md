# 表格洞察 · 图表报告 · 数据解读

本 Skill 由 AI 辅助生成，仅供参考。它帮助你将零散表格数据转化为结构化的可视化分析报告，自动提炼趋势、占比与排行结论。

### 1.1 能做什么

| 能力项 | 说明 | 示例 |
|--------|------|------|
| 表格解析 | 从纯文本、图片、PDF 中提取表格结构 | 识别 CSV 文本、截图中的销售表 |
| 图表生成 | 根据数据特征自动选择折线图、柱状图、饼图 | 时间序列→折线图；类别占比→饼图 |

## 三、标准流程

### 3.1 前置条件

| 条件 | 要求 | 缺失时的处理 |
|------|------|--------------|
| 输入数据 | 至少包含 1 行表头 + 2 行数据 | 提示"数据不足，无法生成有效分析" |
| 数据格式 | 纯文本表格、图片、PDF 均可 | 图片需清晰可辨，PDF 需可复制文本 |
| 列类型 | 至少 1 列数值型数据 | 提示"未检测到数值列，无法进行量化分析" |

### 3.2 执行步骤（分步编号）

**Step 1：数据提取与清洗**

- 从输入中识别表格区域，提取行列结构
- 去除空行、重复行、明显异常值（如负数的年龄）
- 标准化列名（去除空格、特殊字符）

**Step 2：数据结构识别**

- 识别维度列（文本型）与度量列（数值型）
- 识别时间列（日期格式）与类别列（枚举值）
- 输出数据结构摘要，如：`[列名: 产品名称, 类型: 类别]`

**Step 3：图表类型匹配**

| 数据特征 | 推荐图表 | 适用场景 |
|----------|----------|----------|
| 时间序列（≥3 个时间点） | 折线图 | 趋势分析 |
| 类别 + 数值（≤8 个类别） | 柱状图 / 饼图 | 对比与占比 |
| 类别 + 数值（>8 个类别） | 柱状图（横向） | TopN 排行 |
| 两个数值列 | 散点图 | 相关性观察 |

**Step 4：结论生成**

- 计算关键指标：总和、平均值、最大值、最小值、环比变化率
- 识别显著特征：最大值/最小值、突变点、占比超过 50% 的类别
- 生成结论语句，每条结论附带数据支撑

**Step 5：报告组装**

- 按以下结构输出 Markdown 报告：
  1. 报告标题（自动生成，含数据主题）
  2. 数据概览（行数、列数、关键指标）
  3. 图表区（图表类型 + 数据表 + 图表说明）
  4. 结论区（每条结论独立编号，附数据依据）
  5. 附录（完整数据表）

### 3.3 输出规范

输出格式为 Markdown，包含以下必需部分：

```markdown
# [自动生成的报告标题]

## 数据概览
- 数据维度：X 行 × Y 列
- 关键指标：总和 / 平均值 / 峰值

## 图表分析

[图表描述文字，含数据表]

### 图表 2：[图表类型] - [分析维度]
[图表描述文字，含数据表]

## 核心结论
1. [结论 1]（依据：具体数据）
2. [结论 2]（依据：具体数据）
3. [结论 3]（依据：具体数据）

## 附录：完整数据表
| 列1 | 列2 | 列3 |
|-----|-----|-----|
| ... | ... | ... |
```

## 六、FAQ 反模式

### 6.1 常见坑与反模式对照

| 常见坑 | 反模式（错误做法） | 正确做法 |
|--------|-------------------|----------|
| 忽略数据质量 | 直接分析含大量空值的表格 | 先清洗数据，空值用 `[需核实]` 标记 |
| 图表类型误用 | 用饼图展示 20 个类别 | 超过 8 个类别改用横向柱状图 |
| 结论过度解读 | 从 3 个数据点推断长期趋势 | 明确标注"样本量有限，结论仅供参考" |
| 忽略单位差异 | 混用"元"和"万元"计算总和 | 统一单位后再计算，或标注单位差异 |
| 不验证输入 | 直接信任用户提供的"已清洗"数据 | 独立检查数据完整性，不依赖用户声明 |

### 6.2 反模式自查清单

- [ ] 是否在结论中附带了具体数据依据？
