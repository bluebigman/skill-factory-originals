## 三、标准流程

### 前置条件

- 输入内容为有效的 Markdown 格式文本（文件路径、URL 或直接粘贴）
- 若使用自定义主题，需提供合法的十六进制颜色值（如 `#FF6600`）
- 若需批量处理，确保目标目录内所有 `.md` 文件格式正确

### 执行步骤

1. **读取输入**：获取用户提供的 Markdown 内容（文件/URL/粘贴文本）。
2. **解析文档树**：识别所有 Markdown 元素，记录层级与属性。
   - 元素类型：标题、段落、列表、引用、代码块、表格、图片、分割线、行内样式。
3. **选择主题**：
   - 若用户指定主题名，从内置 6 套主题中匹配。
   - 若未指定，使用默认主题 `clean-light`。
   - 若提供自定义参数（如 `主色: #FF6600`），基于默认主题生成派生主题。
4. **生成 HTML**：
   - 遍历文档树，将每个元素映射为带内联样式的 HTML 标签。
   - 图片自动添加 `max-width:100%; height:auto;` 样式，保留原始 `alt` 文本。
   - 生成完整 HTML 骨架（`<html>`, `<head>`, `<body>`）。
5. **校验与输出**：
   - 检查 HTML 结构完整性，收集警告信息。
   - 输出 `.html` 文件（与源文件同名，扩展名替换）。
   - 输出处理报告：转换耗时、元素统计、警告列表。
   - 若存在 `[需核实:字段]` 占位，在报告中单独列出。

### 输出规范

| 输出项 | 格式要求 |
|--------|----------|
| HTML 文件 | 完整文档，含 `<html>`, `<head>`, `<body>` 结构 |
| 处理报告 | 文本形式，包含耗时、统计、警告列表 |
