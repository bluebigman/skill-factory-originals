# 可用性专家

可用性专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 任务脚本 | 给任务不给操作指引 |
| 出声思维 | 让玩家边操作边说出想法 |
| 五人起步 | 小样本即可暴露多数问题 |
| 记录卡点 | 记录卡点位置与情绪反应 |
| 改后复测 | 修改后必须复测 |
