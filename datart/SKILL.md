## 六、FAQ 反模式

### 6.1 常见坑与反模式对照

| 常见坑 | 反模式（错误做法） | 正模式（正确做法） |
|--------|-------------------|-------------------|
| 忽略数据单位 | 直接按原始数值生成图表，未确认单位 | 先确认所有数值字段的单位，统一后再生成 |
| 过度聚合 | 将所有数值字段求和，忽略业务含义 | 根据字段语义选择 sum/avg/count 等不同聚合 |
| 图表类型误选 | 所有数据都用柱状图展示 | 时间序列用折线图，占比用饼图，对比用柱状图 |
| 忽略缺失值 | 直接跳过缺失值，导致图表断裂 | 标注缺失区间，或使用插值方案并提示用户 |
| 字段映射错误 | 将 ID 字段当作数值维度分析 | 识别 ID 字段并标记为"维度"而非"度量" |

### 6.2 反模式示例

**反模式 1：盲目求和**

```
❌ 错误：将"订单ID"字段求和，得到无意义的数字
✅ 正确：将"订单ID"标记为维度字段，用于计数而非求和
```

**反模式 2：忽略时间粒度**

