## 三、标准流程：从输入到输出

### 3.1 前置条件

| 条件 | 要求 | 检查方式 |
|------|------|----------|
| 课程材料 | 至少提供讲义 PDF 或文本文件 | 文件可读，非空 |
| 材料格式 | PDF、TXT、Markdown 均可 | 能提取文本内容 |
| 视频材料（可选） | 提供视频时间戳或字幕文件 | 用于生成对照表 |
| 代码材料（可选） | 提供课程代码文件 | 用于添加注释 |

### 3.2 执行步骤

**步骤 1：材料接收与解析**

接收你提供的课程材料，识别材料类型（讲义/视频字幕/代码），提取文本内容。

```
输入示例：讲义文件 lecture1.pdf
处理：提取文本 → 按章节切分 → 标记关键段落
输出：结构化文本块列表
```

**步骤 2：知识点提取**

从文本块中提取以下类型的信息：

| 信息类型 | 提取规则 | 示例 |
|----------|----------|------|
| 核心概念 | 首次出现的术语及其定义 | "反向传播是一种计算梯度的算法" |
| 公式 | 数学表达式及其含义 | "损失函数 L = -Σ y log(ŷ)" |
| 架构描述 | 网络结构的文字描述 | "CNN 包含卷积层、池化层、全连接层" |
| 超参数 | 实验中使用的参数值 | "学习率 0.001，batch size 32" |
| 实验结论 | 实验结果与观察 | "增加层数后准确率提升 2%" |

**步骤 3：结构化笔记生成**

将提取的信息组织为以下结构：

```
# 第X讲：{主题名称}

## 核心概念
- 概念1：定义 + 关键点
- 概念2：定义 + 关键点

## 关键公式
- 公式1：表达式 + 变量说明 + 用途

## 网络架构
- 架构描述 + 关键组件说明

## 实验与结论
- 实验设置 + 结果 + 结论

## 与前后讲的联系
- 前置知识：{第X讲的概念}
- 后续应用：{第X讲的概念}
```

**步骤 4：复习卡生成**

基于步骤 3 的笔记，生成问答式复习卡：

```
卡片格式：
Q: {问题}
A: {答案}
TAG: {所属讲次} | {知识点类型}
```

生成规则：
- 每个核心概念生成 1-2 张卡片
- 每个公式生成 1 张卡片（问题为"写出{公式名}并说明各符号含义"）
- 每个架构生成 1 张卡片（问题为"描述{架构名}的结构与特点"）

**步骤 5：自测题生成**

为每讲生成 5-10 道自测题，题型分布：

| 题型 | 占比 | 示例 |
|------|------|------|
| 概念题 | 40% | "什么是梯度消失？" |
| 计算题 | 30% | "给定输入和权重，计算输出" |
| 应用题 | 30% | "如何用 Dropout 防止过拟合？" |

**步骤 6：输出汇总**

将所有输出整合为一份完整文档，包含：

1. 结构化笔记（按讲次组织）
2. 复习卡集合（按讲次组织）
3. 自测题及答案
4. 视频-讲义对照表（如提供视频材料）
5. 代码注释（如提供代码材料）

### 3.3 输出规范

| 输出项 | 格式要求 | 示例 |
|--------|----------|------|
| 笔记 | Markdown 格式，层级清晰 | `## 核心概念` 下的 `- 概念名：定义` |
| 复习卡 | 每张卡片独立成块 | `Q: ...` / `A: ...` / `TAG: ...` |
| 自测题 | 题目+答案+解析 | `1. 题目` / `答案：...` / `解析：...` |
