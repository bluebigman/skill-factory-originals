## 三、标准流程：从原始文本到学习产物

### 前置条件

- 已获取课程材料的合法文本副本（字幕文件、讲义 PDF 的文字层、或手动复制的幻灯片内容）。
- 文本已去除时间戳、演讲者姓名等噪声（如未去除，本 Skill 会自动过滤）。
- 明确告知需要哪种输出：`笔记`、`卡片`、或 `两者都要`。

### 执行步骤

1. **文本清洗与分段**
   - 去除时间戳行（如 `00:01:23,456 --> 00:01:25,789`）。
   - 去除重复的演讲者标签（如 `[Lecturer]`）。
   - 按课程章节标记（如 `Lecture 1`, `Lecture 2`）或主题转折点切分文本块。

2. **主题识别与层级构建**
   - 识别每个文本块的核心概念（如“卷积”、“反向传播”、“注意力机制”）。
   - 建立层级结构：`课程 → 章节 → 小节 → 概念`。
   - 每个概念提取三要素：**定义**（一句话）、**关键细节**（2-5 条）、**关联**（与其他概念的关系）。

3. **笔记生成（结构化 Markdown）**
   - 输出格式如下：
     ```markdown
     # [课程名] - [章节名]
     ## [小节名]
     ### 概念名
     - **定义**：...
     - **细节**：
       - ...
       - ...
     - **关联**：与 [其他概念] 的关系是...
     ```
   - 公式保留原样（如 `y = Wx + b`），不进行推导。
   - 架构图用 ASCII 或文字描述（如 `输入 → 卷积层 → 池化层 → 全连接层 → 输出`）。

4. **卡片生成（问答对）**
   - 从笔记中提取适合记忆的“知识点-答案”对。
   - 每张卡片包含：`问题`、`答案`、`章节来源`、`难度`（基础/进阶）。
   - 输出为 CSV（逗号分隔）或 JSON 数组，便于导入 Anki 等工具。

5. **质量校验**
   - 检查是否有未归属的文本块（无法识别主题的段落）。
   - 检查卡片问题是否过于宽泛（如“什么是深度学习？”）或过于琐碎（如“第 3 页讲了什么？”）。
   - 对不满足要求的内容，标记为 `[需核实:字段]` 并跳过。

### 输出规范

- **笔记文件**：`notes.md`，UTF-8 编码，Markdown 格式。
- **卡片文件**：`cards.csv` 或 `cards.json`，UTF-8 编码。
- **元信息**：在笔记文件头部附上来源说明（课程名、章节范围、处理时间）。
- **置信度标注**：对不确定的内容（如模糊的音频转写），在笔记中用 `[需核实:术语]` 标注，不猜测。

## 六、FAQ 反模式：常见坑与正确姿势

### 坑 1：把视频链接直接丢进来
- **反模式**：“帮我处理这个 YouTube 链接：https://...”
- **正确姿势**：先下载字幕文件（SRT/VTT）或手动复制讲义文字，再提交文本。
- **原因**：本 Skill 不访问网络，仅处理纯文本。

### 坑 2：要求生成“完美笔记”
- **反模式**：“生成一份涵盖所有细节的完美笔记，不能遗漏任何知识点。”
- **正确姿势**：“提取核心概念和关键细节，忽略重复的过渡语句。”
- **原因**：笔记的价值在于提炼，而非全文复述。追求“完美”会导致输出冗长且失去重点。

### 坑 3：期望卡片包含所有公式推导
- **反模式**：“把反向传播的每一步数学推导都做成卡片。”
- **正确姿势**：“把反向传播的核心公式和计算步骤做成卡片，推导过程保留在笔记中。”
- **原因**：记忆卡片适合短问答，不适合长推导。长推导应放在笔记中。

### 坑 4：忽略置信度标注
- **反模式**：“直接输出结果，不要加任何 [需核实] 标记，我看着烦。”
- **正确姿势**：保留所有标注，并对照原课程核实。
- **原因**：标注是质量保障的一部分，删除标注等于隐藏不确定性。

### 坑 5：混入非课程内容
- **反模式**：“顺便把我在 Coursera 上学的课程也一起整理了吧。”
- **正确姿势**：仅提交 6.S191 相关材料。
- **原因**：本 Skill 的流程针对 6.S191 的课程结构优化，其他课程内容可能无法正确解析。
