## 三、标准工作流程

### 3.1 前置条件

| 条件 | 要求 | 检查方式 |
|------|------|----------|
| 字幕文件 | 格式为 .srt / .vtt / .txt，编码 UTF-8 | 文件可正常打开，无乱码 |
| 内容完整性 | 单讲字幕 ≥ 500 字，包含课程核心段落 | 粗略浏览确认 |
| 课程范围 | 明确告知是第几讲或哪一主题 | 用户主动说明 |

### 3.2 执行步骤（分步编号）

**流程 A：生成结构化笔记**

1. 接收用户粘贴的字幕文本或文件路径
2. 识别课程主题与章节边界（依据时间戳或内容转折）
3. 提取核心概念、关键公式、架构描述
4. 按以下模板组织输出：

```markdown
# 第 X 讲：{主题名称}

## 核心概念
- {概念1}：{一句话定义}
- {概念2}：{一句话定义}

## 关键公式
- {公式名称}：{公式描述，用文字表述}

## 架构与流程
{用文字描述网络结构或算法流程}

## 应用案例
{课程中提到的实际应用}

## 术语表
| 术语 | 定义 |
|------|------|
| {术语} | {定义} |
```

5. 输出完整笔记文件，命名格式：`notes_lecture{编号}.md`

**流程 B：生成记忆卡片**

1. 确认已有结构化笔记（若没有，先执行流程 A）
2. 从笔记中提取可考核的知识点（概念定义、公式含义、架构特点）
3. 生成 Q&A 格式卡片，每讲 15-30 张
4. 输出 CSV 文件（适配 Anki 导入），格式：

```csv
问题,答案,标签
"什么是反向传播？","一种计算梯度的算法，通过链式法则从输出层向输入层传播误差。","lecture1;基础"
```

**流程 C：构建概念图谱**

1. 收集 ≥3 讲的结构化笔记
2. 提取概念间引用关系（如"CNN 依赖卷积操作"）
3. 输出层级列表：

```markdown
# 概念图谱

## 第 1 层：基础理论
- 神经网络基础
  - 感知机
  - 激活函数
- 优化方法
  - 梯度下降
  - 反向传播

## 第 2 层：核心架构
- CNN
  - 卷积层
  - 池化层
- RNN
  - LSTM
  - GRU
```
