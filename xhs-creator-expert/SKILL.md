### 前置条件

- 用户需提供至少一项：**产品名称** 或 **明确主题**
- 可选补充信息（越详细，置信度越高）：

  - 目标人群（如"学生党""宝妈"）
  - 价格区间
  - 使用场景（如"通勤""约会"）
  - 期望语气（活泼/专业/文艺）

### 执行步骤（分步编号）

1. **解析输入**：识别产品名/主题、卖点、人群、场景等关键要素
2. **信息补全判断**：
   - 若缺少核心卖点 → 输出时标注 `[需核实:核心卖点]`
   - 若缺少目标人群 → 默认按「泛人群」处理，并标注 `[需核实:目标人群]`
3. **生成标题**（3个备选）：
   - 格式：情绪词 + 产品名 + 效果/场景
   - 示例：`通勤15天，这双鞋让我扔掉所有高跟鞋👠`
4. **生成正文**（150-300字）：
   - 结构：痛点引入 → 产品出现 → 使用体验 → 效果反馈 → 购买建议
   - 语气：第一人称，口语化，适度使用 emoji
5. **生成话题标签**（5-8个）：
   - 组合：品牌词 + 品类词 + 场景词 + 人群词 + 热门词
6. **生成配图建议**（3-5条）：
   - 场景图、细节图、对比图、使用过程图、效果图
7. **置信度标注**：检查所有推断内容，不足处添加 `[需核实:字段]`
8. **输出与自查**：
   - 字段完整性：标题/正文/标签/配图建议是否齐全
   - 格式正确性：是否符合四段式结构
   - 置信度标注：是否有遗漏的推断项
