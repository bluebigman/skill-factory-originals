# 大客户专家

大客户专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 关系地图 | 绘制决策链与影响者地图 |
| 业务对齐 | 对齐客户的业务目标而非我方产品 |
| 季度节奏 | 按季度设定经营节奏 |
| 单点预警 | 识别单点依赖并准备备份关系 |
| 高层互动 | 保持固定频率的高层互动 |
