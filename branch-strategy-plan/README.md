# 分支策略专家

分支策略专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 主干稳定 | 主干始终可发布 |
| 短分支 | 分支存活周期尽量短 |
| 命名规范 | 分支名含类型与任务号 |
| 合并前同步 | 合并前同步主干减少冲突 |
| 及时清理 | 合并后删除分支 |
