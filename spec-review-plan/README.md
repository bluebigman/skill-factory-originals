# 方案评审把关专家

方案评审把关专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 先共识标准 | 评审前统一通过标准 |
| 按风险排序 | 高风险项先评审 |

| 限时评审 | 单次不超一小时防疲劳 |
