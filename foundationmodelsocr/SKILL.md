### 1.1 能做什么

| 能力项 | 说明 | 示例 |
|--------|------|------|
| 单文件识别 | 对一张票据或一个PDF文件执行OCR并抽取字段 | `python ocr_skill.py --input ./input/doc_001.pdf --output ./output/` |
| 批量处理 | 对输入目录下所有文件批量执行识别 | `python ocr_skill.py --input ./input/ --output ./output/ --batch` |
| 结构化输出 | 输出JSON格式，包含字段名、字段值、置信度 | `{"amount": {"value": "100.00", "confidence": 0.95}}` |
| 置信度标注 | 每个字段附带0~1之间的置信度分数 | 低于0.8的字段需人工复核 |
| 汇总报告 | 批量任务结束后生成 `summary.json` 汇总所有文件识别情况 | 含文件数、成功率、平均置信度 |


## 四、置信度门控机制

### 4.1 置信度阈值说明

| 置信度区间 | 处理建议 |
|------------|----------|
| 0.9 ~ 1.0 | 可直接使用，无需复核 |
| 0.8 ~ 0.9 | 建议抽查，可批量使用 |
| 0.6 ~ 0.8 | 必须人工复核 |
| < 0.6 | 视为不可信，需重新扫描或手动录入 |

### 4.2 信息不足时的处理

当模型无法从图片中提取到某个字段时，**不编造数据**，输出：

```json
{
  "amount": {"value": "[需核实:amount]", "confidence": 0.0}
}
```

占位符格式：`[需核实:字段名]`

### 4.3 人工复核SOP

1. 从输出中筛选 `confidence < 0.8` 的字段
2. 打开源文件，人工读取对应字段值
3. 在输出JSON中手动修正 `value`，并将 `confidence` 改为 `1.0`（人工确认）
4. 在 `summary.json` 中记录复核状态
