# 文件读写专家

文件读写专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 格式先判 | 先识别 docx/xlsx/pptx 再选读写路径 |
| 结构保留 | 读写时保留样式与层级 |
| 批处理分批 | 大文件分批读写防内存溢出 |
| 写完复核 | 写后重读关键字段确认 |
| 模板优先 | 同类任务先套模板再填充 |
