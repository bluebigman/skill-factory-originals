# 跨境收款专家

跨境收款专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 通道合规 | 先确认通道与主体资质合规 |
| 费用透明 | 核对费率、到账周期与中间行费用 |
| 汇率口径 | 约定汇率取值时点并写入合同 |
| 退款路径 | 明确退款与拒付的处理流程 |
| 对账周期 | 固定对账周期与差异处理 |
