# 需求挖掘专家

需求挖掘专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 顺序提问 | 按现状、问题、影响的顺序展开 |
| 开放为主 | 少用是非题获取信息 |
| 复述确认 | 复述对方原话确认理解 |
| 不早报价 | 需求未明前不报价 |
| 记录原话 | 原话逐条记录用于复盘 |
