## 四、置信度门控

### 4.1 置信度等级定义

| 等级 | 含义 | 判定标准 |
|------|------|----------|
| `high` | 确信无误 | 字段值符合预期格式，且无歧义 |
| `medium` | 可能有误 | 字段值格式正确但存在多种解释，或源数据有轻微噪声 |
| `low` | 存疑 | 字段值缺失、格式异常、或与上下文矛盾 |

### 4.2 信息不足时的处理

当信息不足时，**不编造数据**，输出 `[需核实:字段名]` 占位符。

```json
{
  "name": "张三",
  "age": "[需核实:age]",
  "city": "北京",
  "confidence": {
    "name": "high",
    "age": "low",
    "city": "high"
  }
}
```

### 4.3 置信度调整规则

| 场景 | 调整动作 |
|------|----------|
| 字段值包含明显噪声（如多余空格、乱码） | 降为 `medium` |
| 字段值缺失 | 降为 `low`，并输出占位符 |
| 字段值格式与预期不符但可推断 | 降为 `medium`，并在元信息中记录推断依据 |
| 字段值完全无法解析 | 降为 `low`，输出占位符 |
