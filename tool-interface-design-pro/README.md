# 工具设计专家

工具设计专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 字段类型 | 每字段显式声明类型与取值域 |
| 必填标注 | 列出全部必填并给错误码 |
| 默认值 | 默认值必须写进 schema |
| 描述充分 | docstring 要够不看源码也能调用 |
| 场景示例 | 至少给 3 个什么时候用 |
