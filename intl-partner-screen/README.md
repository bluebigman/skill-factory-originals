# 海外伙伴专家

海外伙伴专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 资质核验 | 核验注册信息与经营资质 |
| 案例验证 | 要求提供可联系的过往案例 |
| 经营佐证 | 要求提供基本经营与履约证明 |
| 小额试单 | 先小额试单验证履约 |
| 退出条款 | 合同设明确退出与违约责任 |
