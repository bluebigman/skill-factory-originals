# 全球定价专家

全球定价专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 成本加成 | 先算落地成本再谈定价 |
| 竞品锚定 | 参考当地竞品价格带 |
| 购买力分层 | 按区域购买力分层定价 |
| 价位习惯 | 注意当地价格尾数与心理价位习惯 |
| 定期复核 | 汇率与关税变动后复核价格 |
