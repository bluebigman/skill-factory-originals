## 四、置信度门控

### 4.1 置信度等级定义

| 等级 | 含义 | 处理方式 |
|------|------|----------|
| `high` | 模式匹配完全命中，无歧义 | 直接使用 |
| `medium` | 模式匹配部分命中，存在合理推断 | 可接受，但建议抽查 |
| `low` | 模式匹配失败，基于上下文猜测 | 必须人工确认 |

### 4.2 门控规则

| 规则编号 | 规则内容 | 触发条件 | 处理动作 |
|----------|----------|----------|----------|
| R1 | 字段置信度上限 | 某字段为 `low` | 该条记录整体置信度上限降为 `medium` |
| R2 | 低置信度字段数量阈值 | 单条记录中 `low` 字段 > 3 个 | 整条记录标记为 `needs_review` |
| R3 | 分流输出 | 记录被标记为 `needs_review` | 单独输出至 `review_queue.csv`，不混入主结果 |

### 4.3 信息不足时的处理

当输入数据不足以确定字段值时：

1. 在输出字段中填入 `[需核实:字段名]` 占位符
2. 该字段置信度标记为 `low`
3. 该记录进入 `review_queue.csv`

**禁止行为**：不得编造数据、不得用默认值填充、不得跳过该字段。

## 八、高级用法

### 8.1 自定义 Schema 示例

```json
{
  "fields": [
    {"name": "order_id", "type": "string", "pattern": "^ORD-\\d{6}$"},
    {"name": "customer_name", "type": "string", "required": true},
    {"name": "order_date", "type": "date", "format": "%Y-%m-%d"},
    {"name": "total_amount", "type": "number", "min": 0, "max": 1000000}
  ],
  "rules": {
    "string_trim": true,
    "date_normalize": "ISO8601"
  }
}
```

### 8.2 自定义转换规则示例

```json
{
  "date_formats": ["%Y/%m/%d", "%d-%m-%Y", "%Y年%m月%d日"],

    "remove_extra_spaces": true,
    "strip_special_chars": ["#", "*", "~"]
  },
  "number_format": {
    "thousand_separator": ",",
    "decimal_places": 2
  }
}
```

```python
import json

with open('validation_report.json') as f:
```
