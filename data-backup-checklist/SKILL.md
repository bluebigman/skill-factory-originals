# 备份核验与风险预警 Skill 文档

## 一、能力边界速查卡

### 能做什么
- 解析备份清单文本、日志或粘贴内容，抽取关键字段（时间、大小、位置、类型）。
- 输出结构化结果：Markdown 表格、JSON、自定义分隔符文本。
- 对比不同批次备份的版本差异，标记缺失、重复或异常条目。
- 模拟恢复演练逻辑，输出可恢复性评分（不实际执行恢复操作）。
- 生成风险预警报告，按严重程度分级（提示 / 警告 / 严重 / 致命）。
- 处理批量输入，支持一次分析多组备份记录。
- 对不确定字段标注 `[需核实:字段名]`，不做臆测填充。
- 提供字段完整性自查与改进建议。

### 不能做什么
- 不连接真实存储系统，不读取实际文件内容。
- 不执行真正的数据恢复操作，仅做逻辑推演。
- 不校验文件哈希或内容真实性，只基于提供的信息判断。
- 不替代专业备份软件或运维人员的决策。

### 适用对象
- 运维工程师：日常备份巡检。
- 数据管理员：定期核对备份策略执行情况。
- 审计人员：检查备份合规性。
- 个人用户：验证个人重要文件备份是否完整。

## 三、标准处理流程

### 前置条件
- 输入内容须包含以下至少两项字段，否则无法有效处理：
  - 备份时间（日期/时间戳）
  - 文件大小（字节/ KB / MB / GB）
  - 存储位置（路径/ 标签）
  - 备份类型（全量/增量/差异）

### 执行步骤（编号）

1. **收集输入并确认格式**
   - 接受文本粘贴、文件路径指向的文本内容、或日志片段。
   - 若输入为空或格式不明，返回错误码 `E1001` 并附示例格式。

2. **解析关键字段**
   - 使用正则与关键词匹配提取以下信息：
     | 字段 | 识别规则 |
     |------|----------|
     | 备份时间 | 匹配 `YYYY-MM-DD`、`YYYYMMDD`、`HH:MM` 等模式 |
     | 文件大小 | 匹配数字+单位（B/KB/MB/GB/TB） |
     | 存储位置 | 识别路径（含 `/`、`\`）或标签（如"本地磁盘"、"S3"） |
     | 备份类型 | 关键词：全量/增量/差异/full/incremental/diff |
   - 未识别字段标记为 `[需核实:字段名]`。

3. **版本比对处理**
   - 按时间排序备份记录。
   - 检查连续性：若存在间隔（如 1 月 1 日、1 月 3 日，缺少 1 月 2 日），标记缺失。
   - 检查重复：相同时间+位置出现多条记录，标记为异常重复。
   - 检查大小异常：同一类型备份大小偏差超过 ±50% 时，标记为可疑。

4. **恢复演练评估**
   - 对每条备份记录打分（0-100）：
     - 有完整时间、大小、位置、类型 → 90-100 分
     - 缺一项字段 → 70-89 分
     - 缺两项字段 → 50-69 分
     - 缺三项以上 → 0-49 分
   - 输出可恢复性评级：良好（≥80）/ 一般（50-79）/ 较差（<50）。

5. **生成风险预警报告**
   - 分级标准：
     | 级别 | 触发条件 | 示例 |
     |------|----------|------|
     | 提示 | 字段缺失但可推断 | 大小缺失但时间存在 |
     | 警告 | 版本间隔超过 1 个周期 | 全量备份间隔 3 天 |
     | 严重 | 关键字段缺失或大小异常 | 无时间戳 / 大小偏差 80% |
     | 致命 | 连续 N 天无备份记录 | 连续 5 天无任何条目 |

6. **输出结果并自查**
   - 按用户指定格式输出（默认 Markdown 表格）。
   - 自查字段完整性、格式规范性、置信度标注是否齐全。

## 六、FAQ 与反模式

### 常见坑与正确做法

| 反模式 | 问题 | 正确做法 |
|--------|------|----------|
| 忽略缺失字段，直接猜值 | 导致分析结果失真 | 使用 `[需核实]` 标注，提示用户补充 |
| 将增量备份与全量备份混为一谈 | 版本连续性判断错误 | 区分类型，按类型分别比对连续性 |
| 只比对文件名，忽略时间戳 | 同名文件重复备份无法识别 | 结合时间+文件名双重判断 |
| 认为"没有错误"= "备份完整" | 忽略未检测到的风险 | 即使无明确错误，也输出最低级别的提示 |
| 一次处理超 100 条记录不分组 | 性能下降且易出错 | 建议分批处理，每批 50 条左右 |

### 边界情况处理
- 输入包含非备份内容（如普通文件列表）：过滤并提示"未识别为备份记录"。
- 时间格式混乱（如 2025/01/01 与 20250101 混用）：统一转换为 `YYYY-MM-DD` 格式。
- 大小单位混用（GB 与 GiB）：统一按十进制换算，标注换算说明。
