## 一、能力边界与适用对象

### 1.1 能做什么

| 能力项 | 说明 | 输入要求 |
|--------|------|----------|
| 笔记转卡片 | 将自由文本笔记拆分为独立的知识卡片 | UTF-8 编码的 `.md` / `.txt` 文件 |
| 卡片分类 | 自动识别卡片类型（概念、公式、问答、流程、清单） | 单文件建议 ≤ 5000 字 |
| 置信度标注 | 对信息完整度不足的卡片打标 `[需核实:字段]` | 无特殊要求 |

| 校验报告 | 输出 JSON 格式的校验结果，便于人工抽检 | 输出目录可写 |

### 1.2 不能做什么

- 不能理解图片、PDF 扫描件中的文字（仅支持纯文本）
- 不能自动修正原文中的事实错误
- 不能替代人工判断：低置信度卡片必须人工复核
- 不能跨目录递归处理（仅处理指定目录下的直接文件）

## 三、标准执行流程

### 3.1 前置条件

| 检查项 | 要求 | 失败处理 |
|--------|------|----------|
| 文件编码 | UTF-8（无 BOM） | 报错 E001 |
| 文件命名 | `主题_日期.md` 或 `主题_日期.txt` | 提示重命名（E002） |
| 输入路径 | 存在且可读 | 报错 E003 |
| 输出路径 | 可写或可创建 | 报错 E004 |

### 3.2 执行步骤

#### 步骤 1：环境自检

```bash
notewise --selftest
```

预期输出：

```
[OK] 环境就绪
[OK] 模板加载完成
[OK] 依赖组件可用
```

#### 步骤 2：单文件试运行

```bash
notewise --input ./notes/量子力学_20260820.md --output ./output/
```

核对输出文件中的以下字段：

| 字段名 | 类型 | 说明 |
|--------|------|------|
| `card_id` | string | 唯一标识，格式 `NW-YYYYMMDD-XXXX` |
| `card_type` | string | 枚举值：`concept` / `formula` / `qa` / `process` / `checklist` |
| `content` | string | 卡片正文（Markdown 格式） |
| `source_ref` | string | 来源文件路径 + 行号范围 |
| `confidence` | float | 0.0 ~ 1.0，低于 0.7 需人工复核 |

#### 步骤 3：批量执行

```bash
notewise --input ./notes/ --output ./output/ --batch
```

批量执行前自动创建 `./backup/` 目录，将原始文件复制备份。

#### 步骤 4：校验与报告

```bash
notewise --verify ./output/ --report ./output/verification.json
```

校验规则：

- 随机抽取 ≥ 10% 的卡片（至少 5 张）
- 核对 `source_ref` 指向的原文内容与 `content` 是否一致
- 检查 `confidence` 字段：低于 0.7 的卡片在报告中标记为 `[需核实:字段]`

### 3.3 输出规范

每张卡片输出为独立 `.md` 文件，命名规则：`{card_id}_{card_type}.md`。

文件内容结构：

```markdown
# {card_id}

> 类型：{card_type} | 来源：{source_ref} | 置信度：{confidence}

{content}

---

<!-- 生成时间：{timestamp} -->
```

## 四、置信度门控规则

当原始笔记信息不足以生成完整卡片时，**不编造内容**，按以下规则处理：

| 缺失信息 | 处理方式 | 输出示例 |
|----------|----------|----------|
| 定义不完整 | 保留已有部分，缺失处标注 | `[需核实:定义后半部分]` |
| 公式缺少变量说明 | 仅输出公式本身 | `[需核实:变量含义]` |
| 问答缺少答案 | 输出问题，答案留空 | `[需核实:答案]` |
| 流程步骤缺失 | 按已有步骤生成，标注缺失 | `[需核实:步骤3-5]` |

**门控阈值**：

- `confidence ≥ 0.7`：正常输出
- `0.5 ≤ confidence < 0.7`：输出卡片并标记 `[需核实]`
- `confidence < 0.5`：不生成卡片，在报告中列出原因
