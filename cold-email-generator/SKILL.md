# 冷邮件生成器（Cold Email Generator）

## 一、能力边界：能做什么，不能做什么

本 Skill 的核心任务：**将你提供的客户速查卡信息，转化为一封结构完整、语气得体的冷邮件草稿**。它解决的是「从零到一」的草稿生成问题，而非「从一到优」的最终定稿问题。

### 1.1 能做清单

| 能力项 | 说明 | 边界条件 |
|--------|------|----------|
| 单封邮件生成 | 根据 3-5 个必填字段生成一封完整邮件 | 必填字段缺失时拒绝生成 |
| 批量邮件生成 | 一次处理多份客户速查卡，逐封输出 | 每份速查卡独立校验，单份失败不影响其他 |
| 语气调节 | 支持 `formal`（正式）/ `semi`（半正式）/ `casual`（轻松）三档 | 默认 `semi` |
| 长度控制 | 支持 `short`（80-120词）/ `standard`（150-220词）/ `detailed`（250-350词） | 默认 `standard` |
| 置信度标注 | 信息不足时输出 `[需核实:字段名]` 占位符 | 不编造任何未提供的信息 |
| 主题行生成 | 每封邮件附带 2-3 个备选主题行 | 主题行长度不超过 60 字符 |

### 1.2 不能做清单

| 禁止事项 | 原因 |
|----------|------|
| 不能编造客户信息（如姓名、公司名、职位） | 违反置信度门控原则 |
| 不能生成虚假数据、案例、引用 | 违反事实性原则 |
| 不能保证邮件打开率、回复率 | 超出生成器能力范围 |
| 不能替代人工审阅 | 法律与合规要求 |
| 不能自动发送邮件 | 本 Skill 仅输出草稿 |
| 不能处理非速查卡格式的输入 | 输入格式约束 |

### 1.3 适用对象

- **新手用户**：第一次使用冷邮件，需要模板化引导
- **销售/商务人员**：需要批量生成客户开发信

**可选字段（补充越多，邮件越精准）：**

| 字段名 | 说明 | 示例 |
