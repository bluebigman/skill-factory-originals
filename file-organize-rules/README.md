# 文件归集整理专家

文件归集整理专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 先分类后移动 | 先出分类方案再动手 |
| 保留原路径 | 移动前记录原路径便于回滚 |
| 重名处理 | 重名加序号不覆盖 |
| 只增不删 | 整理只做移动与改名，删除须确认 |
| 整理报告 | 输出移动明细供核对 |
