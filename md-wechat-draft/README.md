# 转公众号专家

转公众号专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 先定主题 | 配色与字号先定一套再全文统一 |
| 段落短化 | 每段不超过三行，适配手机阅读 |
| 图片配文案 | 每图配一句说明，避免裸图 |
| 标题序号 | 小节用统一序号层级 |
| 预览必查 | 发布前逐段预览，检查代码块与表格 |
