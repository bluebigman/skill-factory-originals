# 文档水印管理专家

文档水印管理专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 分级水印 | 按密级设置不同水印 |
| 含溯源信息 | 水印含分发对象标识 |
| 不可轻易移除 | 水印与内容交织 |
| 位置合理 | 不遮挡关键内容 |
| 发放登记 | 记录水印与对应接收方 |
