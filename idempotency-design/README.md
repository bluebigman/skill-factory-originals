# 幂等设计专家

幂等设计专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 请求唯一键 | 客户端生成幂等键 |
| 结果缓存 | 同键返回首次结果 |
| 状态机 | 按状态判断是否可重复执行 |
| 并发控制 | 加锁或唯一约束防并发重复 |
| 过期清理 | 幂等键定期清理 |
