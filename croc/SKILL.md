# croc 技能手册：跨设备加密文件传输

## 一、能力边界速查卡

本技能围绕 `croc` 命令行工具展开，用于在任意两台电脑之间建立端到端加密的文件传输通道。

### 1.1 能做与不能做

| 维度 | 能做 | 不能做 |
|------|------|--------|
| 传输对象 | 单个文件、多个文件、整个目录 | 不处理传输内容的或解压 |
| 网络环境 | 支持 IPv4、IPv6、NAT 穿透场景 | 不保证在完全隔离的内网中自动工作 |
| 传输特性 | 端到端加密、断点续传、自动重连 | 不提供传输后的文件校验（需自行比对哈希） |
| 操作方式 | 命令行交互、通过 code 短语配对 | 不提供图形界面操作 |
| 辅助功能 | 自检（selftest）、版本查询 | 不提供文件管理、云存储或同步功能 |

### 1.2 适用对象

- 需要在两台自有设备之间快速传文件的个人用户。
- 需要临时向同事或合作伙伴发送较大文件的团队协作场景。
- 对传输隐私有要求，希望数据不经过第三方服务器的场景。

### 1.3 边界说明

- 传输速度受双方网络带宽和延迟影响，本技能不承诺任何速率指标。
- 断点续传依赖双方设备保持在线，若一端完全离线，续传无法触发。
- 文件大小无硬性上限，但超大文件（>10GB）建议预留充足磁盘空间。
