## 常见问题

**Q1：处理大量图片时速度较慢怎么办？**  
本 Skill 基于 macOS 原生 `sips` 工具，处理速度受图片分辨率与数量影响。建议分批处理（每批不超过 500 张），或先使用 `--dry-run` 验证参数正确性后再批量执行。

**Q2：HEIC 格式转换失败如何处理？**  
HEIC 转换依赖 macOS 系统框架，请确认系统版本为 macOS 10.13+。若仍失败，可先使用 `sips -s format jpeg` 手动测试单张图片是否可正常转换。

**Q3：压缩后图片质量不理想怎么办？**  
请检查 `--quality` 参数值是否过低（建议不低于 60），或改用 `--max-size` 按目标文件大小压缩。对于含文字的截图，建议使用 PNG 格式避免压缩失真。

**Q4：`--dry-run` 模式下没有输出结果？**  
请确认输入路径正确且包含图片文件。干跑模式仅输出预览信息，不会生成实际文件，请检查终端输出中是否有处理摘要信息。

**Q5：处理子目录时部分文件被跳过？**  
请确认跳过的文件是否为 RAW 格式（如 CR2、NEF）。本 Skill 仅支持 RAW 作为输入格式，不支持输出。另外，PDF 多页文件仅处理第一页。
