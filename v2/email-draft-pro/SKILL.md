## 三、标准流程：从输入到输出

### 前置条件

1. 用户需提供**至少 3 项核心信息**：收件人身份/关系、邮件目的、关键事实（时间/金额/事件）。

### 执行步骤（单封邮件）

1. **信息采集**：提取用户输入中的收件人、目的、关键事实、期望语气。缺失项标记为 `[需核实:字段]`。

3. **语气校准**：根据场景和用户指定，选择语气档位（1-5 级，见参数表）。
4. **结构搭建**：按标准邮件结构组织内容——称呼 → 开场白 → 主体（背景+行动点）→ 结束语 → 签名。
5. **语言渲染**：按用户指定语言输出（默认中文；英文需显式声明）。
6. **长度控制**：正文 ≤ 500 字（中文按字符计，英文按单词计）。
7. **质量评分**：对生成结果打分（0-100），评分维度见下文。
8. **输出交付**：输出邮件全文 + 评分 + 低于 70 分时的修改建议。

### 执行步骤（批量模式）

1. **数据校验**：检查输入数据条数 ≤ 100，字段完整度 ≥ 80%。
2. **模板识别**：从批量数据中识别共性场景（如"续费提醒"），提取公共模板。
3. **逐条渲染**：将每条数据的差异化字段（姓名、日期、金额等）填入模板。
4. **独立校验**：每条邮件独立评分，不因批量而降低标准。
5. **汇总输出**：输出全部邮件 + 批量评分报告（平均分、最低分、需人工复核的条目）。

### 输出规范

- 邮件正文 ≤ 500 字（单封）；批量每条 ≤ 500 字。
