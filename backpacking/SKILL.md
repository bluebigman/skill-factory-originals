# 背包行前规划与装备核查 Skill 文档

## 一、能力边界速查卡

本 Skill 面向户外背包旅行场景，帮助用户将零散的行前信息（如目的地、季节、天数、同行人数、特殊需求）转化为结构化的装备清单、路线核查表和风险提示。

### 能做（核心能力）

| 编号 | 能力项 | 说明 |
|------|--------|------|
| 1 | 输入解析 | 接受用户提供的文本描述、文件路径或 URL，提取目的地、季节、行程天数、人数、活动类型等关键字段 |
| 2 | 装备清单生成 | 根据行程特征生成分层装备清单（基础层、季节层、活动层、个人层） |
| 3 | 路线核查表 | 生成包含交通、补给点、紧急联络、天气窗口等要素的路线核查表 |
| 4 | 置信度标注 | 对推断出的字段（如季节、装备优先级）标注置信度，低置信度项以 `[需核实:字段名]` 占位 |
| 5 | 批量与自定义格式 | 支持一次处理多条行程记录，输出格式可指定为 Markdown 表格、CSV 或纯文本清单 |

### 不能做（明确边界）

- 不提供实时天气、路况或地质灾害预警（需用户自行查询官方渠道）
- 不替代专业户外领队或救援机构的现场判断
- 不生成地图或 GPS 轨迹文件
- 不评估用户个人体能或健康状况
- 不推荐具体品牌或购买链接

### 适用对象

- 计划进行 1-7 天背包徒步的入门与中级爱好者
- 需要快速整理行前信息的活动组织者
- 希望将散乱笔记转为标准清单的户外社团

## 三、标准执行流程

### 前置条件

- 用户需提供至少以下一项信息：目的地、行程天数、出行季节/月份
- 若信息缺失，本 Skill 会先输出 `[需核实:目的地]` 等占位符，并提示用户补充

### 执行步骤

1. **收集与确认输入**
   - 读取用户提供的文本、文件或 URL
   - 提取字段：目的地、天数、月份/季节、人数、活动类型（徒步/露营/攀岩等）、特殊需求（如摄影、钓鱼）
   - 若字段缺失，列出缺失项并请求补充

2. **解析与结构化**
   - 将输入映射到内部行程模型（TripProfile）
   - 字段表如下：

   | 字段名 | 类型 | 示例 | 必填 |
   |--------|------|------|------|
   | destination | string | "四姑娘山" | 是 |
   | days | int | 3 | 是 |
   | month | int | 7 | 否 |
   | party_size | int | 2 | 否 |
   | activity | enum | hiking/camping/climbing | 否 |
   | special_notes | string | "需携带相机" | 否 |

3. **生成装备清单**
   - 按以下分层逻辑生成：
     - **基础层**（所有行程必备）：背包、水具、头灯、急救包、多功能刀具、防晒、防雨
     - **季节层**（根据月份调整）：夏季→防暑/驱虫；冬季→保暖/防滑；雨季→防水袋/速干衣
     - **活动层**（根据活动类型）：露营→帐篷/睡袋/防潮垫；攀岩→安全带/头盔/快挂
     - **个人层**（根据特殊需求）：摄影→三脚架/备用电池；钓鱼→渔具包
   - 每项装备标注优先级：`P0`（必须）、`P1`（建议）、`P2`（可选）

4. **生成路线核查表**
   - 包含以下检查项：
     - 交通方式与到达时间窗口
     - 沿途补给点（水源、食物）
     - 紧急联络方式（当地救援、景区管理处）
     - 天气窗口（建议查询时间与备选方案）
     - 下撤路线标记

5. **输出与自查**
   - 按用户指定格式输出（默认 Markdown 表格）
   - 自查项：字段完整性、格式正确性、置信度标注是否齐全
   - 若存在低置信度推断（如季节推断），在输出末尾附注说明

### 输出规范

- **默认格式**：Markdown 表格，包含 `装备名称 | 优先级 | 数量 | 备注` 四列
- **路线核查表**：Markdown 列表，按 `[检查项]：状态` 格式
- **置信度标注**：低置信度字段以 `[需核实:字段名]` 形式保留在输出中，不编造数据
