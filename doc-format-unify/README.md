# 文档格式统一专家

文档格式统一专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 样式驱动 | 用样式表统一而非逐段改 |
| 标题层级 | 按大纲级别设标题不靠加粗 |
| 编号自动 | 用自动编号替代手打 |
| 页眉页脚 | 一次设置全文一致 |
| 终稿检查 | 用导航窗格逐级检查结构 |
