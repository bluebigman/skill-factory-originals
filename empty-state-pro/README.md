# 空状态专家

空状态专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 说明原因 | 说明为什么没有内容 |
| 给下一步 | 给出可执行的动作入口 |
| 区分场景 | 区分首次使用、无结果、加载失败 |
| 不甩锅 | 不把系统问题表达成用户错误 |
| 风格一致 | 与整体视觉语言一致 |
