# 配额守卫专家

配额守卫专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 全局唯一入口 | 同一资源只允许一个操作入口 |
| 并发锁 | 多实例并发必冲突须加锁 |
| 预算上限 | 预设调用与成本预算触顶即停 |
| 失败即停 | 失败也消耗配额时不得重试 |
| 来源盘点 | 动手前先盘清所有调用来源 |
