# 导航设计专家

导航设计专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 位置可见 | 始终显示当前位置 |
| 可回溯 | 任何页面可返回上级 |
| 常用前置 | 高频入口前置不埋深 |
| 命名一致 | 导航项与页面标题一致 |
| 深链可达 | 支持链接直达具体页面 |
