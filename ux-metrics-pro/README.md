# 体验度量专家

体验度量专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 分层指标 | 设北极星指标与过程指标 |
| 可归因 | 指标能归因到具体改动 |
| 防刷 | 设计防刷与防污染机制 |
| 口径固定 | 口径一旦确定不随改随换 |
| 定期复盘 | 定期看趋势而非单点值 |
