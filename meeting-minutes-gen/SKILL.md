### Step 3: 输出与校验
1. 将结果整理为约定格式输出

## 四、置信度门控（量化规则）

| 场景 | 加分/扣分 | 示例 |
|---|---|---|
| 明确关键词匹配（"决议"、"决定"、"同意"） | +10 分/处 | "会议决议：..." → 置信度提升 |
| 责任人+截止时间同时出现 | +15 分 | "张三负责，6月30日前完成" → 高置信度 |
| 仅责任人无截止时间 | +5 分 | "由李四跟进" → 中等置信度 |
| 模糊表述（"大概"、"可能"、"尽快"） | -10 分/处 | "可能下周完成" → 置信度降低 |
| 输入文本长度 <50 字 | -20 分 | 信息量不足，置信度大幅降低 |
| 多发言人交叉且无明确归属 | -15 分 | "A说...B说...（无主语）" → 置信度降低 |
| 责任人使用昵称或代称（如"老张"、"组长"） | -5 分/处 | 责任人映射不确定，置信度降低 |
| 截止时间使用相对表述（如"下周"、"月底"） | -8 分/处 | 时间解析不确定，置信度降低 |
| 输入文本包含明确发言人标注（如"张三："） | +5 分/处 | 归属明确，置信度提升 |
| 输入文本长度 >2000 字 | +5 分 | 信息量充足，置信度提升 |
| 输入文本包含英文缩写或专业术语 | -5 分/处 | 术语解析不确定，置信度降低 |
| 输入文本包含明确时间戳（如"[10:30]"） | +3 分/处 | 时间信息明确，置信度提升 |

**置信度分级输出：**
- ≥90%：直接输出，无标注
- 85%-90%：标注"建议复核"
- <85%：标注"[需核实]"，并说明不确定点

**置信度计算规则说明：**
- 基础分为 50 分，根据上表加减分项计算最终置信度
- 最终置信度 = max(0, min(100, 基础分 + 加分 - 扣分))
- 若输入文本包含复杂嵌套结构（如多层引用、括号嵌套），额外 -5 分（解析难度增加）
