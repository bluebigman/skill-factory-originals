## 三、标准处理流程

### 3.1 前置条件

| 条件项 | 要求 | 检查方法 |
|--------|------|----------|
| 输入图像存在 | 路径可访问，文件非空 | `os.path.exists()` 返回 True |
| 格式合规 | 扩展名在允许列表内 | 正则匹配 `\.(jpg\|png\|bmp)$` |
| 尺寸达标 | 最短边 ≥ 224 像素 | 用 PIL 读取后检查 `size` 属性 |
| 色彩空间 | RGB 三通道 | 检查 `mode == 'RGB'`，否则转换 |

### 3.2 执行步骤（分步编号）

**步骤 1：输入解析**

- 读取用户提供的路径或 URL，下载至临时目录
- 校验文件完整性（MD5 比对可选）
- 输出：标准化图像对象 + 元数据字典

**步骤 2：犬只检测**

- 使用目标检测模型（如 YOLO 系列）定位犬只区域
- 参数建议：`conf_threshold=0.5`，`iou_threshold=0.45`
- 输出：边界框坐标 `[x_min, y_min, x_max, y_max]`

**步骤 3：面部关键点定位**

- 检测眼部、鼻尖、耳根等 6 个关键点
- 用于后续对齐与裁剪
- 输出：关键点坐标数组

**步骤 4：品种分类**

- 将裁剪后的面部区域缩放至 224×224
- 输入分类网络（如 ResNet50 微调模型）
- 输出：Top-5 品种概率分布

**步骤 5：个体识别（可选）**

- 提取特征向量（512 维），与注册库比对
- 相似度阈值建议 0.75（余弦相似度）
- 输出：匹配 ID + 相似度分数

**步骤 6：结果封装**

- 组装 JSON 结构，标注置信度
- 写入输出文件或返回内存对象

## 四、置信度门控机制

### 4.1 置信度分级

| 置信度范围 | 级别 | 处理策略 |
|------------|------|----------|
| 0.90 ~ 1.00 | 高置信 | 直接输出结果，无需人工复核 |
| 0.70 ~ 0.89 | 中置信 | 输出结果并附加 `"needs_review": true` 标记 |
| 0.50 ~ 0.69 | 低置信 | 输出结果但建议人工确认，标注 `"uncertain": true` |
| < 0.50 | 不可靠 | 不输出分类结果，返回 `"breed": null` |

### 4.2 信息不足处理

当出现以下情况时，使用 `[需核实:字段名]` 占位符，禁止编造：

- 图像中无犬只 → `"breed": "[需核实:图像中未检测到犬只]"`
- 品种不在训练类别中 → `"breed": "[需核实:未知品种，可能为混种]"`
- 图像模糊无法判断 → `"confidence": "[需核实:图像质量不足，无法计算]"`

### 4.3 二次确认规则

当输出包含 `needs_review` 或 `uncertain` 标记时，流程自动暂停，向用户展示：

1. 原始图像缩略图
2. 检测到的边界框可视化
3. 当前分类结果与置信度
4. 询问用户是否接受结果或提供额外信息

## 六、FAQ 反模式对照

### 6.1 常见坑与正确做法

| 反模式（错误做法） | 问题 | 正确做法 |
|--------------------|------|----------|
| 直接使用未微调的 ImageNet 模型分类犬种 | 模型输出 1000 类通用物体，犬种细分精度极低 | 使用在犬种数据集（如 Stanford Dogs）上微调的模型 |
| 忽略图像中的多只犬只 | 只检测最大目标，漏掉其他犬只 | 设置 `max_detections=10`，输出所有检测框 |
| 置信度阈值固定为 0.9 | 对模糊图像过于严格，大量误拒 | 根据场景动态调整：清晰图像 0.9，模糊图像 0.7 |
| 批量处理时无错误隔离 | 单个文件出错导致整个任务崩溃 | 使用 try-except 包裹单文件处理，记录错误后继续 |
| 输出结果不保留原始图像引用 | 后续无法追溯结果来源 | 在 meta 字段中记录输入文件路径与哈希值 |

### 6.2 常见疑问解答

**Q1: 如何区分相似品种（如哈士奇与阿拉斯加）？**

A: 建议在分类层后增加细粒度特征提取模块，或使用度量学习（Metric Learning）训练嵌入空间，使相似品种的特征距离大于阈值。

**Q2: 处理时间如何优化？**

A: 三个方向：1) 使用轻量级骨干网络（MobileNetV3 替代 ResNet）；2) 检测阶段使用 TensorRT 加速；3) 批量推理时动态调整 batch size。

**Q3: 训练数据需要多少张图？**

A: 每个品种建议至少 500 张，覆盖不同角度、光照、背景。若数据不足，使用数据增强（随机裁剪、色彩抖动、水平翻转）扩充至 3~5 倍。
