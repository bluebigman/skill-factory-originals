# 设计系统专家

设计系统专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 令牌先行 | 先定义颜色与间距令牌 |
| 职责边界 | 明确每个组件的职责边界 |
| 状态齐全 | 覆盖默认/悬停/禁用/错误状态 |
| 文档同步 | 组件文档与代码同步更新 |
| 变更评审 | 组件变更走评审流程 |
