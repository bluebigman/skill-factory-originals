## 六、FAQ 反模式对照

### 6.1 常见坑与反模式

| 常见坑 | 反模式（错误做法） | 正模式（正确做法） |
|--------|-------------------|-------------------|
| 直接删除文件 | 生成 `rm -rf` 脚本且无确认机制 | 生成带 `--dry-run` 和回收站机制的脚本 |
| 忽略路径空格 | 使用未加引号的 `$VAR` 引用路径 | 使用 `"${VAR}"` 引用所有路径变量 |
| 无前置检查 | 脚本直接执行，不检查目录是否存在 | 脚本开头检查所有依赖路径和命令 |
| 硬编码路径 | 将 `/home/user/data` 直接写入脚本 | 使用变量 + 默认值 + 命令行参数覆盖 |
| 忽略错误处理 | 脚本中途失败后继续执行 | 使用 `set -euo pipefail` 并在关键步骤检查返回值 |

### 6.2 反模式示例

**反模式（错误）**：
```bash
rm -rf /tmp/test/*.tmp   # 无确认、无检查、无日志
```

**正模式（正确）**：
```bash
#!/usr/bin/env bash
set -euo pipefail

TARGET_DIR="${1:-/tmp/test}"
DRY_RUN="${DRY_RUN:-false}"

# 前置检查
if [ ! -d "$TARGET_DIR" ]; then
    echo "E007: 目录 $TARGET_DIR 不存在" >&2
    exit 1
fi

# 模拟执行
if [ "$DRY_RUN" = "true" ]; then
    find "$TARGET_DIR" -name "*.tmp" -mtime +7 -print
    echo "[DRY RUN] 共 $(find "$TARGET_DIR" -name '*.tmp' -mtime +7 | wc -l) 个文件将被删除"
    exit 0
fi

# 正式执行
find "$TARGET_DIR" -name "*.tmp" -mtime +7 -delete
echo "清理完成"
```
