本 Skill 将你散落在聊天记录、备忘录、网页截图里的行前信息，整合为一份可直接执行的 Markdown 文档。它不替你决定带什么，而是帮你把该想的都想全。

| 维度 | 能做 | 不能做 |

| 输出结构 | 固定章节：行程概览 → 背包清单 → 路线核查表 → 待核实项 | 不输出非 Markdown 格式（如 PDF、Excel） |

**适用对象**：周末单日徒步者、多日重装露营者、小型团队（2-8人）出行组织者。不适合：商业探险队、极地/高海拔（>5000m）特种作业。

- 输入满足上述最低要求（5项信息齐全）
- 若缺少数值型字段（天数/人数），默认天数=1，人数=1，并在输出中标注 `[需核实:天数]`

### 执行步骤

1. **信息解析**：提取输入中的目的地、月份、天数、人数、活动类型、路线信息
2. **环境推断**：根据月份+目的地推断温度区间、降水概率、日照时长（标注置信度）
3. **清单生成**：按四层结构生成背包清单（见下方分层说明）
4. **路线核查**：若提供路线信息，生成核查表（检查点、风险点、补给点）
5. **标注核实项**：所有推断字段标注 `[需核实:字段]`
6. **输出组装**：按固定章节顺序输出 Markdown

### 背包清单四层结构

| 层级 | 名称 | 内容 | 示例 |
|------|------|------|------|
| L1 | 生存层 | 保命必备，不可省略 | 急救包、头灯、哨子、防水火柴 |
| L2 | 舒适层 | 提升体验，按需增减 | 睡垫、炊具、换洗衣物 |
| L3 | 效率层 | 提升行动效率 | 登山杖、GPS设备、快干毛巾 |
| L4 | 个人层 | 因人而异，`--special` 扩展 | 相机、Kindle、药品、零食 |
