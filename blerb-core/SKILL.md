## 四、置信度门控

### 4.1 置信度规则

| 置信度范围 | 含义 | 处理方式 |
|-----------|------|----------|
| 0.9 - 1.0 | 高置信度，信息明确 | 直接输出 |
| 0.7 - 0.9 | 中置信度，存在轻微歧义 | 输出并附注说明 |
| 0.5 - 0.7 | 低置信度，信息不完整 | 输出并标注 `[需核实:字段名]` |
| 0 - 0.5 | 极低置信度，无法确认 | 输出 `[需核实:字段名]`，不猜测 |

### 4.2 占位符使用规范

当信息不足时，使用以下占位符，**绝不编造**：

```
[需核实:字段名]
```

示例：

```json
{
  "data": {
    "contract_amount": {
      "value": "[需核实:contract_amount]",
      "confidence": 0.3,
      "note": "原文中未找到明确金额表述"
    }
  }
}
```

### 4.3 边界值处理

| 场景 | 处理方式 |
|------|----------|
| 字段存在但格式异常 | 尝试修复，置信度降 0.1 |
| 字段存在但语义模糊 | 保留原文，置信度 ≤ 0.6 |
| 字段完全缺失 | 使用占位符，置信度 0 |
| 多个候选值冲突 | 取第一个，置信度 ≤ 0.5，附注说明 |
