# 区域划分专家

区域划分专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 潜力均衡 | 按市场潜力而非人数划分 |
| 规则稳定 | 划分规则年度内保持稳定 |
| 归属规则 | 明确交叉线索的归属规则 |
| 覆盖密度 | 评估覆盖密度并补盲区 |
| 数据调整 | 按数据定期小幅调整 |
