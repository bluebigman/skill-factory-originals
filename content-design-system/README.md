# 内容设计专家

内容设计专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 语气维度 | 定义正式度与温度等语气维度 |
| 正反例 | 每个场景给出正反示例 |
| 术语表 | 维护术语与标准写法 |
| 本地化预留 | 预留翻译带来的长度冗余 |
| 定期抽审 | 定期抽审线上文案 |
