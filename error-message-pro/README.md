# 错误提示专家

错误提示专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 不用错误码 | 错误码不能作为正文 |
| 说明原因 | 说明可能的原因 |
| 给出动作 | 给可执行的下一步 |
| 不丢数据 | 不得丢失用户已输入内容 |
| 分级呈现 | 按严重度差异化样式 |
