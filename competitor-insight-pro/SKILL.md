## 三、标准流程：前置条件 → 执行步骤 → 输出规范

### 3.1 前置条件

| 条件 | 要求 | 缺失时的处理 |
|------|------|--------------|
| 种子概念 | 至少一个明确的名词短语（2-6 字为宜） | 提示用户输入，不猜测 |
| 受众（可选） | 如"初学者""企业采购决策者" | 默认"大众读者" |
| 文章长度（可选） | 如"1500 字""3000 字" | 默认 2000 字 |
| 语气（可选） | 如"专业严谨""轻松口语" | 默认"专业务实" |

### 3.2 执行步骤（分步编号）

**步骤 1：输入确认与参数收集**

接收用户输入，解析种子概念及可选参数。示例：

```
输入：种子概念 = "智能手表"，受众 = "科技爱好者"，长度 = "2500 字"，语气 = "专业"
```

**步骤 2：关键词研究**

基于种子概念扩展关键词，按搜索意图分组：

| 意图类型 | 说明 | 示例（种子概念="智能手表"） |
|----------|------|------------------------------|
| 信息型 | 用户想了解知识 | 智能手表有什么用、智能手表怎么选 |
| 商业型 | 用户想比较后购买 | 智能手表品牌对比、智能手表性价比 |
| 导航型 | 用户想找特定网站/页面 | 某品牌智能手表官网、某平台智能手表专区 |

输出格式：分组列表，每组标注意图类型。

**步骤 3：大纲设计**

基于关键词研究结果，构建文章骨架：

```
# 智能手表选购指南（H1）
## 引言：为什么需要智能手表（H2）
## 智能手表的类型与分类（H2）
### 按操作系统分类（H3）
### 按功能定位分类（H3）
## 选购要点（H2）
### 续航与充电（H3）
### 健康监测准确性（H3）
### 生态兼容性（H3）
## 品牌对比（H2）
## 常见问题（H2）
## 结论（H2）
```

**步骤 4：正文撰写**

按大纲逐节生成内容，遵循以下规则：

- 每个 H2 段落 200-400 字
- 自然嵌入目标关键词（密度控制在 1%-3%）
- 使用短段落（3-5 行/段）和列表提升可读性
- 涉及数据、统计、引用时，使用 `[需核实:具体数据]` 占位

**步骤 5：标题与元描述生成**

生成 3 个标题候选 + 2 个元描述候选：

| 类型 | 要求 | 示例 |
|------|------|------|
| 标题候选 1 | 含核心关键词，≤30 字 | 智能手表怎么选？2026 年选购指南与避坑建议 |
| 标题候选 2 | 数字/列表型 | 智能手表选购 5 大要点：从续航到健康监测 |
| 标题候选 3 | 问题导向型 | 智能手表值得买吗？一文看懂优缺点与适用人群 |
| 元描述候选 1 | 150-160 字符，含关键词 | 智能手表选购指南：从续航、健康监测、生态兼容到品牌对比，一文理清选购思路，附常见问题解答。 |
| 元描述候选 2 | 150-160 字符，行动导向 | 还在纠结智能手表怎么选？本文覆盖类型解析、选购要点、品牌对比与 FAQ，帮你快速决策。 |

**步骤 6：自检报告**

| 检查项 | 通过标准 | 警告标准 | 失败标准 |
|--------|----------|----------|----------|
| 关键词覆盖 | 核心关键词出现 ≥5 次 | 出现 3-4 次 | 出现 <3 次 |
| 结构完整性 | 包含 H1/H2/H3 层级 | 缺少 H3 | 缺少 H2 |
| 占位符残留 | 无 `[需核实:...]` | 有 1-2 处 | 有 ≥3 处 |
| 段落长度 | 平均段落 3-5 行 | 平均段落 6-8 行 | 平均段落 >8 行 |
| 元描述长度 | 150-160 字符 | 140-149 或 161-170 | <140 或 >170 |

**步骤 7：输出与预览**

按以下顺序输出：

1. 关键词研究结果
2. 文章大纲
3. 完整正文（Markdown）
4. 标题与元描述候选
5. 自检报告

### 3.3 输出规范

所有输出使用 Markdown 格式，遵循以下规范：

- 标题层级：H1 仅一个，H2/H3 按需使用
- 列表：使用 `-` 无序列表，`1.` 有序列表
- 强调：使用 `**加粗**` 表示重点
- 代码块：使用 ``` 包裹
- 表格：使用 `|` 分隔

## 四、置信度门控：不编造原则

### 4.1 占位符规则

当以下信息缺失或不确定时，必须使用 `[需核实:字段]` 占位：

| 场景 | 占位示例 |
|------|----------|
| 具体统计数据 | `[需核实:2025年智能手表市场规模]` |
| 产品价格 | `[需核实:某品牌最新款价格]` |
| 法律法规引用 | `[需核实:相关法规条款]` |
| 技术参数 | `[需核实:某型号电池容量]` |
| 专家观点 | `[需核实:某专家关于该问题的观点]` |

### 4.2 占位符处理流程

1. 生成内容时，凡涉及上述场景，一律使用占位符
2. 输出自检报告时，列出所有占位符位置
3. 用户需在发布前替换所有占位符为真实信息
4. 未替换占位符的内容不得标记为"发布就绪"

### 4.3 禁止行为

- 禁止猜测数据并标注为事实
- 禁止虚构专家引用或研究结论
- 禁止在信息不足时给出确定性建议

## 六、FAQ 反模式：常见坑与对照

### 6.1 反模式 1：关键词堆砌

**错误做法**：
```
智能手表选购指南，智能手表推荐，智能手表品牌，智能手表价格，智能手表评测，智能手表排行榜...
```

**正确做法**：
```
智能手表怎么选？本文从续航、健康监测、生态兼容三个维度展开，并对比主流品牌，帮你找到合适的产品。
```

### 6.2 反模式 2：忽略搜索意图

**错误做法**：用户搜索"智能手表怎么用"，文章却全是"智能手表品牌对比"

**正确做法**：先识别意图类型（信息型/商业型/导航型），再匹配内容类型

### 6.3 反模式 3：标题与内容脱节

**错误做法**：标题写"2026 年智能手表排行榜"，正文却没有排名信息

**正确做法**：标题承诺什么，正文必须兑现什么

### 6.4 反模式 4：元描述超长被截断

**错误做法**：元描述 200 字，搜索引擎显示时被截断，关键信息丢失

**正确做法**：控制在 150-160 字符，核心关键词前置

### 6.5 反模式 5：忽略移动端阅读体验

**错误做法**：大段文字无分段，表格过宽超出屏幕

**正确做法**：短段落 + 响应式表格 + 适当使用列表
