#### 步骤4：Mask矫正

当检测到遮挡或污损时，自动执行mask矫正：

```bash
# 手动指定mask区域（像素坐标）

# 自动检测mask区域
```

矫正流程：
1. 定位mask区域（手动指定或自动检测）
2. 对mask区域进行图像修复（inpainting）
3. 重新识别修复后的区域
4. 对比两次识别结果，保留高置信度版本

## 四、置信度门控机制

### 4.1 置信度计算

每个字段的置信度由三个维度加权计算：

```
confidence = 0.5 * ocr_confidence + 0.3 * template_match_score + 0.2 * format_validation_score
```

| 维度 | 权重 | 说明 |
|------|------|------|
| OCR置信度 | 0.5 | OCR引擎对字符识别的置信度 |
| 模板匹配度 | 0.3 | 字段区域与模板定义的匹配程度 |
| 格式校验分 | 0.2 | 字段值是否符合预设格式（如日期格式、金额格式） |

### 4.2 门控阈值

| 阈值 | 行为 |
|------|------|
| ≥ 0.9 | 正常输出，标记为高置信度 |
| 0.7 - 0.9 | 输出并标记 `needs_review: true` |
| < 0.7 | 输出 `[需核实:字段名]`，不猜测值 |

### 4.3 二次确认流程

当出现以下情况时，系统会主动向用户确认：
1. 关键字段（金额、日期、单号）置信度 < 0.8
2. 同一字段多次识别结果不一致
3. 模板匹配失败，需用户选择模板

### 6.1 常见坑与解决方案

| 坑 | 反模式 | 正确做法 |
|----|--------|----------|
| 图片模糊 | 直接识别，结果全错 | 先预处理：增强对比度、锐化、去噪 |
| 倾斜票据 | 不矫正直接识别 | 使用`--auto-mask`或手动旋转后再识别 |
| 模板过时 | 继续使用旧模板 | 定期校验模板，更新字段位置 |
| 批量处理不检查 | 全量跑完才发现错误 | 先跑单个样本，确认无误再批量 |
| 忽略置信度 | 直接采信所有结果 | 对`needs_review`字段人工复核 |
| 覆盖原始文件 | 直接修改原图 | 保留原始文件，输出到独立目录 |
