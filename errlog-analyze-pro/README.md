# 错误日志分析专家

错误日志分析专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 时间对齐 | 先对齐各节点时间戳与时钟偏移 |
| 聚类去重 | 同类错误归并计数 |
| 首次出现 | 定位首次出现时间点 |
| 上下文窗口 | 取错误前后若干行看完整链路 |
| 关联变更 | 与最近发布或配置变更比对 |
