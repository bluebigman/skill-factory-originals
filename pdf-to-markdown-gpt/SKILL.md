### 3.2 执行步骤

**Step 1：输入确认**

- 确认用户提供的 PDF 文件路径或 URL
- 确认输出格式要求（默认标准 Markdown，可自定义）
- 确认是否需要批量处理

**Step 2：内容解析**

- 提取 PDF 文本层内容
- 识别文档结构（标题层级、段落、列表、表格、代码块）
- 提取元数据（标题、作者、日期等）

**Step 3：格式转换**

- 按以下规则将提取内容转为 Markdown：

| 源元素 | 转换规则 |
|--------|----------|
| 一级标题 | `# 标题文本` |
| 二级标题 | `## 标题文本` |
| 三级及以上 | 逐级对应 `###`、`####` |
| 有序列表 | `1. 项目` |
| 无序列表 | `- 项目` |
| 表格 | `\| 列1 \| 列2 \|` 格式 |
| 图片 | `![描述](占位路径)` |
| 代码块 | 用 ``` 包裹，标注语言类型（如可识别） |
| 链接 | `[链接文字](URL)` |

**Step 4：置信度标注**

- 对以下情况添加 `[需核实:字段名]` 标注：
  - OCR 识别置信度低于 85% 的文本
  - 表格结构推断不确定的单元格
  - 标题层级无法明确判断的段落
  - 元数据缺失或冲突

**Step 5：输出生成**

- 生成 Markdown 文件，文件名与源 PDF 同名（`.md` 后缀）
- 文件头部自动添加 YAML frontmatter：

```yaml

confidence: 0.92
---
```

**Step 6：自查校验**

- 检查字段完整性：标题、段落、列表、表格是否齐全
- 检查格式正确性：Markdown 语法是否合法
- 检查置信度标注：所有不确定项是否已标注
