# 智能体技能编排与指令扩展工具包（agent-toolkit）

## 一、能力边界速查卡

本工具包面向 **AI 编码智能体** 与 **自动化流水线**，提供技能包的声明、编排、依赖解析与执行日志输出能力。以下内容为“一页纸”边界说明，帮助你在 30 秒内判断是否适用。

| 维度 | 能做 | 不能做 |
|------|------|--------|
| 技能声明 | 解析 `--order` 参数，按逗号分隔得到技能序列 | 不支持 YAML/JSON 配置文件作为唯一输入源 |
| 依赖检查 | 检查每个技能的依赖是否满足（依赖技能必须已启用） | 不自动安装或下载缺失技能包 |
| 依赖修复 | 若依赖缺失，自动插入依赖技能到序列前部 | 不处理循环依赖（A→B→A） |
| 执行计划 | 生成执行计划并逐项执行，每步输出独立日志 | 不保证执行顺序的并发安全 |
| 参数查看 | 使用 `--detail` 查看每个技能的参数要求 | 不提供参数值的运行时校验 |
| 自定义配置 | 支持自定义技能配置参数（见 7.3 节） | 不支持热更新配置（需重启进程） |
| 集成扩展 | 可将编排命令封装为 shell 脚本，集成到 CI/CD | 不提供 GUI 界面或远程管理 API |

**适用对象**：需要将多个技能按序组合执行的 AI 编码智能体、需要将技能调用纳入自动化流水线的开发团队、希望统一管理技能依赖关系的个人开发者。

**不适用场景**：需要图形化编排界面的场景、需要跨进程共享技能状态的场景、需要动态加载未声明技能的场景。

## 三、标准执行流程

### 3.1 前置条件

| 条件 | 说明 | 检查方式 |
|------|------|---------|
| 技能包已安装 | 所有技能已注册到本地技能库 | `agent-toolkit --version` 确认版本号 |
| 依赖技能已启用 | 每个技能的依赖项在配置文件中标记为 `enabled: true` | 查看技能配置文件 |
| 参数格式正确 | `--order` 参数使用逗号分隔，无空格 | 直接目视检查 |
| 执行环境就绪 | 当前目录有读写权限，日志目录可创建 | `touch .write_test` 测试 |

### 3.2 执行步骤（分步编号）

**Step 1：解析技能序列**

```bash
agent-toolkit --order lint,test,build
```

解析规则：
- 按逗号（`,`）分隔，忽略首尾空格
- 空技能名（如 `lint,,test`）自动跳过并记录警告
- 重复技能名（如 `lint,lint`）只保留第一个，记录去重日志

**Step 2：依赖检查**

对序列中的每个技能，读取其声明文件（`skill.yaml` 或 `SKILL.md` frontmatter）中的 `dependencies` 字段：

```yaml
# 示例：test 技能的依赖声明
dependencies:
  - lint
  - mock-server
```

检查逻辑：
- 若依赖技能已在序列中 → 通过
- 若依赖技能未在序列中但已启用 → 插入到当前技能之前
- 若依赖技能未启用 → 报错并终止（错误码 `E-DEP-001`）

**Step 3：依赖自动插入**

假设输入 `--order test,build`，而 `test` 依赖 `lint` 和 `mock-server`：

```text
原始序列: [test, build]
插入后:   [lint, mock-server, test, build]
```

插入规则：
- 依赖技能按声明顺序插入
- 若依赖技能本身还有依赖，递归处理（深度优先）
- 插入位置为当前技能之前，不改变其他技能相对顺序

**Step 4：生成执行计划**

输出格式为结构化文本：

```text
执行计划（共 4 步）:
  [1/4] lint        — 代码风格检查
  [2/4] mock-server — 启动模拟服务
  [3/4] test        — 单元测试
  [4/4] build       — 构建产物
```

**Step 5：逐项执行并输出日志**

每步执行后输出独立日志文件，命名规则：`logs/{skill_name}_{timestamp}.log`。日志内容包含：

```text
[2025-01-15 10:23:45] [INFO] 开始执行技能: lint
[2025-01-15 10:23:46] [INFO] 参数: --config .eslintrc.json
[2025-01-15 10:23:48] [INFO] 执行完成，退出码: 0
[2025-01-15 10:23:48] [INFO] 输出摘要: 发现 3 个警告，0 个错误
```

### 3.3 输出规范

| 输出类型 | 格式 | 示例 |
|---------|------|------|
| 执行计划 | 文本列表，含序号和技能名 | `[1/4] lint — 代码风格检查` |
| 步骤日志 | 独立文件，含时间戳和级别 | `logs/lint_20250115_102345.log` |
| 最终报告 | 汇总所有步骤的退出码和耗时 | `全部 4 步执行完成，耗时 12.3s` |
| 错误输出 | 错误码 + 提示话术（见第五节） | `E-DEP-001: 依赖技能未启用` |

### 7.3 自定义技能配置参数

技能参数通过环境变量注入，命名规则：`SKILL_<技能名>_<参数名>`（技能名大写，连字符替换为下划线）。

**示例**：为 `test` 技能设置超时时间为 600 秒：

```bash
export SKILL_TEST_TIMEOUT=600
agent-toolkit --order test
```

**参数优先级**：环境变量 > 技能默认值 > 全局默认值。

**查看可用参数**：

```bash
agent-toolkit --detail test
```

输出示例：

```text

  参数名: timeout
  默认值: 300
  单位: 秒
  说明: 单次测试执行的最大时长
```
