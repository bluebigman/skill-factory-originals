## 三、标准操作流程

### 3.1 前置条件

在开始任何重命名操作前，请确认以下条件：

| 检查项 | 要求 | 验证方法 |
|--------|------|----------|
| 文件位置 | 待处理文件已集中存放 | 确认所有文件在同一目录或已列出完整路径 |
| 命名一致性 | 现有命名规则已确认 | 抽查 3-5 个文件，记录当前命名模式 |
| 操作权限 | 对目标目录有读写权限 | 尝试创建临时测试文件并删除 |
| 备份空间 | 有足够空间存放备份 | 确认磁盘剩余空间 ≥ 文件总大小的 1.2 倍 |
| 命名规则 | 目标命名规范已明确 | 参考下方命名模板设计章节 |

### 3.2 执行步骤

#### 第一步：收集文件清单

```bash
# 在目标目录下执行（示例）
ls -la > file_list.txt
# 或使用 find 命令递归列出
find /path/to/dir -type f > file_list.txt
```

记录以下信息：
- 文件完整路径
- 当前文件名
- 文件大小
- 修改日期

#### 第二步：设计命名规则

根据文件类型和使用场景，选择命名模板：

| 场景 | 推荐模板 | 示例 |
|------|----------|------|
| 日期归档 | `YYYYMMDD_描述.ext` | `20250115_项目报告.pdf` |
| 序号排列 | `序号_描述.ext` | `001_会议纪要.docx` |
| 分类命名 | `分类_子类_描述.ext` | `财务_发票_2024Q4.xlsx` |
| 版本管理 | `文件名_v版本号.ext` | `设计稿_v2.3.psd` |
| 混合模式 | `日期_分类_序号_描述.ext` | `20250115_合同_A_001_采购协议.pdf` |

**命名规则参数表：**

| 参数 | 格式 | 长度限制 | 示例 |
|------|------|----------|------|
| 日期 | YYYYMMDD | 8位 | 20250115 |
| 时间 | HHMMSS | 6位 | 143025 |
| 序号 | 001-999 | 3位起 | 007 |
| 分类 | 2-6个汉字 | 建议≤10字符 | 合同、发票、报告 |
| 描述 | 2-20个汉字 | 建议≤30字符 | 年度总结、客户提案 |
| 版本号 | v1.0.0 | 建议≤10字符 | v2.3.1 |

#### 第三步：单样本试运行

1. 选择 1 个代表性文件
2. 手动执行重命名操作
3. 核对以下字段：
   - 文件名格式是否符合预期
   - 扩展名是否保留
   - 文件是否可正常打开
   - 路径长度是否在系统限制内

**试运行检查表：**

```text
□ 文件名：符合命名模板
□ 扩展名：保持不变
□ 文件内容：可正常访问
□ 路径长度：≤ 255 字符（Windows）或 ≤ 1024 字符（Linux/macOS）
□ 特殊字符：无非法字符（\/:*?"<>|）
```

#### 第四步：批量执行

确认试运行无误后，按以下顺序操作：

1. **创建备份**：
   ```bash
   # 复制整个目录作为备份
   cp -r /source/dir /backup/dir_$(date +%Y%m%d)
   ```

2. **生成重命名映射表**：列出每个文件的旧名 → 新名对应关系

3. **执行批量操作**（示例脚本）：
   ```bash
   #!/bin/bash
   # rename_batch.sh - 批量重命名脚本示例
   while IFS=',' read -r old_name new_name; do
     if [ -f "$old_name" ]; then
       mv "$old_name" "$new_name"
       echo "已重命名: $old_name → $new_name"
     else
       echo "[需核实:文件不存在] $old_name"
     fi
   done < rename_map.csv
   ```

4. **记录操作日志**：保存重命名前后对照表，便于回溯

#### 第五步：结果校验

批量执行后，按以下比例抽查：

| 文件总数 | 抽查数量 | 校验重点 |
|----------|----------|----------|
| 1-10 | 全部 | 逐一核对 |
| 11-100 | 10-20% | 随机抽样 + 首尾各1个 |
| 101-1000 | 5-10% | 分层抽样（按目录/类型） |
| 1000+ | 2-5% | 按批次抽样 + 程序化校验 |

**校验内容：**
- 文件名与映射表一致
- 文件可正常打开

- 无意外丢失文件
