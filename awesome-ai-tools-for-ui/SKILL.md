# awesome-ai-tools-for-ui 技能文档

## 一、能力边界速查卡

本技能用于整理和输出 AI 辅助 UI/UX 设计的工具清单。它不是一个自动搜索工具，也不是设计工具本身，而是一个**信息整理与格式化输出器**。

### 能做（核心能力）

| 编号 | 能力项 | 说明 |
|------|--------|------|
| 1 | 数据转结构化 | 将用户提供的工具名称、链接、描述等原始信息，整理为统一格式的清单 |
| 2 | 关键信息识别 | 从杂乱的输入中提取工具名称、适用场景、核心功能、价格模式等关键字段 |
| 3 | 格式约定输出 | 按预定义的 Markdown 表格或列表结构输出结果 |
| 4 | 置信度标注 | 对无法确认的信息（如价格、开源状态）标注 `[需核实:字段名]` 占位符 |
| 5 | 批量与自定义 | 支持一次处理多个工具条目，并允许用户指定输出字段顺序或筛选条件 |

### 不能做（明确边界）

- 不实时抓取互联网数据，仅处理用户提供的内容
- 不评价工具优劣，只做客观信息整理
- 不生成设计建议或代码
- 不保证信息的时效性（价格、功能可能已变更）

### 适用对象

- 需要快速整理 AI 设计工具清单的产品经理、UI/UX 设计师
- 需要将零散工具信息格式化的技术写作者
- 需要批量整理工具对比表的团队负责人
