# 内容改写与降重处理 Skill 文档

## 一、能力边界（一页纸速查卡）

### 1.1 能做与不能做

| 维度 | 能做 ✅ | 不能做 ❌ |
|------|---------|-----------|
| **文本处理** | 对高重复段落进行同义替换、句式重组、语序调整、主被动转换 | 不改变原文核心事实、数据、结论；不进行事实性增删 |
| **场景覆盖** | 学术论文、课程报告、项目申报书、技术文档的降重改写 | 不处理法律合同、医疗处方、金融审计等强合规文本的实质内容 |
| **查重对接** | 接受知网/维普等查重报告中的重复段落标记作为输入 | 不替代查重系统，不提供"包过"承诺 |
| **输出形式** | 生成改写后的段落文本，标注替换比例与修改说明 | 不生成完整论文排版、不负责引用格式自动修正 |
| **批量处理** | 支持单段落、多段落（≤10段/批次）的连续改写 | 不支持一次处理超过5000字的整篇文档（受上下文窗口限制） |

### 1.2 适用对象

- **直接用户**：需要降低论文重复率的高校学生、科研人员
- **间接用户**：期刊编辑、导师（用于审阅改写质量）
- **不适用的用户**：需要原创观点生成、需要事实核查、需要法律效力的用户

## 三、标准流程

### 3.1 前置条件

1. **输入要求**：
   - 用户需提供原文段落（纯文本或 Markdown 格式）
   - 如有查重报告，需提供重复段落标记（如"第3段，重复率25%"）
   - 明确改写目标（降重/润色/两者兼顾）

2. **环境要求**：
   - 无需额外安装，本技能在对话环境中直接运行
   - 建议用户准备原文的 Word/PDF 备份，便于对照

3. **信息确认**：
   - 确认文本类型（学术论文/技术文档/其他）
   - 确认目标查重系统（知网/维普/其他）——不同系统对连续字符重复的判定阈值不同

### 3.2 执行步骤（分步编号）

#### 步骤 1：接收与解析输入

```
输入示例：
原文段落："深度学习是一种基于人工神经网络的机器学习方法，它通过多层非线性变换对数据进行高层抽象。"
查重标记：该段落重复率 32%
目标：降重至 15% 以下
```

- 解析原文，识别句子边界（按句号、分号、问号切分）
- 标记重复片段（如有查重报告则直接使用标记；无标记则默认整段处理）

#### 步骤 2：制定改写策略

| 策略项 | 决策依据 | 默认值 |
|--------|----------|--------|
| 替换比例 | 重复率越高，`replace_ratio` 越大 | 重复率 >30% 用 0.6；15-30% 用 0.5；<15% 用 0.4 |
| 句式重组 | 重复片段若集中在句首/句尾，启用重组 | 默认开启 |
| 术语保留 | 专业术语、固定缩写、数据、引用标记必须保留 | 默认开启 |

#### 步骤 3：执行改写（核心操作）

**改写操作清单**（按优先级排序）：

1. **同义替换**：将非术语词汇替换为同义词（如"方法"→"途径"、"重要"→"关键"）
2. **语态转换**：主动↔被动互换（如"我们提出"→"被提出"）
3. **句式重组**：拆分长句、合并短句、调整从句位置
4. **增删修饰**：添加限定词（"在一定程度上"）、删除冗余修饰
5. **抽象-具体互换**：将具体表述抽象化，或将抽象概念具体化

**示例**（`replace_ratio=0.5`）：

```
原文：深度学习是一种基于人工神经网络的机器学习方法，它通过多层非线性变换对数据进行高层抽象。
改写：在机器学习领域，深度学习依托人工神经网络架构，借助多层非线性映射机制，实现对数据的高阶特征提取。
修改说明：①"是一种...方法"→"依托...架构"；②"通过...变换"→"借助...映射机制"；③"进行高层抽象"→"实现高阶特征提取"；④语序调整（状语前置）
```

#### 步骤 4：质量自检

改写完成后，执行以下自检：

- [ ] 核心术语是否保留？（如"深度学习"未被替换）
- [ ] 数据、年份、引用标记是否原样保留？
- [ ] 句子是否通顺？有无语法错误？
- [ ] 是否改变了原意？（用"反向翻译"检查：将改写文本回译，对比原意）
- [ ] 替换比例是否达到目标？（估算：被修改的词汇数 / 总词汇数）

#### 步骤 5：输出规范

输出格式必须包含以下三部分：

```markdown
### 改写结果
[改写后的完整段落]

### 修改说明
- 替换了 X 处词汇（列表）
- 调整了 Y 处句式（说明调整方式）
- 保留了术语：Z（列表）

### 预估效果
- 估算重复率：从 32% 降至 12-18%（基于词汇替换率估算，实际以查重系统为准）
- 建议：如未达标，可进行第二轮处理（replace_ratio=0.6 + 句式重组）
```

### 3.3 输出规范补充

| 输出项 | 必须包含 | 可选 |
|--------|----------|------|
| 改写后文本 | ✅ | - |
| 修改说明 | ✅ | - |
| 预估重复率区间 | ✅ | - |
| 二次处理建议 | 仅当首次未达标时 | 始终提供 |
| 术语保留清单 | 当有专业术语时 | 始终提供 |

## 六、FAQ 反模式

### 6.1 常见坑与反模式对照

| # | 常见坑（错误做法） | 反模式（正确做法） |
|---|---------------------|---------------------|
| 1 | **过度改写**：将"深度学习"改为"深度进修"、"神经网络"改为"神经网格" | **术语保留**：专业术语、固定表达、专有名词一律保留，只改写连接词、修饰语、句式结构 |
| 2 | **忽略上下文**：单独改写一个句子，导致与前后文逻辑断裂 | **上下文感知**：改写时参考前后段落，确保衔接自然、逻辑连贯 |
| 3 | **追求字数对等**：改写后字数必须与原文完全一致 | **允许字数浮动**：改写后字数可在原文的 80%-120% 之间浮动，优先保证语义完整 |
| 4 | **一次到位心态**：期望一次改写就彻底降重 | **迭代处理**：接受多轮改写，每轮调整 `replace_ratio` 和策略，逐步逼近目标 |
| 5 | **忽略查重系统差异**：用同一策略应对知网和维普 | **系统适配**：知网对连续 13 字符重复敏感，维普对语义相似度更敏感——知网侧重字面替换，维普侧重句式重组 |

### 6.2 反模式示例

**错误做法**：
```
原文：本文提出了一种基于深度学习的图像识别方法。
错误改写：本文提出了一种基于深度进修的图画辨认方式。
问题：术语被破坏，语义失真，且"图画辨认"不符合学术表达。
```

**正确做法**：
```
原文：本文提出了一种基于深度学习的图像识别方法。
正确改写：本文介绍了一种图像识别方案，其核心依托深度学习技术。
说明：保留"深度学习"和"图像识别"术语，调整句式结构（"提出...方法"→"介绍...方案"），增加"其核心依托"作为连接。
```

## 八、参数详解与调优建议

### 8.1 `replace_ratio` 参数

| 取值 | 适用场景 | 效果 | 风险 |
|------|----------|------|------|
| 0.3 | 轻度润色、仅需微调 | 改动小，保留原句式 | 降重效果有限 |
| 0.5 | 常规降重（默认） | 平衡改动量与语义保持 | 需检查语义是否偏移 |
| 0.6 | 高重复率段落（>30%） | 大幅改动，句式重组 | 语义可能受损，需仔细校验 |
| 0.8 | 极端情况（重复率>50%） | 几乎重写 | 不建议单独使用，应配合人工审阅 |

### 8.2 `sentence_restructure` 参数

| 取值 | 操作 | 示例 |
|------|------|------|
| true | 拆分长句、调换从句位置、合并短句 | "A 和 B 是 C 的基础，同时 D 也影响 C" → "C 的基础包括 A 与 B，且受 D 影响" |
| false | 仅替换词汇，保持句式不变 | "A 和 B 是 C 的基础，同时 D 也影响 C" → "A 与 B 是 C 的根基，同时 D 也作用于 C" |

### 8.3 `terminology_preserve` 参数

| 取值 | 行为 | 适用场景 |
|------|------|----------|
| true | 保留专业术语、固定缩写、数据、引用 | 学术论文、技术文档 |
| false | 允许替换非核心术语 | 科普文章、一般性内容 |

## 九、多轮迭代处理流程

当首次改写未达标时，执行以下迭代：

```
第 1 轮：replace_ratio=0.5, sentence_restructure=true
  ↓ 查重
第 2 轮：replace_ratio=0.6, sentence_restructure=true
  ↓ 查重
第 3 轮：replace_ratio=0.6, sentence_restructure=true, 人工审阅
  ↓ 查重
第 4 轮：人工深度修改（AI 辅助提供同义词库和句式模板）
```

**每轮迭代的检查清单**：

- [ ] 语义是否保持？（反向翻译检查）
- [ ] 术语是否完整？
- [ ] 是否引入了新的重复片段？（与原文其他段落比对）
- [ ] 语言是否自然流畅？
