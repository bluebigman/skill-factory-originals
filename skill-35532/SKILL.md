### 3.1 前置条件

### 3.2 执行步骤

#### 步骤 1：信息确认

```
输入格式：
1. 粘贴原文（必填）
2. 说明重复率（选填，如"知网 30%"）
3. 选择强度（选填，0.1-1.0，默认 0.5）
4. 指定保留术语（选填，如"深度学习、Transformer"）
```

#### 步骤 2：文本分析

对输入文本进行以下分析：

| 分析维度 | 具体内容 |
|----------|----------|
| 句子结构 | 识别长句、短句、复合句分布 |
| 术语密度 | 统计专业术语出现频率 |
| 重复模式 | 识别与常见学术表达高度相似的句式 |
| 改写空间 | 评估同义替换、语态转换的可行区域 |

#### 步骤 3：执行改写

根据强度参数执行改写策略：

| 强度值 | 策略组合 | 适用场景 |
|--------|----------|----------|
| 0.1-0.3 | 仅同义替换 + 轻度语态转换 | 轻度重复，需保持原句结构 |
| 0.4-0.6 | 同义替换 + 语态转换 + 句式重组 | 中等重复，常规降重 |
| 0.7-0.9 | 全部策略 + 增删修饰 + 抽象-具体互换 | 高重复率，需深度改写 |
| 1.0 | 全部策略 + 段落级重构 | 极高重复率，需整体重写 |

#### 步骤 4：输出规范

```
输出格式：
【改写结果】
（改写后的完整文本）

【改写说明】
- 修改句子数：X 句
- 替换词汇数：X 处
- 句式调整：X 处
- 保留术语：X 个

【建议】
- 建议查重验证：是/否
- 如需进一步降重，可调整强度或指定重点段落
```

## 八、改写策略详解

### 8.1 同义替换策略

**适用场景**：非术语词汇的重复

**操作要点**：
- 优先替换高频重复词
- 保持替换后语义等价
- 避免使用生僻词

**示例**：
- "方法" → "途径"、"手段"、"方式"
- "重要" → "关键"、"核心"、"至关重要"
- "研究" → "探讨"、"分析"、"考察"

### 8.2 语态转换策略

**适用场景**：主动/被动结构重复

**操作要点**：
- 保持时态一致
- 注意施事者与受事者的关系
- 避免过度转换导致语义模糊

**示例**：
- "我们提出了一种新方法" → "一种新方法被提出"
- "实验验证了该假设" → "该假设通过实验得到验证"

### 8.3 句式重组策略

**适用场景**：长句结构重复

**操作要点**：
- 拆分超过 40 字的长句
- 合并语义关联的短句
- 调整从句位置改变句序

**示例**：
- 原句："由于实验条件限制，我们无法在高温环境下进行测试，因此采用了常温方案。"
- 改写："受实验条件限制，高温环境测试无法开展，常温方案因此被采用。"

### 8.4 增删修饰策略

**适用场景**：需要调整句子长度或强调程度

**操作要点**：
- 添加限定词使表述更精确
- 删除冗余修饰使表达更简洁
- 保持学术语体的严谨性

**示例**：
- 添加："该方法有效" → "该方法在一定程度上是有效的"
- 删除："非常明显地提高了" → "提高了"

### 8.5 抽象-具体互换策略

**适用场景**：需要改变语义表达层级

**操作要点**：
- 具体→抽象：将实例归纳为一般规律
- 抽象→具体：将一般规律举例说明
- 保持学术严谨性

**示例**：
- 具体→抽象："在 A 和 B 两个案例中均观察到该现象" → "该现象在多个案例中具有普遍性"
- 抽象→具体："该方法适用范围广泛" → "该方法适用于文本分类、情感分析等多个自然语言处理任务"

## 九、多轮迭代改写流程

### 9.1 迭代流程

```
第 1 轮：初始改写（强度 0.5）→ 查重验证
第 2 轮：针对标红段落定向改写（强度 0.6-0.7）→ 查重验证
第 3 轮：剩余重复部分深度改写（强度 0.8-0.9）→ 查重验证
第 4 轮：人工复核 + 微调 → 最终查重
```

### 9.2 迭代策略建议

| 章节类型 | 推荐策略 | 注意事项 |
|----------|----------|----------|
| 引言 | 中度改写（0.5-0.6） | 保持研究背景的准确性 |
| 方法 | 轻度改写（0.3-0.4） | 确保技术细节不丢失 |
| 结果 | 中度改写（0.5-0.6） | 数据表述必须精确 |
| 讨论 | 深度改写（0.7-0.8） | 保持逻辑论证的严密性 |
| 结论 | 中度改写（0.5-0.6） | 核心观点不可偏移 |
