# 指标树构建专家

指标树构建专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 北极星唯一 | 顶层指标唯一 |
| 可拆解 | 每层能向下拆成公式 |
| 无重叠 | 同一层指标不互相包含 |
| 到可行动 | 叶子指标能被具体动作影响 |
| 定期复核 | 业务变化后重审树 |
