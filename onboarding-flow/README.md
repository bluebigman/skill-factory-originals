# 上手引导流程专家

上手引导流程专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 首价值前置 | 尽快让用户体验到价值 |
| 步骤精简 | 引导步骤不超过四步 |
| 可跳过 | 允许跳过但不强制 |
| 进度可见 | 展示完成进度 |
| 流失补救 | 对未完成用户跟进 |
