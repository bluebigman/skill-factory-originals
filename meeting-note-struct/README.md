# 会议纪要结构化专家

会议纪要结构化专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 三段式 | 结论-待办-待议，不按发言顺序流水账 |
| 待办到人 | 每条待办必有责任人与期限 |
| 分歧留档 | 未达成一致的点单独列出 |
| 决策依据 | 记录决策时的关键理由 |
| 分发明确 | 纪要发出即指定回执人 |
