# 产出与验收（production）

> 本页说明：**交付什么形态、怎么验收、免责怎么说**。

## 一、交付形态

| 形态 | 内容 | 用途 |
|---|---|---|
| 文本输出 | 状态 + 条目（情境/动作/权重）+ 下一步 | 人直接看 |
| JSON 输出 | `--json` 开关，含 state/items/next_actions | 程序调用 |

## 二、真实输出样例

> **本样例来自真实运行**，不是手写。换输入则输出不同，属正常。

```
[编排] ok ｜ 检查点 3
  - 重要紧急 (0.60) 
  - 优先级 (0.48) 
  - 排序 (0.48) 
  → 复核 约束条件
  → 归档 异常兜底
```

## 三、验收标准

| 项 | 标准 | 怎么验 |
|---|---|---|
| 自测 | `--selftest` 输出 PASS | `python scripts/main.py --selftest` |
| 空输入 | 返回 empty，不崩 | `--text ""` |
| 超长输入 | 不崩，截断并标注 | 传入 >2 万字 |
| 规则命中 | 用召回词输入返回 ok | 见 playbooks 召回词表 |
| 示例真实 | 文档样例能跑出来 | 按样例命令实跑比对 |

## 四、免责声明

本能力提供通用方法性建议，不构成专业诊断、治疗、法律或投资意见。

## 四点五、交付前检查清单

| # | 检查项 | 通过标准 |
|---|---|---|
| 1 | 自测 | `--selftest` 输出 PASS |
| 2 | 空输入 | 返回 empty，不抛异常 |
| 3 | 超长输入 | 不崩，截断并标注 |
| 4 | 召回词 | 用包内召回词输入返回 ok |
| 5 | 示例真实 | 文档样例能按原命令跑出来 |
| 6 | 四分区齐 | creation/environment/playbooks/production 都有页 |
| 7 | 路由可达 | SKILL.md 路由表指向的文件都存在 |

## 五、版本与维护

- 版本号见 `SKILL.md` frontmatter 的 `version`
- 修改规则必须同步更新本目录四分区（否则文档滞后于实现）
- 每次改动跑 `--selftest` 与示例复现，两者都过才可发布

## AtoA 调用示例（Agent 视角）（来自 SKILL.md）

面向 Agent 自主调用时，建议按以下顺序判断与使用：

1. **适配判断**：读 `when_to_use` 与 `boundary`，确认用户意图落在「时间管理」领域内
2. **构造入参**：按 `input_schema` 组装 `{"text": "<用户原始描述>"}`，不要自行改写用户原话
3. **调用**：`python run.py --text "<text>"`（或 `--input <文件>`）
4. **解析出参**：读 JSON 摘要的 `ok` / `summary` / `next_actions`；`next_actions` 可直接转述给用户
5. **异常处理**：`error_code` 非空时按错误码表自愈重试；**同一错误重试不超过 1 次**
6. **边界兜底**：若 `ok=false` 且 `error_code=E03`，说明超出本能力范围，应改用其他能力或补充上下文

    type: object

  boundary: "只处理 '时间管理' 等领域情境；不做专业诊断/法律/投资意见"
