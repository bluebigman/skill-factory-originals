## 1. 能力边界（一页纸速查卡）

### 1.1 能做与不能做

| 维度 | 能做 | 不能做 |
|------|------|--------|
| 输入类型 | 本地 PDF 文件路径、可访问的 PDF 文件 URL、Base64 编码的 PDF 数据 | 扫描版图片型 PDF（无文本层）、加密带密码的 PDF、损坏的 PDF 文件 |
| 提取内容 | 文本正文、目录结构（TOC）、章节标题层级、页码映射、表格文本化 | 数学公式的 LaTeX 还原、复杂图片中的文字 OCR、手写批注 |
| 输出格式 | 结构化 Markdown（含标题层级、目录树、章节分隔）、纯文本备用格式 | 直接生成 Word/PDF 文件（需用户自行转换） |
| 批量处理 | 同一目录下多个 PDF 文件依次处理，输出独立 Markdown 文件 | 跨文件内容合并、去重比对 |
| 自定义能力 | 用户可指定章节深度（如只提取到二级标题）、是否包含目录页 | 自定义字体识别、版面重排 |

### 1.2 适用对象

- **适用**：中国小初高及大学阶段、带有文本层的 PDF 教材（人教、苏教、北师大版等主流版本均适用）。
- **不适用**：纯图片扫描件、影印本、无目录结构的非教材类 PDF（如论文、合同）。

### 1.3 输入输出速查

## 3. 标准流程

### 3.1 前置条件

1. 确认输入 PDF 存在且可读（文件路径正确或 URL 可访问）。
2. 确认 PDF 包含文本层（可用 `pdftotext` 或 Python `PyPDF2` 快速验证）。
3. 确认输出目录存在且有写入权限。
4. 若需批量处理，确认所有文件命名无重复。

### 3.2 执行步骤

**步骤 1：输入校验**

- 检查输入类型（路径/URL/Base64）。
- 验证文件扩展名为 `.pdf`（URL 场景检查 Content-Type）。
- 若输入为 URL，先下载至临时目录，再进入下一步。

**步骤 2：文本层检测**

- 使用 `PyPDF2` 或 `pdfplumber` 读取第一页文本。
- 若提取文本长度 < 10 字符，判定为扫描件，返回错误码 `E_SCAN_ONLY`。

**步骤 3：目录提取**

- 遍历 PDF 书签（outline/bookmarks），提取标题层级与页码。
- 若无书签，则通过字体大小和样式启发式识别章节标题（字号 ≥ 14pt 且加粗视为一级标题）。
- 输出目录树结构，格式如下：

```markdown
## 目录
1. 第一章 有理数 (p.1)
   1.1 正数和负数 (p.3)
   1.2 有理数的加减法 (p.5)
2. 第二章 整式的加减 (p.20)
```

**步骤 4：正文提取**

- 按页顺序提取文本，保留段落换行。
- 根据目录中的页码定位章节起始页，将文本切分为章节块。
- 每个章节块输出为：

```markdown
### 第一章 有理数
[正文内容，保留原始段落结构]
```

**步骤 5：元数据记录**

- 记录总页数、提取时间、源文件名。
- 写入输出 Markdown 的末尾 `metadata` 区块。

**步骤 6：完整性自查**

- 检查每个章节块是否非空。
- 检查目录条目数是否与章节块数一致（允许 ±10% 偏差，因部分章节可能无正文）。
- 若不一致，在输出中标注 `[需核实:章节缺失]`。

### 3.3 输出规范

输出文件命名规则：`{原文件名}_extracted.md`。

输出结构模板：

```markdown
# {教材名称}

> 来源：{源文件名} | 页数：{N} | 提取时间：{timestamp}

## 目录
{目录树}

## 正文

### {章节标题}
{章节正文}

...

## 元数据
- 总页数：{N}
- 提取工具版本：pdf-textbook-extractor v1.0.0
- 置信度：{高/中/低}
```

## 4. 置信度门控

### 4.1 置信度等级定义

| 等级 | 判定条件 | 输出标注 |
|------|---------|---------|
| 高 | 书签完整 + 文本层清晰 + 章节匹配率 ≥ 95% | 无额外标注 |
| 中 | 书签部分缺失，依赖启发式识别，章节匹配率 80%-95% | 标注 `[需核实:章节边界]` |
| 低 | 无书签，启发式识别效果差，章节匹配率 < 80% | 标注 `[需核实:全文结构]` |

### 4.2 信息不足时的处理

- 当某章节标题无法确定时，输出 `[需核实:第N章标题]` 占位，不猜测。
- 当页码映射冲突时，输出 `[需核实:页码映射]`，并保留所有候选页码。
- 当文本提取出现乱码时，输出 `[需核实:文本编码]`，并附上原始字节片段（前 50 字符）。

### 4.3 禁止行为

- 严禁编造不存在的章节标题。
- 严禁将扫描件强行输出为"提取成功"。
- 严禁在置信度低时仍输出"完整提取"结论。

## 5. 错误码体系

| 错误码 | 含义 | 提示话术 | 修正步骤 |
|--------|------|---------|---------|
| `E_FILE_NOT_FOUND` | 文件路径不存在 | "未找到指定文件，请检查路径是否正确。" | 1. 确认路径拼写；2. 使用绝对路径重试 |
| `E_INVALID_FORMAT` | 非 PDF 文件 | "输入文件不是有效的 PDF 格式。" | 1. 检查扩展名；2. 用 PDF 阅读器验证文件 |
| `E_SCAN_ONLY` | 扫描版无文本层 | "该 PDF 为扫描版，无法直接提取文本，建议先进行 OCR。" | 1. 使用 OCR 工具（如 Tesseract）预处理；2. 重新提交 |
| `E_PASSWORD_PROTECTED` | 文件加密 | "该 PDF 受密码保护，无法读取。" | 1. 去除密码保护；2. 重新提交 |
| `E_CORRUPTED` | 文件损坏 | "PDF 文件已损坏，无法解析。" | 1. 重新下载/获取文件；2. 验证文件完整性 |
| `E_TOO_LARGE` | 文件超过 200MB | "文件大小超出限制（200MB）。" | 1. 拆分 PDF；2. 压缩后重试 |
| `E_BATCH_LIMIT` | 批量超过 50 个 | "批量处理数量超出上限（50 个）。" | 1. 分批处理；2. 减少单次提交数量 |
| `E_OUTPUT_DIR` | 输出目录不可写 | "输出目录无写入权限。" | 1. 更换目录；2. 修改目录权限 |

1. 设置 `chapter_depth` 参数控制标题层级（默认 2，可选 1-4）。
