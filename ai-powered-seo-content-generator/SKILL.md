## 三、标准流程：从概念到成文

### 前置条件

- 已明确种子概念（一句话，含核心名词与场景词）
- 已选定受众层级（初级/中级/专业）
- 已选定内容类型（列表型/教程型/对比型/观点型）
- 已设定字数范围（建议 800-3000 字）

### 执行步骤

**步骤 1：种子概念确认**

将你的主题整理为「名词 + 场景 + 目的」格式。示例：

- 错误示例："空气炸锅"（过于宽泛）
- 正确示例："家用空气炸锅选购指南"（含品类、场景、目的）

**步骤 2：参数确认**

| 参数 | 选项 | 默认值 | 说明 |
|------|------|--------|------|
| 受众层级 | 初级 / 中级 / 专业 | 初级 | 决定术语深度与解释密度 |
| 内容类型 | 列表型 / 教程型 / 对比型 / 观点型 | 列表型 | 决定大纲骨架 |
| 字数范围 | 800-3000 | 1500 | 决定段落数量与展开程度 |

**步骤 3：关键词推导**

基于种子概念，生成三组关键词：

- 核心词（1-2 个）：与主题直接相关的短尾词
- 长尾词（3-5 个）：含修饰语的具体短语
- LSI 词（3-5 个）：语义相关的辅助词

示例（种子概念：家用空气炸锅选购指南）：

- 核心词：空气炸锅、空气炸锅选购
- 长尾词：家用空气炸锅推荐、空气炸锅容量怎么选、空气炸锅品牌对比
- LSI 词：无油烹饪、炸锅清洗、温控精度、厨房小家电

**步骤 4：大纲生成**

按内容类型生成骨架：

- 列表型：引言 → 条目 1-N（每项含小标题+说明）→ 总结
- 教程型：引言 → 前置准备 → 分步操作（步骤 1-N）→ 常见问题 → 总结
- 对比型：引言 → 对比维度表 → 分项解析 → 选购建议 → 总结
- 观点型：引言 → 论点 1-N（含论据）→ 反驳与回应 → 结论

**步骤 5：正文生成**

按大纲逐段生成，遵循以下规则：

- 每段落 80-150 字，含一个核心信息点
- 每 2-3 段插入一个过渡句
- 关键词自然分布，密度控制在 1%-3%
- 长尾词至少出现 2 次，LSI 词至少出现 1 次

**步骤 6：自检**

对照以下清单逐项检查：

- [ ] 标题层级是否连续（无 H1 跳 H3）
- [ ] 字数是否在设定范围内
- [ ] 核心词出现次数 ≥ 3 次
- [ ] 长尾词出现次数 ≥ 2 次
- [ ] 段落间是否有逻辑过渡
- [ ] 结尾是否有行动号召或总结

**步骤 7：预览与输出**

输出格式为 Markdown 文件，结构如下：

```markdown
---
title: （生成的 SEO 标题）
meta_description: （160 字以内的描述）
slug: （URL 友好路径）
keywords: （核心词, 长尾词, LSI 词）
---

# （H1 标题）

（正文内容...）

## 元数据建议

- **Title 标签**：（≤60 字符）
- **Meta Description**：（≤160 字符）
- **URL Slug**：（小写连字符分隔）
```
