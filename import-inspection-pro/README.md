# 进口检验专家

进口检验专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 标准对照 | 逐项对照目的地标准要求 |
| 按批抽样 | 按批量确定抽样方案 |
| 不合格处置 | 明确退运、销毁或整改路径 |
| 预检前置 | 尽量在装运前完成预检 |
| 记录可溯 | 检验记录完整可追溯 |
