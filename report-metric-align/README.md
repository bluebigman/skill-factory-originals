# 报表口径对齐专家

报表口径对齐专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 同一指标同一口径 | 跨报表必须一致 |
| 差异显式 | 有差异必说明原因 |
| 责任人 | 每个口径有归属人 |
| 变更通告 | 口径变更通知使用方 |
| 下线机制 | 废弃报表及时下线 |
