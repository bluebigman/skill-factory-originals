# 表格转图表专家

表格转图表专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 先定意图 | 比较趋势还是构成决定图型 |
| 一图一义 | 一张图只讲一个结论 |
| 刻度不截断 | 柱状图纵轴从零开始 |
| 标注极值 | 标出最大最小与拐点 |
| 配色克制 | 同类同色系，强调项用对比色 |
