1. **初始化检查**：验证 Git 环境、文件存在性、参数合法性
2. **文件加载**：读取目标文件内容到内存
3. **执行修改**：执行文本替换或正则替换

6. **自动提交**：接受修改后，自动执行 `git add` 和 `git commit`
7. **结果输出**：显示提交哈希和修改摘要
