# 技术方案评审专家

技术方案评审专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 问题先行 | 先讲清问题再讲方案 |
| 备选对比 | 列备选与取舍理由 |
| 风险显式 | 列出风险与应对 |
| 可验证 | 方案含验证方式 |
| 限时评审 | 单次不超一小时 |
