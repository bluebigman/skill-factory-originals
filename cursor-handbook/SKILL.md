## 一、能力边界：一页纸速查卡

本技能用于将 Cursor IDE 的规则集（通常为 `.cursorrules` 或 `rules/` 目录下的 Markdown 文件）转换为结构化的、可查询的、可校验的、可执行的技能文档（SKILL.md）。

| 维度 | 能做 | 不能做 |
|------|------|--------|
| 输入 | 单条或多条 Cursor 规则文本（Markdown/纯文本） | 无法直接读取二进制文件或加密内容 |
| 处理 | 解析规则意图、提取关键参数、识别触发条件、生成结构化字段 | 不修改原始规则文件，不自动执行规则逻辑 |
| 输出 | 生成符合本手册规范的 SKILL.md 文档（含 frontmatter、TRACE 结构、合规章节） | 不生成可编译代码，不保证规则在 IDE 中的实际效果 |
| 校验 | 检查输出文档的字段完整性、结构合规性、禁用词命中情况 | 无法验证规则在真实 Cursor 环境中的运行结果 |
| 适用对象 | 需要将散落规则整理为团队可共享文档的开发者、技术文档工程师、AI 辅助开发流程管理者 | 不适用于非 Cursor 生态的规则转换 |

**边界值说明**：单次处理建议不超过 50 条规则；单条规则文本长度建议不超过 2000 字；超出部分建议拆分后分批处理。

## 四、置信度门控

| 规则中未明确错误处理方式 | 输出 `[需核实:error_handling]` 占位符 |
| 规则中未明确输出格式 | 输出 `[需核实:output_format]` 占位符 |

**示例**：
