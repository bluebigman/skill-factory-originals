# 可用性测试执行专家

可用性测试执行专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 任务导向 | 用真实任务而非提问用户偏好 |
| 小样本 | 小样本即可发现多数可用性问题 |
| 出声思维 | 让用户边操作边说出想法 |
| 记录失败 | 记录失败点而非喜好评价 |
| 改后复测 | 修改后必须复测验证 |
