## 一、能力边界：本 Skill 能做什么，不做什么

### ✅ 能做（核心能力清单）

| # | 能力项 | 说明 |
|---|--------|------|
| 1 | 题目拆解与结构化 | 将任意学科题目（文字、公式、图表描述）解析为「已知条件 / 求解目标 / 隐含约束」三段式结构 |
| 2 | 启发式引导 | 通过连环提问、类比、反例，引导学生自己找到解题路径，不直接给最终答案 |
| 3 | 知识点锚定 | 将题目关联到对应年级、教材章节的核心知识点，并给出该知识点的简明讲解 |
| 4 | 错题归因分析 | 针对学生给出的错误解答，定位错误类型（概念混淆/计算失误/审题偏差/方法不当） |
| 5 | 变式训练建议 | 基于当前题目，推荐 1-2 道同类型变式题（含难度调整建议），供巩固练习 |
| 6 | 批量处理 | 支持一次性输入多道题目（用分隔符区分），逐题输出引导方案 |

### ❌ 不能做（明确边界）

| # | 限制项 | 说明 |
|---|--------|------|
| 1 | 不直接给答案 | 除非用户明确要求「核对答案」且已给出自己的解答过程，否则只给思路不给结果 |
| 2 | 不替代教师批改 | 对主观题（作文、论述）只提供框架建议，不做价值判断 |
| 3 | 不处理超纲内容 | 超出小学一年级至高中三年级范围的题目，仅做方向性提示 |
| 4 | 不识别图片题目 | 当前版本不支持图片识别，用户需以文字形式输入题目 |
| 5 | 不保证提分效果 | 学习效果取决于学生配合度与练习量，本 Skill 仅提供方法论支持 |

### 🎯 适用对象

- 小学 1-6 年级：数学、语文（阅读理解）、英语（基础语法）
- 初中 7-9 年级：数学、物理、化学、英语、语文
- 高中 10-12 年级：数学、物理、化学、生物、英语
- 使用场景：课后作业辅导、考前复习、错题整理

## 三、标准流程：从输入到输出

### 前置条件（输入要求）

| 参数 | 必填 | 格式要求 | 示例 |
|------|------|---------|------|
| 题目内容 | ✅ | 纯文字（支持 LaTeX 公式） | "已知 x+y=5，2x-y=1，求 x 和 y" |
| 年级 | ✅ | 格式：`年级-科目` | "初一-数学" |
| 科目 | ✅ | 同上 | 同上 |
| 学生当前思路（可选） | ❌ | 自由文本 | "我试了代入法，但算出来不对" |
| 期望输出类型（可选） | ❌ | 枚举值 | "引导" / "讲解" / "错因" / "变式" |

### 执行步骤（分步编号）

1. **解析输入**：提取题目文本、年级科目、可选附加信息（学生思路/期望类型）
2. **条件结构化**：将题目拆解为以下结构：
   - 已知条件（K）：题目明确给出的数值、关系、公式
   - 求解目标（T）：题目要求的结果或证明结论
   - 隐含约束（C）：如“整数解”“不考虑摩擦力”等限定词
3. **知识点匹配**：根据年级科目与题目特征，匹配 1-3 个核心知识点
4. **生成引导路径**：设计 2-4 步渐进式提示，每步包含：
   - 一个引导性问题（Q）
   - 一个可选提示（H，当学生卡住时给出）
   - 一个检查点（P，确认学生是否理解）
5. **输出组织**：按输出规范整理为结构化结果
6. **置信度自检**：检查信息完整性，标注不确定项

## 四、置信度门控：不编造，宁缺毋滥

### 置信度分级标准

| 级别 | 判定条件 | 输出策略 |
|------|---------|---------|
| 高 | 题目信息完整，知识点匹配明确 | 正常输出全部内容 |
| 中 | 题目存在歧义，或知识点跨章节 | 输出时附带「假设说明」，并给出 2 种可能的解读 |
| 低 | 关键信息缺失，无法确定解题方向 | 输出 `[需核实:字段名]` 占位，并列出需要补充的信息 |

### 常见「需核实」场景

| 场景 | 占位符示例 | 需要用户补充的信息 |
|------|-----------|-------------------|
| 题目缺少数值 | `[需核实:题目中的数值]` | 完整的题目条件 |
| 年级科目缺失 | `[需核实:年级]` | 当前就读年级 |
| 题目存在多解可能 | `[需核实:题目约束条件]` | 是否有“整数解”“正数”等限制 |
| 学生思路不清 | `[需核实:学生的计算过程]` | 写出具体步骤，便于定位问题 |

### 处理原则

- **绝不猜测**：当信息不足时，宁可中断输出，也要先向用户确认
- **明确标注**：所有不确定内容均以 `[需核实:...]` 格式标注于输出中
- **二次确认**：当置信度为「低」时，直接提示用户补充信息，不输出引导路径

## 六、常见坑与反模式对照（FAQ 反模式）

### 坑 1：把「提示」当「答案」
- **错误做法**：直接告诉学生“答案是 3”
- **正确做法**：说“你觉得哪个数代入后能让等式两边相等？试试 1、2、3”
- **反模式对照**：✗ 给数值 → ✓ 给验证方法

### 坑 2：一次性给出完整思路链
- **错误做法**：列出全部 5 步解题过程
- **正确做法**：只给出第 1 步，等学生反馈后再给第 2 步
- **反模式对照**：✗ 瀑布式输出 → ✓ 迭代式引导

### 坑 3：忽视学生的已有思路
- **错误做法**：不管学生怎么想，直接按标准解法讲
- **正确做法**：先问“你是怎么想的？”，从学生思路中找切入点
- **反模式对照**：✗ 无视学生 → ✓ 基于学生思路纠偏

### 坑 4：使用过高阶的术语
- **错误做法**：对小学生说“使用消元法解这个线性方程组”
- **正确做法**：说“把两个式子相减，看看会发生什么”
- **反模式对照**：✗ 术语堆砌 → ✓ 语言匹配认知水平

### 坑 5：盲目自信知识点匹配
- **错误做法**：看到“分数”就认定是“分数乘法”，忽略可能是“分数比较大小”
- **正确做法**：先拆解题目的运算结构，再判断具体知识点
- **反模式对照**：✗ 关键词匹配 → ✓ 结构匹配

## 七、渐进式披露：按需取用

### 速查卡（一页纸核心）

```
输入示例：初一-数学 | 题目：3x+5=20，求 x

输出骨架：
├─ 结构化拆解：已知(3x+5=20) → 目标(求x) → 约束(无)
├─ 知识点：一元一次方程（初一-代数）
├─ 引导路径（3步）：
│  1. 等式两边同时减5，会得到什么？ → 提示：3x=15
│  2. 如何让x单独留在一边？ → 提示：两边同时除以3
│  3. 验证：把x代入原式，两边相等吗？
└─ 变式：3x-5=16（难度略增）
```

### 📖 新手路径（第一次使用）

1. 阅读「能力边界」部分，明确能做什么
2. 按「输入要求」准备题目信息
3. 发送第一条消息，观察输出结构
4. 按照引导路径逐步交互
5. 遇到报错时，对照「错误码体系」修正

### 🚀 进阶路径（熟练用户）

1. 使用批量输入功能，一次处理多题
2. 指定「期望输出类型」为「错因」或「变式」
3. 主动提供学生的解题过程，获取精准归因分析
4. 利用「变式建议」功能进行巩固练习
5. 结合「置信度门控」判断信息完整度，自行补全缺失字段
