# 客户跟进轨迹管理 Skill 文档

## 一、能力边界速查卡

本 Skill 聚焦于客户关系管理中“跟进轨迹”的记录、诊断与预警，不承担完整 CRM 系统的所有职责。

| 能力维度 | 支持范围 | 不支持范围 |
| :--- | :--- | :--- |
| **记录解析** | 解析文字、表格、邮件摘要中的跟进时间、人员、方式、结论 | 语音、视频、图片等非结构化原始文件 |
| **状态判定** | 基于间隔天数、互动频次、阶段变化，标记活跃、沉默、停滞、流失风险 | 主观判断客户情绪、语气、合作意愿 |
| **预警输出** | 输出停滞预警、流失风险预警、下一步行动建议 | 自动发送邮件、短信或创建任务（需外部系统配合） |
| **数据范围** | 单客户全生命周期轨迹、多客户横向对比 | 财务数据、合同条款审核、销售预测模型 |

**适用对象**：销售运营人员、客户成功经理、销售团队负责人、CRM 系统管理员。
