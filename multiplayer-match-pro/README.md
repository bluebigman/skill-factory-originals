# 对战匹配专家

对战匹配专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 分段匹配 | 按水平分段并限制段位差 |
| 等待权衡 | 在等待时长与公平间明确取舍 |
| 连败保护 | 设连败后的保护机制 |
| 异常识别 | 识别挂机、代打与恶意行为 |
| 数据复盘 | 定期复盘胜率分布是否失衡 |
