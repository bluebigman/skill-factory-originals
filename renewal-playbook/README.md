# 续约管理专家

续约管理专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 提前启动 | 在到期前足够时间启动续约 |
| 价值回顾 | 用可量化价值做回顾 |
| 风险早识 | 早期识别降配与流失信号 |
| 多方确认 | 确认多角色意愿而非单一联系人 |
| 条款前置 | 条款调整提前谈不压线 |
