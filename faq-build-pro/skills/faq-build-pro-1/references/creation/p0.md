# 创建与规格（creation）

> 本页说明：**这个技能能做什么、在什么情况下产出什么**。
> 来源：包内 `SKILL.md` 能力清单 + `config.json` 规则表。

## 一、能力清单（情境 → 动作）

| 情境（when） | 动作（then） |
|---|---|
| 真实问法 | 用用户原话而非官方术语 |
| 分层组织 | 按场景分组而非按功能 |

**执行动作**：用用户原话而非官方术语

**复核点**：确认动作与用户实际场景一致；若只是字面命中而语义不符，须明说「按字面命中，请确认」。

**前置条件**：先明确「真实问法」在用户语境里具体指什么，避免把行业术语套到日常表达上。

**常见偏差**：把「真实问法」当成万能答案，忽略输入里的其它约束（如规模、时点、责任人）。

## 前置条件（来自 SKILL.md）

- 输入：一段待分析文本（`--text`），或文件路径（`--input`），或标准输入
- 环境：Python 3.8+；**无第三方依赖**，纯本地运行，不联网、不读取业务系统
- 边界：本能力提供通用方法性建议，不构成专业诊断、治疗、法律或投资意见。
- 不适用：需要专业资质判断的场景（医疗诊断 / 法律意见 / 投资决策）——请转介专业人士

## 适用场景 When to Use（来自 SKILL.md）

**适合使用**

- 输入描述里出现「真实问法」相关情境时
- 输入描述里出现「分层组织」相关情境时
- 输入描述里出现「答在首句」相关情境时
- 输入描述里出现「关联链接」相关情境时
- 输入描述里出现「命中统计」相关情境时
- 想把模糊描述转成**归因清单 + 可执行动作**时

**不适合使用**
- 输入为空或与「常见问题库构建」完全无关
- 需要**专业资质判断**的场景——请转介专业人士
