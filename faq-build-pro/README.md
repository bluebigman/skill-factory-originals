# 常见问题库构建专家

常见问题库构建专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 真实问法 | 用用户原话而非官方术语 |
| 分层组织 | 按场景分组而非按功能 |
| 答在首句 | 先给答案再给解释 |
| 关联链接 | 相关条目互相引用 |
| 命中统计 | 按访问量排序定期重排 |
