# xhtmlize — HTML 片段转 XHTML 规范标记

## 一、能力边界（一页纸速查卡）

### 1.1 能做与不能做

| 维度 | 能做 | 不能做 |
|------|------|--------|
| 标签处理 | 闭合缺失标签、修复嵌套错乱、统一标签小写 | 不处理脚本逻辑、不执行 JavaScript |
| 属性处理 | 属性值加引号、布尔属性显式化、移除重复属性 | 不新增语义化属性、不推断业务含义 |
| 实体处理 | 转义 `&` `<` `>` 为合法实体、保留合法实体 | 不转换中文标点、不处理 Unicode 特殊字符 |
| 结构处理 | 清理空标签、移除非法嵌套（如 `<p>` 内嵌 `<div>`） | 不重排文档流、不调整内容顺序 |
| 格式输出 | 统一缩进（2 空格）、标签换行、属性顺序固定 | 不压缩为单行、不保留原格式风格 |

### 1.2 适用对象

- **适用**：静态 HTML 片段、模板文件、邮件正文、富文本编辑器输出
- **不适用**：含 `<iframe>` 的复杂页面、SVG 内嵌图形、MathML 公式、需要保留条件注释的旧系统代码

### 1.3 输入输出速览

| 项目 | 说明 |
|------|------|
| 输入格式 | 单个 `.html` / `.htm` / `.txt` 文件，或直接粘贴的文本片段 |
| 输出格式 | 同目录生成 `*_xhtml.html` 文件，编码统一为 UTF-8 |
| 最大文件 | 单文件不超过 500KB，超过需分段处理 |
| 字符集 | 仅处理 UTF-8 编码，其他编码需先转码 |

## 三、标准流程

### 3.1 前置条件

| 检查项 | 要求 | 不满足时处理 |
|--------|------|--------------|
| 文件命名 | 文件名不含空格、中文、特殊符号 | 先重命名为 `page_01.html` 格式 |
| 文件编码 | UTF-8 无 BOM | 用编辑器转码后再处理 |
| 目录权限 | 当前目录可写 | 更换工作目录 |
| 备份确认 | 原文件未被占用 | 关闭编辑器中的文件锁 |

### 3.2 执行步骤

#### 第一步：准备输入

1. 将所有待处理文件放入同一目录，确认命名规范一致（如 `chapter_01.html`、`chapter_02.html`）。
2. 检查文件编码，非 UTF-8 需先转换。
3. 记录原始文件列表，用于后续比对。

#### 第二步：试运行（单样本）

1. 选取第一个文件执行转换命令：
   ```
   xhtmlize --selftest chapter_01.html
   ```
2. 检查输出文件 `chapter_01_xhtml.html`，核对以下字段：
   - 所有标签是否小写
   - 所有属性值是否带引号
   - 空标签是否闭合（如 `<br />`）
   - 嵌套层级是否正确
3. 确认无误后进入批量阶段。

#### 第三步：批量执行

1. 对全量文件执行转换：
   ```
   xhtmlize chapter_*.html
   ```
2. 转换前自动生成备份目录 `backup_原始时间戳/`，原文件不覆盖。
3. 输出文件命名规则：`原文件名_xhtml.html`。

#### 第四步：校验结果

1. 抽查 20% 输出文件，核对以下关键字段：
   - `<html>` 根标签存在且含 `xmlns` 属性
   - 所有标签闭合（自闭合标签使用 `/>` 结尾）
   - 属性名小写、属性值加引号
   - 无重复属性、无空标签残留
2. 与源数据比对内容完整性：文本内容、链接地址、图片路径不得改变。

### 3.3 输出规范

| 输出项 | 规范 |
|--------|------|
| 文件编码 | UTF-8 无 BOM |
| 缩进 | 2 空格，标签层级缩进 |
| 属性顺序 | `id` → `class` → `style` → 其他属性（按字母序） |
| 自闭合标签 | `<br />`、`<img />`、`<hr />`、`<input />` |
| 根元素 | `<html xmlns="http://www.w3.org/1999/xhtml">` |
| 文档声明 | `<?xml version="1.0" encoding="UTF-8"?>` 置于首行 |
