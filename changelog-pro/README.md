# 变更日志专家

变更日志专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 按版本组织 | 每个版本独立成节 |
| 分类清晰 | 新增修复变更分类列示 |
| 影响说明 | 破坏性变更必须显著标注 |
| 日期明确 | 每个版本带发布日期 |
| 可追溯 | 变更可关联到具体提交 |
