# 模式演进专家

模式演进专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 兼容优先 | 优先做兼容性变更 |
| 分步执行 | 大变更拆成多步 |
| 脚本可回滚 | 迁移脚本必须可回滚 |
| 影子验证 | 新结构先影子写入 |
| 消费方通知 | 结构变更须通知消费方 |
