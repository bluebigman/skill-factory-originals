### 1.1 本 Skill 能做什么

| 2 | 奖金计算 | 支持月度/季度/年度奖金，含年终奖单独计税方案 |
| 3 | 个税计算 | 按累计预扣法计算个人所得税，支持专项附加扣除 |
| 4 | 五险一金 | 按当地比例计算个人与单位承担部分，支持上下限封顶 |

| 8 | 异常校验 | 出勤天数超限、环比波动>20%等异常自动标记 |
| 9 | 年终奖比选 | 对比合并计税与单独计税，避开临界点 |

## 三、标准流程

### 3.1 前置条件

开始核算前，需要确认以下数据是否齐备：

| 数据类别 | 必需字段 | 缺失处理 |
|----------|----------|----------|
| 员工基础信息 | 姓名、部门、入职日期、社保基数、公积金基数 | 缺失则询问 |
| 考勤数据 | 出勤天数、请假天数、加班时长 | 缺失则询问 |
| 绩效数据 | 绩效系数/绩效工资 | 缺失则按 1.0 处理并标注 |
| 补贴数据 | 餐补、交通补、通讯补等 | 缺失则按 0 处理 |
| 社保参数 | 当地社保比例、上下限 | 缺失则使用默认值并标注 |
| 个税参数 | 累计收入、累计已缴税、专项附加扣除 | 缺失则按首月处理 |

### 3.2 执行步骤

#### 步骤 1：数据收集与校验

1. 接收用户输入的员工数据（支持单人或批量）
2. 校验数据完整性，缺项主动询问
3. 校验数据合理性：
   - 出勤天数 ≤ 当月应出勤天数
   - 社保基数在上下限范围内
   - 绩效系数在 0-2 之间

#### 步骤 2：五险一金计算

```
个人承担部分 = 社保基数 × 个人比例（养老8% + 医疗2% + 失业0.5%）
单位承担部分 = 社保基数 × 单位比例（养老16% + 医疗8% + 失业0.5% + 工伤0.2% + 生育0.8%）
公积金个人部分 = 公积金基数 × 公积金比例（5%-12%，取配置值）
公积金单位部分 = 公积金基数 × 公积金比例（同个人）
```

**上下限处理**：
- 社保基数 < 下限 → 按下限计算
- 社保基数 > 上限 → 按上限计算
- 公积金基数同理

#### 步骤 3：应发工资计算

```
应发工资 = 基本工资 + 岗位工资 + 绩效工资 × 绩效系数 + 加班费 + 各类补贴 - 缺勤扣款
```

其中：
- 缺勤扣款 = 日工资 × 缺勤天数
- 日工资 = 月工资标准 ÷ 21.75
- 加班费 = 加班时长 × 时薪 × 加班倍数（工作日1.5倍/休息日2倍/法定节假日3倍）

#### 步骤 4：个税计算（累计预扣法）

```
本期应预扣预缴税额 = （累计预扣预缴应纳税所得额 × 预扣率 - 速算扣除数）- 累计减免税额 - 累计已预扣预缴税额

累计预扣预缴应纳税所得额 = 累计收入 - 累计免税收入 - 累计减除费用（5000×月数）- 累计专项扣除 - 累计专项附加扣除 - 累计依法确定的其他扣除
```

**税率表（综合所得适用）**：

| 级数 | 累计预扣预缴应纳税所得额 | 预扣率 | 速算扣除数 |
|------|--------------------------|--------|------------|
| 1 | 不超过36,000元 | 3% | 0 |
| 2 | 36,000 - 144,000元 | 10% | 2,520 |
| 3 | 144,000 - 300,000元 | 20% | 16,920 |
| 4 | 300,000 - 420,000元 | 25% | 31,920 |
| 5 | 420,000 - 660,000元 | 30% | 52,920 |
| 6 | 660,000 - 960,000元 | 35% | 85,920 |
| 7 | 超过960,000元 | 45% | 181,920 |

#### 步骤 5：实发工资计算

```
实发工资 = 应发工资 - 个人社保 - 个人公积金 - 个税 - 其他扣款
```

#### 步骤 6：输出工资条与汇总表

**工资条格式**：

```
┌─────────────────────────────────────────────┐
│  2026年08月 工资条                           │
│  姓名：张三    部门：技术部    工号：T001    │
├─────────────────────────────────────────────┤
│  基本工资    8,000.00                        │
│  岗位工资    2,000.00                        │
│  绩效工资    1,500.00  × 系数1.2 = 1,800.00 │
│  加班费        320.50                        │
│  餐补          300.00                        │
│  交通补贴      200.00                        │
├─────────────────────────────────────────────┤
│  应发合计   12,620.50                        │
├─────────────────────────────────────────────┤
│  养老保险   -640.00  （8%）                  │
│  医疗保险   -160.00  （2%）                  │
│  失业保险    -40.00  （0.5%）                │
│  住房公积金 -600.00  （7.5%）                │
│  个人所得税 -214.62                          │
├─────────────────────────────────────────────┤
│  实发工资   10,965.88                        │
└─────────────────────────────────────────────┘
```

**部门汇总表格式**：

| 部门 | 人数 | 应发合计 | 个人社保 | 个人公积金 | 个税 | 实发合计 | 单位社保 | 单位公积金 | 单位总成本 |
|------|------|----------|----------|------------|------|----------|----------|------------|------------|
| 技术部 | 15 | 189,307.50 | 12,600.00 | 9,000.00 | 3,219.30 | 164,488.20 | 25,200.00 | 9,000.00 | 223,507.50 |
| 市场部 | 8 | 96,500.00 | 6,400.00 | 4,800.00 | 1,456.20 | 83,843.80 | 12,800.00 | 4,800.00 | 114,100.00 |

#### 步骤 7：数据回写

- 累计收入 = 上月累计收入 + 本月应发工资
- 累计已缴税 = 上月累计已缴税 + 本月个税
- 累计专项扣除 = 上月累计 + 本月个人社保公积金

## 六、FAQ 与反模式

### 6.1 常见坑

| 坑 | 反模式（错误做法） | 正模式（正确做法） |
|----|-------------------|-------------------|
| 社保基数用错 | 直接用工资作为社保基数，忽略上下限 | 先确认当地上下限，再判断是否封顶 |
| 个税算错 | 用月度税率表而非累计预扣法 | 使用累计预扣法，按年度累计计算 |
| 年终奖计税选错 | 一律按单独计税 | 对比合并计税与单独计税，选税负低的 |
| 缺勤扣款算错 | 按当月实际天数折算日工资 | 统一按 21.75 天折算 |
| 加班费倍数用错 | 休息日加班按 1.5 倍 | 工作日 1.5 倍，休息日 2 倍，法定节假日 3 倍 |

### 6.2 反模式对照

**反模式 1：忽略累计数据**
> ❌ "这个月个税 = 本月应纳税所得额 × 税率"
> ✅ "这个月个税 = （累计应纳税所得额 × 税率 - 速算扣除数）- 累计已缴税"

**反模式 2：社保基数直接取工资**
> ❌ "社保基数 = 员工月工资"
> ✅ "社保基数 = min(max(月工资, 下限), 上限)"

**反模式 3：年终奖一律单独计税**
> ❌ "年终奖单独计税，税率 = 年终奖 ÷ 12 对应的税率"
> ✅ "分别计算单独计税和合并计税的税额，取较低者"
