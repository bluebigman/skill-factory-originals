# 投放管理专家

投放管理专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 预算上限 | 设置日与总预算上限 |
| 账户隔离 | 测试账户与正式账户隔离 |
| 素材轮换 | 定期更换素材防疲劳 |
| 异常熔断 | 成本异常时自动暂停 |
| 先审后投 | 素材先审合规再投放 |
