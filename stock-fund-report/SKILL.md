## 三、标准流程

### 3.1 前置条件

- 用户提供至少 1 只股票的持仓信息
- 每只股票至少包含：代码或名称、数量、成本价、现价
- 若缺少现价，需用户补充或使用最近收盘价（需标注数据日期）

### 3.2 执行步骤

**步骤 1：收集与确认输入**

- 接收用户输入，判断格式类型（CSV/JSON/自然语言）
- 若格式不明确，返回格式示例并请求确认

**步骤 2：解析持仓数据**

- 提取字段：代码、名称、数量、成本价、现价
- 计算派生字段：市值 = 数量 × 现价；成本市值 = 数量 × 成本价；浮动盈亏 = (现价 - 成本价) × 数量

**步骤 3：收益统计**

- 单只股票收益率 = (现价 - 成本价) / 成本价 × 100%
- 组合总市值 = Σ(数量 × 现价)
- 组合总成本 = Σ(数量 × 成本价)
- 组合整体收益率 = (总市值 - 总成本) / 总成本 × 100%

**步骤 4：集中度分析**

- 个股仓位占比 = 个股市值 / 组合总市值 × 100%
- 行业分布（需用户提供行业信息，或使用默认分类）
- 前三大持仓集中度 = 前三大市值之和 / 总市值 × 100%

**步骤 5：风险提示**

- 单一持仓占比 > 40% → 提示集中度过高
- 行业重叠度 > 60% → 提示行业风险
- 现金比例 < 5% → 提示流动性风险
- 组合波动率估算（基于个股历史波动率，需用户提供或使用默认值）

**步骤 6：调仓建议**

- 基于集中度、行业分散度、现金比例给出结构性建议
- 建议格式：具体操作方向 + 参考比例范围

**步骤 7：输出报告**

- 按约定格式输出 Markdown 报告
- 标注置信度（★★★/★★☆/★☆☆）
- 附处理说明与数据假设
