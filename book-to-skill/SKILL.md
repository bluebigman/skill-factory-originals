# 书籍转技能（book-to-skill）使用指南

## 一、能力边界速查卡

本技能用于将非结构化的书籍、文章、网页链接等内容，转化为结构化的技能说明文档，便于后续检索、复用与二次加工。

| 维度 | 说明 |
|------|------|
| 输入类型 | 文本段落、文件路径（.txt/.md/.pdf）、URL 链接 |
| 输出类型 | Markdown 格式的技能文档（SKILL.md） |
| 核心能力 | 信息抽取、结构重组、置信度标注、批量处理 |
| 非目标 | 不进行语义创作、不生成新知识、不替代原书阅读 |

**适用对象**：需要快速整理阅读笔记的学习者、需要将内部文档标准化的团队、希望从长文中提取要点的研究者。

**不适用场景**：需要深度理解与批判性分析的学术写作、需要版权授权的商业转载、对原文进行情感化改写。
