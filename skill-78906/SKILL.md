## 三、标准流程

### 执行步骤

#### 步骤 1：获取脚本

将 `run.py` 下载到本地工作目录。确保 Python 环境可用：

```bash
python --version
```

若需直接执行，可赋予权限：

```bash
chmod +x run.py
```

#### 步骤 2：生成标题

基础生成命令：

```bash
python run.py "起标题" --topic "AI医疗" --count 8
```

参数说明：

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `--topic` | str | 必填 | 标题主题或关键词 |
| `--count` | int | 5 | 生成数量，建议 5-10 条 |
| `--style` | str | 混合 | 可选：悬念/数字/痛点/故事/清单 |
| `--audience` | str | 通用 | 目标人群描述，如"30-40岁职场女性" |
| `--length` | str | 自动 | 可选：短（<15字）/中（15-25字）/长（>25字） |

#### 步骤 3：校验标题

对已有标题进行合规检查：

```bash
python run.py "标题校验" --input titles.txt
```

校验维度：

| 维度 | 规则 | 判定标准 |
|------|------|----------|
| 长度 | 中文 8-30 字，英文 5-20 词 | 超出范围标记为警告 |
| 敏感词 | 命中内置词表或自定义词表 | 命中即标记为违规 |
| 绝对化用语 | 检测"最""第一""100%""绝对"等 | 命中即标记为风险 |
| 重复率 | 与同批次其他标题的相似度 | 相似度 >80% 标记为重复 |

#### 步骤 4：整理标题库

对已有标题列表进行清洗和排序：

```bash
python run.py "标题整理" --input old_titles.txt --dedupe --sort quality
```

输出规范：

- 去重后的标题列表
- 每个标题附带质量分（0-100）
- 按质量分降序排列
- 重复项单独输出到 `duplicates.txt`

## 八、最佳实践建议

### 受众明确化

使用 `--audience` 参数指定目标人群，如"30-40岁职场女性"。明确的受众描述能显著提升标题的针对性。

### 风格混合策略

不指定 `--style` 时，系统自动混合多种风格生成。建议先混合生成，再根据平台特性选择单一风格进行微调。

### 数量控制

建议每次生成 5-10 条，便于比较和选择。数量过多会增加筛选成本，过少则缺乏选择空间。

### 迭代优化

先生成一批，再对满意的标题进行微调。微调时可修改个别词汇、调整语序或更换数字。

### 合规前置

发布前务必运行校验命令。特别注意：

- 避免"最""第一""100%"等绝对化用语
- 避免生僻词和歧义缩写
- 与已有标题相似度控制在 80% 以下

### 数据安全

输入文件中的敏感信息请自行脱敏。本工具不收集或上传任何数据，所有处理均在本地完成。
