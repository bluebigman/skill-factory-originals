## 一、能力边界（一页纸速查卡）

| 序号 | 能力项 | 说明 | 输出物 |
|------|--------|------|--------|
| 1 | 多维度竞品拆解 | 从产品功能、定价策略、目标客群、渠道布局、内容运营、技术壁垒六个维度拆解 | 六维拆解表 |

| 3 | 结构化对比报告 | 生成可直接用于汇报的 Markdown 格式对比报告 | 完整报告 |

| 5 | 行动优先级排序 | 按投入产出比、实施难度、时间窗口三个维度排序 | 优先级矩阵 |

## 三、标准处理流程

### 3.1 前置条件

| 条件项 | 要求 | 缺失处理 |
|--------|------|----------|
| 竞品名称 | 至少 1 个明确竞品 | 提示用户补充，否则无法启动 |
| 分析维度 | 可选，默认全维度 | 用户可指定重点维度 |
| 数据素材 | 可选，但影响分析深度 | 无素材时输出框架性分析，标注 [需核实:数据] |
| 自身产品信息 | 建议提供 | 缺失时差异化策略偏通用 |

### 3.2 执行步骤

**第一步：信息收集与确认（约 2 分钟）**

1. 确认竞品名称、数量（建议 1-5 个）
2. 确认分析维度（默认六维全开）
3. 确认输出格式（默认 Markdown 报告）
4. 确认是否有补充素材（截图、链接、文档等）

**第二步：六维拆解（核心逻辑）**

对每个竞品执行以下六个维度的拆解：

| 维度 | 拆解要点 | 输出格式 |
|------|----------|----------|
| 产品功能 | 核心功能列表、特色功能、功能成熟度 | 功能对照表 |
| 定价策略 | 价格区间、付费模式、免费策略 | 定价对比表 |
| 目标客群 | 客群画像、使用场景、核心痛点 | 客群画像卡 |
| 渠道布局 | 线上/线下渠道、合作生态、触达方式 | 渠道分布图 |
| 内容运营 | 内容类型、更新频率、互动数据 | 内容运营表 |
| 技术壁垒 | 专利、算法、数据积累、技术栈 | 壁垒评估表 |

**第三步：差异化机会识别**

1. 对比自身与竞品的六维差异
2. 标记竞品薄弱项（评分 ≤ 2/5 的维度）
3. 识别竞品未覆盖的细分场景
4. 输出机会点列表（每个机会点含：场景描述、目标用户、预估价值）

**第四步：策略生成与排序**

按以下公式评估策略优先级：

```
优先级得分 = 投入产出比(1-5) × 0.4 + 实施难度反向分(1-5) × 0.3 + 时间窗口(1-5) × 0.3
```

得分 ≥ 4.0 为「立即执行」，3.0-3.9 为「短期规划」，< 3.0 为「长期观察」。

**第五步：报告输出**

输出结构化 Markdown 报告，包含：

1. 执行摘要（200 字内）
2. 竞品全景对比表
3. 六维拆解详情
4. 差异化策略清单（含优先级）
5. 风险提示
6. 下一步行动建议
