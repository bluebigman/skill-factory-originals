# 竞品拆解与差异化策略生成器（Competitor Analysis Skill）

## 一、能力边界：一页纸速查卡

### 1.1 本 Skill 能做什么

| 能力项 | 说明 | 输出物 |
|--------|------|--------|
| 多维度竞品拆解 | 从产品功能、定价、渠道、用户评价、技术栈、商业模式六个维度拆解 | 六维拆解表 |
| 差异化策略生成 | 基于拆解结果，输出 3-5 条可执行的差异化建议 | 策略清单 |

### 1.2 本 Skill 不能做什么

- **不能** 实时抓取网页数据（需用户自行提供或使用其他工具获取）

## 三、标准流程

### 3.1 前置条件

| 条件 | 要求 | 缺失处理 |
|------|------|----------|
| 竞品清单 | 至少 1 个竞品名称或链接 | 提示用户提供，否则无法启动 |

### 3.2 执行步骤

**Step 1：输入确认（耗时约 1 分钟）**

读取用户输入，确认以下参数：

| 参数 | 类型 | 必填 | 默认值 | 示例 |
|------|------|------|--------|------|
| `target_product` | string | 是 | 无 | "我们的 SaaS 产品" |
| `competitors` | array | 是 | 无 | ["竞品A", "竞品B"] |
| `dimensions` | array | 否 | ["功能","定价","渠道","用户评价","技术栈","商业模式"] | ["功能","定价"] |
| `output_format` | string | 否 | "markdown" | "markdown" / "json" |
| `depth` | string | 否 | "standard" | "quick" / "standard" / "deep" |

**Step 2：信息收集与标注（耗时约 2 分钟）**

- 对每个竞品，按选定维度逐项拆解
- 信息不足的字段标注 `[需核实:字段名]`
- 信息冲突时，标注 `[需核实:冲突项]` 并列出冲突来源

**Step 3：六维拆解（核心逻辑，耗时约 3 分钟）**

对每个竞品执行以下拆解：

```
维度1 功能拆解：
  - 核心功能列表（按用户价值排序）
  - 独有功能标记（★）
  - 缺失功能标记（△）

维度2 定价拆解：
  - 定价模式（订阅/买断/免费+增值）
  - 价格区间（低/中/高）
  - 免费策略（有无免费层）

维度3 渠道拆解：
  - 主要获客渠道（线上/线下/渠道商）
  - 内容营销活跃度（高/中/低）
  - 社交媒体矩阵（平台+粉丝量级）

维度4 用户评价拆解：
  - 正面评价关键词（Top 5）
  - 负面评价关键词（Top 5）
  - 用户满意度趋势（上升/平稳/下降）

维度5 技术栈拆解：
  - 前端技术（如 React/Vue/原生）
  - 后端架构（如微服务/单体）
  - 部署方式（SaaS/私有化/混合）

维度6 商业模式拆解：
  - 收入来源（订阅/广告/交易抽成）
  - 成本结构（研发/营销/运营占比）
  - 盈利模式（单位经济模型）
```

**Step 4：差异化策略生成（耗时约 2 分钟）**

基于拆解结果，按以下逻辑生成策略：

```
策略生成规则：
1. 找空白：竞品均未覆盖的功能/场景 → 建议进入
2. 找弱点：竞品负面评价集中的维度 → 建议优化
3. 找错位：竞品定价区间之外的空白带 → 建议定价
4. 找趋势：用户评价中上升的需求关键词 → 建议布局
```

**Step 5：输出规范（耗时约 1 分钟）**

输出结构化报告，包含：

```
# 竞品分析报告：[目标产品] vs [竞品列表]

## 一、执行摘要（3-5 句话）
## 二、六维拆解对比表
## 三、差异化策略建议（3-5 条，每条含：策略描述/依据/预期效果/风险）
## 四、竞争态势矩阵（2x2 定位图）
## 五、下一步行动清单
## 六、信息置信度说明
```
