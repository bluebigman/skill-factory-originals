| 网页转 Markdown | 采集网页正文内容，去除导航/广告/页脚等噪声，保留文章主体 | `https://example.com/article` | 干净的 Markdown 正文，保留原文标题和段落结构 |

### 3.2 执行步骤

#### 步骤 1：输入验证

```
输入类型检测：
- 本地文件：检查扩展名（.pdf）、文件大小、是否加密
- URL：检查协议（http/https）、域名可达性、内容类型（text/html）
- 不合法输入 → 返回错误码 E1001
```

#### 步骤 2：内容解析

```
PDF 解析流程：
1. 读取 PDF 元数据（标题、作者、创建日期）
2. 逐页提取文本块，记录页码和坐标位置
3. 识别标题层级（基于字体大小、加粗、缩进）
4. 识别表格区域（基于线条检测或文本对齐模式）
5. 识别列表结构（基于项目符号、编号模式）

网页解析流程：
1. 获取 HTML 源码
2. 解析 DOM 树，识别主内容区（基于标签语义和文本密度）
3. 移除噪声元素（nav、aside、footer、script、style）
4. 保留图片链接和 alt 文本
```

#### 步骤 3：置信度评估

| 内容类型 | 高置信度（≥0.9） | 中置信度（0.7-0.9） | 低置信度（<0.7） |
|----------|-------------------|---------------------|-------------------|
| 纯文本段落 | 清晰字体、无遮挡 | 轻微模糊、字体异常 | 乱码、重叠字符 |
| 表格数据 | 行列对齐、无合并单元格 | 部分合并、跨页 | 结构混乱、数据缺失 |
| 数值信息 | 数字清晰、单位明确 | 数字模糊、单位存疑 | 数字残缺、无法辨认 |
| 标题层级 | 字体差异明显 | 字体差异较小 | 无格式区分 |

#### 步骤 4：Markdown 生成

```
输出结构模板：
---
title: （文档标题）
source: （来源文件/URL）
converted_at: （转换时间戳）
confidence: （整体置信度均值）
---

# （一级标题）

（正文段落）

## （二级标题）

| 表头1 | 表头2 |
|-------|-------|
| 数据1 | 数据2 |

- 列表项1
- 列表项2

[需核实:第X页-第Y段-具体内容]
```

#### 步骤 5：质量校验

```
校验清单：
□ 所有标题层级是否连续（无跳级）
□ 表格列数是否一致
□ 所有 [需核实] 标记是否包含位置信息
□ 链接是否保留完整 URL
□ 图片是否保留 alt 文本
□ 整体置信度是否 ≥ 0.7（低于则提示用户）
```

## 常见问题（FAQ）

**Q: 支持中文文件吗？**
A: 支持，内置 utf-8/gbk/gb18030 多编码容错。

**Q: 运行报错怎么办？**
A: 工具内置异常降级，错误会有明确提示；可先用 --dry-run 预览。

**Q: 如何确认功能正常？**
A: 运行 --selftest，全部通过即核心功能正常。
