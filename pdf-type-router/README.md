# 类型路由专家

类型路由专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 先判类型 | 扫描件与文本件走不同路径 |
| 文本优先 | 有文本层不用 OCR |
| 页级判定 | 同一文件不同页可分别处理 |
| 失败回退 | 文本抽取失败再试 OCR |
| 抽后校验 | 统计页数与实际抽取页比对 |
