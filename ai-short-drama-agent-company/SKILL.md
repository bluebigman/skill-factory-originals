# 短剧工坊：策划与编剧辅助 Skill

## 一、能力边界（一页纸速查卡）

本 Skill 面向**竖屏短剧（单集 1-3 分钟，总集数 60-100 集）**的策划与编剧环节，提供结构化的工作流支持。

| 维度 | 能做 | 不能做 |
|------|------|--------|
| 策划 | 题材定位、用户画像、竞品拆解、核心梗提炼、世界观设定 | 市场趋势预测、平台政策解读、投资回报测算 |
| 编剧 | 分集大纲、冲突设计、台词润色、反转点排布、人物弧光设计 | 直接产出可拍摄的完整文学剧本（需人工二次加工） |
| 格式 | 输出分集梗概表、单集分场表、人物关系图、钩子清单 | 生成分镜脚本（含镜头语言、机位标注） |
| 协作 | 提供多版本方案供选择、按反馈迭代修改 | 替代真人编剧的创意决策与最终定稿 |

**适用对象**：短剧编剧、内容策划、制片助理、短视频运营人员。

**不适用场景**：长剧（45分钟/集）、综艺脚本、广告文案、小说创作。

## 三、标准流程

### 前置条件

- 用户需明确：**题材方向**（战神/逆袭/甜宠/悬疑/都市/古装等）、**目标受众**（性别/年龄段）、**总集数**（默认 80 集）、**单集时长**（默认 90 秒）。
- 若信息不足，先执行信息收集（见第四节置信度门控）。

### 执行步骤

**Step 1：题材与定位确认（5 分钟）**

输出一张定位卡：

```
题材：逆袭
受众：18-30 岁女性
核心卖点：打脸渣男 + 事业逆袭
对标参考：《XXX》（用户提供或 AI 推荐）
差异化：女主从家庭主妇→科技公司创始人
```

**Step 2：核心梗提炼（10 分钟）**

用一句话概括全剧：`[主角] + [初始困境] + [转折事件] + [终极目标]`。

示例：*"被扫地出门的家庭主妇，意外获得前夫竞争对手的商业机密，三年后以科技新贵身份回归，在商场上碾压前夫全家。"*

**Step 3：分集大纲生成（20 分钟）**

按"每 10 集一个高潮"的节奏，输出分集梗概表：

|------|----------|------------------|----------|
| 1-10 | 女主被离婚、净身出户 | 她捡到一部神秘手机 | 低谷→微升 |
| 11-20 | 女主开始创业，遭遇打压 | 前夫发现她竟在对手公司 | 波动上升 |
| 21-30 | 首次商战胜利 | 神秘手机的真实身份揭晓 | 上升→小高潮 |
| ... | ... | ... | ... |

**Step 4：单集分场细化（按需触发）**

用户指定某一集，输出分场表：

```
第 15 集（目标时长 90 秒）
场景 1：办公室（0:00-0:20）
   - 女主被同事嘲讽，隐忍不语
   - 内心独白：还有三天，计划就完成了
场景 2：电梯间（0:20-0:45）
   - 偶遇前夫与新欢，前夫出言羞辱
   - 女主微笑回应，留下悬念台词
场景 3：天台（0:45-1:30）
   - 女主接听神秘电话，得知关键情报
   - 钩子：镜头切到前夫办公室，一份文件被打开
```

**Step 5：输出规范**

- 所有输出使用 Markdown 表格或列表，便于复制粘贴。
- 每份输出末尾附"待确认项"清单，列出需要用户拍板的决策点。
- 单次输出不超过 2000 字，超出部分分批次交付。
