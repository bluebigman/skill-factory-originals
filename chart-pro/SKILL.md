### 3.2 执行步骤

1. **接收数据** — 用户提供数据（粘贴/上传/路径），确认数据格式与完整性。
2. **确认参数** — 询问图表类型（可选）、标题（可选）、坐标轴名称（可选）、配色（可选，默认商务蓝）、输出格式（可选，默认 PNG）。
3. **数据校验** — 检查数据行列数、数据类型、缺失值。若发现问题，返回错误码并给出修正建议。
4. **图表生成** — 根据参数生成图表，自动选型时依据以下规则：

   | 数据特征 | 推荐图表 |

   | 时间序列（年份/月份） | 折线图 |

   | 占比分析（总和=100%） | 饼图 |

## 六、FAQ 反模式

### 6.1 常见坑与反模式对照

| 常见坑 | 反模式（错误做法） | 正模式（正确做法） |

| 数据含合并单元格 | 直接粘贴 Excel 合并单元格内容 | 先展开合并单元格，确保每行独立 |
| 日期格式不统一 | 混用 `2024/01/01` 和 `2024-01-01` | 统一为 ISO 格式 `YYYY-MM-DD` |
| 饼图类别过多 | 10+ 类别全部放入饼图 | 合并次要类别为"其他"，控制在 7 类以内 |
