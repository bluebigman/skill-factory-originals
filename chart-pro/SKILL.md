## 三、标准执行流程

### 3.1 前置条件

1. 数据格式必须为 CSV、TSV 或 Excel 粘贴文本
2. 数据首行应为表头（列名）
3. 数据中不得包含合并单元格
4. 文件路径需为绝对路径或相对当前工作目录的有效路径

### 3.2 执行步骤

**步骤 1：接收数据**

- 用户提供数据（粘贴/上传/路径）
- 系统自动识别数据格式与维度
- 输出数据预览（前 5 行）

**步骤 2：确认参数**

| 参数 | 是否必填 | 默认值 | 可选值 |
|------|----------|--------|--------|
| 图表类型 | 否 | 自动选型 | 柱状图/折线图/饼图/散点图/面积图/箱线图 |
| 标题 | 否 | 数据文件名或"未命名图表" | 任意字符串 |
| X 轴名称 | 否 | 第一列列名 | 任意字符串 |
| Y 轴名称 | 否 | 第二列列名 | 任意字符串 |
| 配色方案 | 否 | 商务蓝 | 商务蓝/暖阳橙/森林绿/樱花粉/石墨灰/自定义 |
| 输出格式 | 否 | PNG | PNG/SVG/PDF |
| 标签开关 | 否 | 开启 | 开启/关闭 |

**步骤 3：数据校验**

- 检查行列数：至少 2 行 × 2 列
- 检查数据类型：数值列必须为数字，否则报错
- 检查缺失值：标记为 `[需核实:缺失值位置]`
- 检查异常值：超出 3 倍标准差的值标记为异常

**步骤 4：图表生成**

自动选型规则：

| 数据特征 | 推荐图表 |
|----------|----------|
| 2 列数据，第一列为类别 | 柱状图 |
| 第一列为日期/时间 | 折线图 |
| 单列数据，计算占比 | 饼图 |
| 两列均为数值 | 散点图 |
| 多列时间序列 | 面积图 |
| 包含分组统计 | 箱线图 |

**步骤 5：输出交付**

- 生成图表文件（PNG/SVG/PDF）
- 附带图表解读说明（数据要点、趋势、异常值提示）
- 输出文件路径与预览

**步骤 6：确认满意度**

- 询问是否需要调整样式、颜色、标签等
- 根据反馈重新生成

### 3.3 输出规范

输出结构：

## 六、FAQ 反模式

### 6.1 常见坑

| 坑点 | 反模式示例 | 正确做法 |
|------|------------|----------|
| 数据格式混乱 | 混用逗号和分号作为分隔符 | 统一使用逗号或制表符 |
| 表头缺失 | 第一行就是数据 | 确保首行为列名 |
| 日期格式不统一 | 混用 2024/01/01 和 2024-01-01 | 统一为 ISO 格式 YYYY-MM-DD |
| 忽略异常值 | 直接生成图表，不检查异常值 | 先查看异常值提示，确认是否需处理 |
| 过度自定义 | 同时修改 10+ 个参数导致生成失败 | 分步调整，每次修改 2-3 个参数 |

### 6.2 反模式对照表

| 反模式 | 问题 | 替代方案 |
|--------|------|----------|
| 盲目使用自动选型 | 自动选型可能不符合业务场景 | 明确指定图表类型 |
| 忽略数据校验结果 | 缺失值导致图表失真 | 先处理缺失值再生成 |
| 使用默认标题 | 图表无法区分 | 自定义有意义的标题 |
| 不检查输出文件 | 生成失败但未察觉 | 确认输出路径与文件大小 |
