# 文档风格迁移专家

文档风格迁移专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 先提风格 | 从参考文档提取语气与句式 |
| 保留信息 | 迁移只改表达不改事实 |
| 术语不换 | 专业术语保持原样 |
| 适配读者 | 按目标读者调难度 |
| 迁移后比对 | 与原文逐段核对信息量 |
