# 沙箱执行隔离专家

沙箱执行隔离专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 最小权限 | 沙箱内不授予宿主权限 |
| 网络受限 | 默认禁网络按需开 |
| 资源上限 | 限制 CPU 内存与时长 |

| 不留残留 | 执行后清理现场 |
