# 创建与规格（creation）

> 本页说明：**这个技能能做什么、在什么情况下产出什么**。
> 来源：包内 `SKILL.md` 能力清单 + `config.json` 规则表。

## 一、能力清单（情境 → 动作）

| 情境（when） | 动作（then） |
|---|---|
| 到菜场再想 | 先出清单：按菜单反推，标注用量 |
| 一次买太多叶菜 | 叶菜只买 3 天量：后面几天用耐放的（白菜/根茎） |
| 不写用量 | 写份量：如「青菜 2 把」「肉 500g」，避免估错 |
| 不分区买 | 按区域排：先干货后生鲜，减少走回头路 |

## 能力边界（契约 · R1）（来自 SKILL.md）

- **能做**：针对 买菜、清单、采购、到菜场再想、一次买太多叶菜、不写用量、不分区买 等情境，输出归因清单与可执行动作
- **不做**：心理/医学诊断；涉自伤、重度抑郁等情况**转介专业机构**
- **输入**：纯文本（`--text` 或 `--input <文件>` 或标准输入）
- **输出**：人类可读 Markdown + **JSON 摘要**（`ok`/`summary`/`next_actions`/`error_code`）
