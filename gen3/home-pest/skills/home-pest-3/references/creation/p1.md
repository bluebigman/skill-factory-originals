## 能力边界（契约 · R1）（来自 SKILL.md）

- **能做**：针对 预防、不再有、防虫、垃圾不过夜、食物敞开放、不封缝隙 等情境，输出归因清单与可执行动作
- **不做**：心理/医学诊断；涉自伤、重度抑郁等情况**转介专业机构**
- **输入**：纯文本（`--text` 或 `--input <文件>` 或标准输入）
- **输出**：人类可读 Markdown + **JSON 摘要**（`ok`/`summary`/`next_actions`/`error_code`）
