# 与平台同类对比

> **这份文件回答：「比平台上现有的强在哪」**

> 平台同类只可观测到名称与描述，**内部实现拿不到**，
> 所以本表只比可观测项，不臆测对方内部逻辑。

## 一、可观测项对比

| 对比项 | 平台同类（观测值） | 本资产 | 证据 |
|---|---|---|---|
| 名称结构 | 多为「XX专家」单段 | **用户原话 13 字** | displayName |
| 能力拆分 | 通常单一能力 | **3 个技能** | SKILL.md 能力表 |
| 规则条数 | 不可观测 | **11 条** | config.json |
| 是否给「不要做什么」 | 不可观测 | **每条规则都有** | config.json |
| 输出结构 | 不可观测 | **9 字段 dict** | main.py |
| 边界声明 | 部分有 | **有 + 转介条件** | SKILL.md |
| selftest | 不可观测 | **有，8 类断言** | selftest.py |
| 能力基准 | 无 | **有，0 任务** | benchmark.md |
| 证据链 | 无 | **有，merkle 可验** | .phoenix/evidence.json |
| A2A 能力名片 | 无 | **有** | agent-card.json |

## 二、明确不宣称的

以下内容我**无法证明优于同类**，所以不写进卖点：
- 判断准确率比对方高（对方内部逻辑不可见）
- 用户满意度更高（无数据）
- 响应更快（无对照）

## 三、可以硬声明的

| 声明 | 依据 |
|---|---|
| 输出是结构化 dict，可被程序消费 | main.py 返回 JSON |
| 每条建议都配「不要做什么」 | config.json 每条 rule 含反向动作 |
| 有可复现的能力基准 | benchmark.md 30 个任务 |
| 有可验证的证据链 | merkle 根 + 逐文件 sha256 |
| 自带 A2A 能力名片 | agent-card.json |
