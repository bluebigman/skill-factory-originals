# 创建与规格（creation）

> 本页说明：**这个技能能做什么、在什么情况下产出什么**。
> 来源：包内 `SKILL.md` 能力清单 + `config.json` 规则表。

## 一、能力清单（情境 → 动作）

| 情境（when） | 动作（then） |
|---|---|
| 直接给普通饭菜 | 改形态：切碎/炖烂/打成泥，比换食材有效 |
| 只给粥 | 要蛋白：粥缺蛋白，加蛋羹/鱼肉泥/豆腐 |
| 炖很久但没味道 | 调味后放：长时间炖会失味，起锅前再调味 |
| 只吃素食 | 加蛋奶豆：老人蛋白需求不比年轻人低 |

## 能力边界（契约 · R1）（来自 SKILL.md）

- **能做**：针对 老人、咬不动、软烂、吃不下、直接给普通饭菜、只给粥、炖很久但没味道、只吃素食 等情境，输出归因清单与可执行动作
- **不做**：心理/医学诊断；涉自伤、重度抑郁等情况**转介专业机构**
- **输入**：纯文本（`--text` 或 `--input <文件>` 或标准输入）
- **输出**：人类可读 Markdown + **JSON 摘要**（`ok`/`summary`/`next_actions`/`error_code`）
