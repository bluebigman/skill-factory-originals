# 创建与规格（creation）

> 本页说明：**这个技能能做什么、在什么情况下产出什么**。
> 来源：包内 `SKILL.md` 能力清单 + `config.json` 规则表。

## 一、能力清单（情境 → 动作）

| 情境（when） | 动作（then） |
|---|---|
| 一次盛一大碗 | 少量多餐：一天 5-6 次小份，比三大碗有效 |
| 只做清淡 | 适度调味：老人味觉退化，太淡反而没胃口 |
| 不记录吃了多少 | 记录：连续 3 天吃不到平时一半要就医 |
| 只关注吃 | 关注口腔：牙不好/假牙不合会直接影响进食 |

## 能力边界（契约 · R1）（来自 SKILL.md）

- **能做**：针对 吃不下、没胃口、食欲、一次盛一大碗、只做清淡、不记录吃了多少、只关注吃 等情境，输出归因清单与可执行动作
- **不做**：心理/医学诊断；涉自伤、重度抑郁等情况**转介专业机构**
- **输入**：纯文本（`--text` 或 `--input <文件>` 或标准输入）
- **输出**：人类可读 Markdown + **JSON 摘要**（`ok`/`summary`/`next_actions`/`error_code`）
