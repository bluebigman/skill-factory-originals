# 创建与规格（creation）

> 本页说明：**这个技能能做什么、在什么情况下产出什么**。
> 来源：包内 `SKILL.md` 能力清单 + `config.json` 规则表。

## 一、能力清单（情境 → 动作）

| 情境（when） | 动作（then） |
|---|---|
| 只扔不控 | 控制入口：每月整理一次新进物品 |
| 没有固定位置 | 一物一位：新物品必须有位置才带回家 |

| 全家只你整理 | 全家参与：只你一个人整理必然反弹 |

## 能力边界（契约 · R1）（来自 SKILL.md）

- **能做**：针对 反弹、不反弹、维持、只扔不控、没有固定位置、买东西不看现有、全家只你整理 等情境，输出归因清单与可执行动作
- **不做**：心理/医学诊断；涉自伤、重度抑郁等情况**转介专业机构**
- **输入**：纯文本（`--text` 或 `--input <文件>` 或标准输入）
- **输出**：人类可读 Markdown + **JSON 摘要**（`ok`/`summary`/`next_actions`/`error_code`）
