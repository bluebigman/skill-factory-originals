# 环境与配置（environment）

> 本页说明：**运行需要什么、边界在哪、出错怎么降级**。
> 来源：包内 `config.json` 的 boundary / encoding_fallback / errors。

## 一、能力边界

怎么不再堆

**为什么必须有边界**：越界承诺（如「保证治愈」「稳赚不赔」）会触发平台红线，
且会误导用户把通用方法当成专业结论。

## 二、运行环境

| 项 | 要求 |
|---|---|
| Python | 3.8+（只用标准库，无第三方依赖）|
| 入口 | `run.py --text "<你的输入>"` |
| 配置 | 同目录 `config.json`（规则与关键词）|
| 自测 | `python scripts/main.py --selftest` |

## 三、编码降级链

读取外部文本时按以下顺序尝试，任一步成功即停：

1. `utf-8`
2. `gbk`
3. `gb18030`

全部失败 ⇒ 以 `utf-8` + `errors=ignore` 读取并标注「编码异常」，**不中断**。

## 四、错误码

| 码 | 含义 | 处置 |
|---|---|---|
| E01 | 输入缺失 | 提示提供 `--text` |
| E02 | 配置不可读 | 返回空结果并说明 |
| E03 | 输入超长 | 截断后处理并标注 |

## 五、异常降级原则

每个异常分支**必须有降级输出**，并留下可查痕迹；**禁止静默吞异常**。
理由：静默吞会让「跑完显示全部通过」变成假象，掩盖真实失败。

## 六、降级行为细表

| 异常 | 降级输出 | 是否可重试 | 留痕方式 |
|---|---|---|---|
| config.json 缺失 | 用空规则集，返回 unknown 并说明 | 否 | FAILURES |
| config.json 格式错 | 同上，附错误类型 | 否 | FAILURES |
| 输入非 UTF-8 | 按降级链重试 | 是 | 输出标注编码 |
| 输入超长 | 截断到上限并标注原长 | 是 | 输出标注截断 |
| 规则表为空 | 直接返回 unknown | 否 | FAILURES |

## 七、常见配置故障排查

1. **改了规则但行为没变** ⇒ 检查是否改了正确技能的 config.json（多技能包易混）
2. **关键词命中了但没动作** ⇒ 关键词只做召回，动作来自 rules；两者要配套
3. **中文乱码** ⇒ 确认读取时走降级链，且写入统一 UTF-8
4. **自测通过但实际不准** ⇒ 自测只验结构，语义准确度要用真实输入抽检

## 能力边界（契约 · R1）（来自 SKILL.md）

- **能做**：针对 反弹、不反弹、维持、只扔不控、没有固定位置、买东西不看现有、全家只你整理 等情境，输出归因清单与可执行动作
- **不做**：心理/医学诊断；涉自伤、重度抑郁等情况**转介专业机构**
- **输入**：纯文本（`--text` 或 `--input <文件>` 或标准输入）
- **输出**：人类可读 Markdown + **JSON 摘要**（`ok`/`summary`/`next_actions`/`error_code`）
