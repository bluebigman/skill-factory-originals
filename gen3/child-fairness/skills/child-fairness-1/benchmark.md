## 二、怎么复现

```bash

unzip child-fairness.zip -d /tmp/pkg
# 跑单个任务
python /tmp/pkg/child-fairness/skills/child-fairness-1/scripts/main.py --text "<上面的输入>"
# 跑自检
python /tmp/pkg/child-fairness/skills/child-fairness-1/selftest.py
```

## 三、得分口径（可被质疑）

| 项 | 说明 |
|---|---|
| 命中判定 | 输出里出现该规则建议的前 8 个字即算命中 |
| 干扰项 | 输入无关内容或空输入时，必须明确说「未命中/信息不足」，不得硬给建议 |
| 未做手脚 | 未命中就写未命中，没有删除失败任务 |

- 不替代专业判断（见 SKILL.md 边界声明）
