# 创建与规格（creation）

> 本页说明：**这个技能能做什么、在什么情况下产出什么**。
> 来源：包内 `SKILL.md` 能力清单 + `config.json` 规则表。

## 一、能力清单（情境 → 动作）

| 情境（when） | 动作（then） |
|---|---|
| 想加入但不会开口 | 是技能不足：教具体的加入句式 |
| 被特定小团体排斥 | 是关系问题：需要学校介入 |
| 只和一两个固定朋友玩 | 是正常：不需要扩大社交圈 |
| 被起外号后动手 | 是情绪反应：先教应对语言再教情绪调节 |

## 能力边界（契约 · R1）（来自 SKILL.md）

- **能做**：针对 没朋友、处不好、起外号、不会玩、想加入但不会开口、被特定小团体排斥、只和一两个固定朋友玩、被起外号后动手 等情境，输出归因清单与可执行动作
- **不做**：心理/医学诊断；涉自伤、重度抑郁等情况**转介专业机构**
- **输入**：纯文本（`--text` 或 `--input <文件>` 或标准输入）
- **输出**：人类可读 Markdown + **JSON 摘要**（`ok`/`summary`/`next_actions`/`error_code`）
