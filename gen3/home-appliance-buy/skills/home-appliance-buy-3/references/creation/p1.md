# 创建与规格（creation）

> 本页说明：**这个技能能做什么、在什么情况下产出什么**。
> 来源：包内 `SKILL.md` 能力清单 + `config.json` 规则表。

## 一、能力清单（情境 → 动作）

| 情境（when） | 动作（then） |
|---|---|
| 随时买 | 等节点：大促/新品上市旧款降价 |
| 买最新款 | 买次新：新款溢价高，次新性价比好 |
| 不比对 | 比三家：同型号不同渠道价差可观 |
| 不买延保 | 看品类：大件可考虑，小件不必 |

## 三、召回词（用于识别用户是否在问本技能范围内的事）

`什么时候买`、`便宜`、`时机`、`随时买`、`买最新款`、`不比对`、`不买延保`

> 命中任一召回词 ⇒ 进入本技能；全不命中 ⇒ 明确告知超出范围。

## 能力边界（契约 · R1）（来自 SKILL.md）

- **能做**：针对 什么时候买、便宜、时机、随时买、买最新款、不比对、不买延保 等情境，输出归因清单与可执行动作
- **不做**：心理/医学诊断；涉自伤、重度抑郁等情况**转介专业机构**
- **输入**：纯文本（`--text` 或 `--input <文件>` 或标准输入）
- **输出**：人类可读 Markdown + **JSON 摘要**（`ok`/`summary`/`next_actions`/`error_code`）
