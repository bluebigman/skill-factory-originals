# 创建与规格（creation）

> 本页说明：**这个技能能做什么、在什么情况下产出什么**。
> 来源：包内 `SKILL.md` 能力清单 + `config.json` 规则表。

## 一、能力清单（情境 → 动作）

| 情境（when） | 动作（then） |
|---|---|
| 只讲生理知识 | 必须讲感受：变化是正常的、每个人时间不同、不需要比较 |
| 只讲注意事项 | 讲应对：长痘怎么护理、月经怎么处理、情绪波动怎么调 |
| 不谈边界与保护 | 必须谈：身体自主权、什么触碰不可以、遇到怎么办 |
| 用羞耻性语言 | 用中性词：用正确器官名称，不用代称 |

## 能力边界（契约 · R1）（来自 SKILL.md）

- **能做**：针对 讲什么、只讲生理知识、只讲注意事项、不谈边界与保护、用羞耻性语言 等情境，输出归因清单与可执行动作
- **不做**：心理/医学诊断；涉自伤、重度抑郁等情况**转介专业机构**
- **输入**：纯文本（`--text` 或 `--input <文件>` 或标准输入）
- **输出**：人类可读 Markdown + **JSON 摘要**（`ok`/`summary`/`next_actions`/`error_code`）
