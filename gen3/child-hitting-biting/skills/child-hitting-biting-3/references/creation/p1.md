# 创建与规格（creation）

> 本页说明：**这个技能能做什么、在什么情况下产出什么**。
> 来源：包内 `SKILL.md` 能力清单 + `config.json` 规则表。

## 一、能力清单（情境 → 动作）

| 情境（when） | 动作（then） |
|---|---|
| 只说「不许打」 | 必须给替代：教他说「我不要」「等一下」「帮我」三句话 |
| 在家里演练 | 用角色扮演练：家长演抢玩具的人，让他练说那句话 |
| 只在事后教 | 在平静时教，事发时只用最短句制止 |
| 忽略进步 | 每次他自己用语言替代了动手，立刻具体表扬 |

## 能力边界（契约 · R1）（来自 SKILL.md）

- **能做**：针对 替代、教什么、不打人、怎么教、只说「不许打」、在家里演练、只在事后教、忽略进步 等情境，输出归因清单与可执行动作
- **不做**：心理/医学诊断；涉自伤、重度抑郁等情况**转介专业机构**
- **输入**：纯文本（`--text` 或 `--input <文件>` 或标准输入）
- **输出**：人类可读 Markdown + **JSON 摘要**（`ok`/`summary`/`next_actions`/`error_code`）
