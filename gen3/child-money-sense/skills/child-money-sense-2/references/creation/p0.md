# 创建与规格（creation）

> 本页说明：**这个技能能做什么、在什么情况下产出什么**。
> 来源：包内 `SKILL.md` 能力清单 + `config.json` 规则表。

## 一、能力清单（情境 → 动作）

| 情境（when） | 动作（then） |
|---|---|
| 要就给 | 固定周期固定金额：不因表现好坏增减（那是奖励不是零花） |
| 给很少怕乱花 | 给够：太少学不会规划，建议按同龄中位水平 |
| 花超了再补 | 不补：超支就等下次，这是最有效的财商课 |
| 要求记账但不看 | 每周一起看一次账：只问「这笔值吗」，不评判 |

## 能力边界（契约 · R1）（来自 SKILL.md）

- **能做**：针对 零花钱、怎么给、规则、金额、要就给、给很少怕乱花、花超了再补、要求记账但不看 等情境，输出归因清单与可执行动作
- **不做**：心理/医学诊断；涉自伤、重度抑郁等情况**转介专业机构**
- **输入**：纯文本（`--text` 或 `--input <文件>` 或标准输入）
- **输出**：人类可读 Markdown + **JSON 摘要**（`ok`/`summary`/`next_actions`/`error_code`）
