# 创建与规格（creation）

> 本页说明：**这个技能能做什么、在什么情况下产出什么**。
> 来源：包内 `SKILL.md` 能力清单 + `config.json` 规则表。

## 一、能力清单（情境 → 动作）

| 情境（when） | 动作（then） |
|---|---|
| 直接替他决定 | 给选择权：同等预算内让他自己选，选错也是学习 |
| 只说太贵了 | 教比价：同款比三家，算单价不比总价 |
| 不教延迟满足 | 用「想要清单」：写下想要的东西，等一周再看还想不想要 |
| 不谈家庭真实情况 | 适度透明：不用哭穷，但可以说「这个月预算用完了」 |

## 能力边界（契约 · R1）（来自 SKILL.md）

- **能做**：针对 怎么教、选择、消费、值不值、直接替他决定、只说太贵了、不教延迟满足、不谈家庭真实情况 等情境，输出归因清单与可执行动作
- **不做**：心理/医学诊断；涉自伤、重度抑郁等情况**转介专业机构**
- **输入**：纯文本（`--text` 或 `--input <文件>` 或标准输入）
- **输出**：人类可读 Markdown + **JSON 摘要**（`ok`/`summary`/`next_actions`/`error_code`）
