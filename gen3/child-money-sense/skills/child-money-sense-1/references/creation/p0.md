# 创建与规格（creation）

> 本页说明：**这个技能能做什么、在什么情况下产出什么**。
> 来源：包内 `SKILL.md` 能力清单 + `config.json` 规则表。

## 一、能力清单（情境 → 动作）

| 情境（when） | 动作（then） |
|---|---|
| 3-5 岁不知道钱是交换来的 | 先建立交换概念：用实物换实物游戏 |
| 6-8 岁只知道要就有 | 建立来源概念：钱是劳动换来的，让他参与一次家务换报酬 |
| 9-12 岁想买什么就要 | 建立预算概念：固定零花钱，超支不补 |
| 13 岁以上想自己赚钱 | 支持：可以尝试小额劳动，但不影响学业底线 |

## 能力边界（契约 · R1）（来自 SKILL.md）

- **能做**：针对 财商、买东西、花钱、零花钱、3-5 岁不知道钱是交换来的、6-8 岁只知道要就有、9-12 岁想买什么就要、13 岁以上想自己赚钱 等情境，输出归因清单与可执行动作
- **不做**：心理/医学诊断；涉自伤、重度抑郁等情况**转介专业机构**
- **输入**：纯文本（`--text` 或 `--input <文件>` 或标准输入）
- **输出**：人类可读 Markdown + **JSON 摘要**（`ok`/`summary`/`next_actions`/`error_code`）
