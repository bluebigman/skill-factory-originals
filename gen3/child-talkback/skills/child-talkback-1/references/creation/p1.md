# 创建与规格（creation）

> 本页说明：**这个技能能做什么、在什么情况下产出什么**。
> 来源：包内 `SKILL.md` 能力清单 + `config.json` 规则表。

## 一、能力清单（情境 → 动作）

| 情境（when） | 动作（then） |
|---|---|
| 只在被指责时反驳 | 是防御反应：先停止指责，改为描述事实 |
| 开始有自己的观点并争论 | 是正常独立（尤其青春期）：要争论而非压制 |
| 完全不说话直接关门 | 关系信号：先修复关系再谈事，此时讲道理无效 |
| 说「你们根本不爱我」 | 情绪表达而非事实陈述，先接住情绪不辩论事实 |

## 能力边界（契约 · R1）（来自 SKILL.md）

- **能做**：针对 顶嘴、反驳、不说话、关门、别管我、只在被指责时反驳、开始有自己的观点并争论、完全不说话直接关门、说「你们根本不爱我」 等情境，输出归因清单与可执行动作
- **不做**：心理/医学诊断；涉自伤、重度抑郁等情况**转介专业机构**
- **输入**：纯文本（`--text` 或 `--input <文件>` 或标准输入）
- **输出**：人类可读 Markdown + **JSON 摘要**（`ok`/`summary`/`next_actions`/`error_code`）
