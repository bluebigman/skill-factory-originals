# 创建与规格（creation）

> 本页说明：**这个技能能做什么、在什么情况下产出什么**。
> 来源：包内 `SKILL.md` 能力清单 + `config.json` 规则表。

## 一、能力清单（情境 → 动作）

| 情境（when） | 动作（then） |
|---|---|
| 只谈不许 | 给具体边界：不影响睡眠/不单独去私密空间/不涉及金钱往来 |
| 不谈性教育与保护 | 必须谈：以「保护自己」为切口，不谈道德评判 |
| 只关注学业影响 | 同时关注情绪：失恋的打击常大于学业影响 |
| 一次谈完 | 保持开放：让他知道任何时候都能来找你 |

## 能力边界（契约 · R1）（来自 SKILL.md）

- **能做**：针对 边界、底线、引导、只谈不许、不谈性教育与保护、只关注学业影响、一次谈完 等情境，输出归因清单与可执行动作
- **不做**：心理/医学诊断；涉自伤、重度抑郁等情况**转介专业机构**
- **输入**：纯文本（`--text` 或 `--input <文件>` 或标准输入）
- **输出**：人类可读 Markdown + **JSON 摘要**（`ok`/`summary`/`next_actions`/`error_code`）
