# 创建与规格（creation）

> 本页说明：**这个技能能做什么、在什么情况下产出什么**。
> 来源：包内 `SKILL.md` 能力清单 + `config.json` 规则表。

## 一、能力清单（情境 → 动作）

| 情境（when） | 动作（then） |
|---|---|
| 坐在旁边一直纠正 | 不打断，先让他写完一整段再统一说问题 |
| 一错就说这么简单都不会 | 禁止评价能力，只描述事实「这道题再看一遍条件」 |
| 全程盯着 | 改成定时查看（每 15 分钟一次），把责任还给孩子 |
| 孩子问就立刻给答案 | 先反问「你觉得第一步该做什么」，让他自己启动 |

## 能力边界（契约 · R1）（来自 SKILL.md）

- **能做**：针对 陪写、辅导、检查、家长怎么做、坐在旁边一直纠正、一错就说这么简单都不会、全程盯着、孩子问就立刻给答案 等情境，输出归因清单与可执行动作
- **不做**：心理/医学诊断；涉自伤、重度抑郁等情况**转介专业机构**
- **输入**：纯文本（`--text` 或 `--input <文件>` 或标准输入）
- **输出**：人类可读 Markdown + **JSON 摘要**（`ok`/`summary`/`next_actions`/`error_code`）
