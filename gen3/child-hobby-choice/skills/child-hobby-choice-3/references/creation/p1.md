# 创建与规格（creation）

> 本页说明：**这个技能能做什么、在什么情况下产出什么**。
> 来源：包内 `SKILL.md` 能力清单 + `config.json` 规则表。

## 一、能力清单（情境 → 动作）

| 情境（when） | 动作（then） |
|---|---|
| 一说不去就退 | 先分清「平台期」与「真不喜欢」：平台期通常在第 3-8 次课 |
| 逼着必须坚持 | 给期限：「再上 4 次，如果还是不想就停」 |
| 同时上三个班 | 总量控制：一周不超过 2 个班，留白时间比课程重要 |
| 停了就再也不碰 | 停止不等于否定：保留相关体验（如不学琴但可以听音乐会） |

## 能力边界（契约 · R1）（来自 SKILL.md）

- **能做**：针对 放弃、坚持、不想去、退班、一说不去就退、逼着必须坚持、同时上三个班、停了就再也不碰 等情境，输出归因清单与可执行动作
- **不做**：心理/医学诊断；涉自伤、重度抑郁等情况**转介专业机构**
- **输入**：纯文本（`--text` 或 `--input <文件>` 或标准输入）
- **输出**：人类可读 Markdown + **JSON 摘要**（`ok`/`summary`/`next_actions`/`error_code`）
