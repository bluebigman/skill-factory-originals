# 演示文稿大纲专家

演示文稿大纲专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 一页一义 | 每页只讲一个观点，多观点必拆页 |
| 结论前置 | 每页标题写结论而非话题 |
| 三幕结构 | 背景-冲突-方案，缺一则听众失焦 |
| 图表配一句 | 图表下必配一句话结论 |
| 页数与时长 | 按每分钟一页估算，超时即删非核心页 |
