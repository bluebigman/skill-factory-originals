# 上下文优专家

上下文优专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 分块合理 | 按语义边界分块不硬切 |
| 召回优先 | 先提召回再提精度 |
| 去冗余 | 重复上下文合并 |
| 关键保真 | 关键约束不得在压缩中丢失 |
| 长文处理 | 超长文档用检索而非全文注入 |
