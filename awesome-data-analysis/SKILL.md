## 三、标准工作流程

### 3.1 前置条件

| 条件项 | 要求 | 说明 |
|--------|------|------|
| 用户输入 | 明确的学习目标或查询主题 | 模糊输入将触发澄清流程 |
| 上下文 | 用户基础水平（可选） | 有助于定制推荐深度 |
| 时间预算 | 每日可投入时间（可选） | 用于规划学习周期 |

### 3.2 执行步骤

**步骤1：意图识别（输入解析）**

- 从用户输入中提取关键词，映射到资源库分类
- 分类维度：语言（Python/SQL/R）、领域（统计/ML/AI/可视化）、水平（入门/进阶/专家）

**步骤2：资源匹配**

- 在500+资源库中按相关性排序
- 匹配优先级：主题精确度 > 资源质量 > 更新时间 > 用户水平适配

**步骤3：结构化输出**

- 按"学习路径"或"资源清单"格式组织
- 每个资源包含：名称、类型（教程/书籍/工具/社区）、难度、一句话简介

**步骤4：置信度标注**

- 对资源推荐给出置信度：高（明确匹配）/ 中（部分匹配）/ 低（推测匹配）
- 置信度低于60%时，主动提示用户补充信息

**步骤5：自查校验**

- 检查输出是否覆盖用户核心问题
- 检查资源分类是否准确
- 检查置信度标注是否完整

### 3.3 输出规范

