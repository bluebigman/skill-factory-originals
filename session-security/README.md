# 会话安全专家

会话安全专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 令牌短时效 | 访问令牌短期有效 |
| 刷新分离 | 刷新令牌单独存放 |
| 登出即失效 | 登出后令牌立即失效 |
| 绑定信息 | 必要时绑定设备或 IP 段 |
| 并发限制 | 限制同账号并发会话 |
