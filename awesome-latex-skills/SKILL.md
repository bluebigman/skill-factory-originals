## 三、标准工作流程

### 3.1 前置条件

在提问前，请尽量准备以下材料（按优先级排列）：

| 优先级 | 材料 | 说明 |
|--------|------|------|
| P0 | 完整错误信息 | `.log` 文件末尾 20-30 行，或 Overleaf 红色报错框原文 |
| P1 | 最小工作示例（MWE） | 能复现问题的最简 `.tex` 文件，去掉无关章节 |
| P2 | 环境描述 | 编译器类型、宏包版本（`\listfiles` 输出）、操作系统 |
| P3 | 期望行为 | 如"编译通过"、"图表在正确位置"、"符合某期刊格式" |

### 3.2 执行步骤

**步骤 1：信息收集与确认**

- 我会先确认你提供的报错信息是否完整。
- 如果信息不足，我会明确列出缺失项，并给出获取方式（如"请提供 `.log` 文件末尾 20 行"）。

**步骤 2：错误定位与根因分析**

- 根据报错信息，定位到具体的宏包、命令或环境。
- 区分三类错误：
  - **语法错误**：拼写、括号不匹配、命令未定义。
  - **宏包冲突**：两个宏包加载顺序或选项冲突。
  - **资源缺失**：图片文件找不到、`.bib` 文件路径错误。

**步骤 3：输出修正方案**

- 提供可直接替换的代码片段。
- 给出修改前后的对比说明。
- 标注修改的风险等级（低/中/高）。

**步骤 4：验证建议**

- 建议你如何验证修复是否生效（如重新编译、检查 `.log` 特定行）。
- 如果问题涉及多个宏包，建议分步排查。

### 3.3 输出规范

所有输出遵循以下格式：

**代码片段**：

```latex

% 修改后
\usepackage[pdftex]{graphicx}
```

**对照表**（用于模板适配场景）：

| 项目 | 模板要求 | 当前状态 | 差距 | 修改命令 |

## 五、错误码体系

以下为常见 LaTeX 错误码速查表。遇到报错时，对照查找提示话术与修正步骤。

### 5.1 语法类错误

| 错误码 | 典型报错 | 提示话术 | 修正步骤 |
|--------|----------|----------|----------|
| E-001 | `! Undefined control sequence.` | 命令拼写错误或未定义 | 1. 检查命令拼写；2. 确认宏包已加载；3. 检查是否在错误环境中使用 |
| E-002 | `! Missing $ inserted.` | 数学模式未正确进入或退出 | 1. 检查是否在文本模式使用了数学命令；2. 确认 `$...$` 或 `\[...\]` 配对 |
| E-003 | `! Extra }, or forgotten $.` | 括号不匹配或数学模式嵌套错误 | 1. 检查 `{` `}` 配对；2. 检查 `\left` `\right` 配对 |
| E-004 | `! Misplaced alignment tab character &.` | `&` 在非表格环境中使用 | 1. 确认 `&` 仅在 `tabular` / `align` 等环境中使用；2. 检查是否缺少 `\\` |

### 5.2 宏包类错误

| 错误码 | 典型报错 | 提示话术 | 修正步骤 |
|--------|----------|----------|----------|
| E-101 | `! LaTeX Error: File 'xxx.sty' not found.` | 宏包未安装或路径错误 | 1. 确认宏包名称拼写；2. 检查宏包是否已安装；3. Overleaf 用户检查是否在左侧文件树中上传了 `.sty` 文件 |
| E-102 | `! Package xxxx Error: Option clash.` | 宏包选项冲突 | 1. 检查是否重复加载宏包；2. 合并 `\usepackage` 选项；3. 使用 `\PassOptionsToPackage` 预传选项 |
| E-103 | `! LaTeX Error: Too many unprocessed floats.` | 浮动体过多未处理 | 1. 增加 `\clearpage` 或 `\FloatBarrier`；2. 使用 `[H]` 位置参数；3. 减少浮动体数量 |

### 5.3 资源类错误

| 错误码 | 典型报错 | 提示话术 | 修正步骤 |
|--------|----------|----------|----------|
| E-201 | `! LaTeX Error: File 'figure.png' not found.` | 图片文件路径错误或文件缺失 | 1. 检查文件名拼写；2. 确认图片在正确目录；3. 使用相对路径或 `\graphicspath` |
| E-202 | `! Package natbib Error: Bibliography not compatible with author-year citations.` | 参考文献样式与引用方式不匹配 | 1. 检查 `\bibliographystyle` 是否支持 author-year；2. 更换样式或改用 `\citep` / `\citet` |
| E-203 | `! Package inputenc Error: Unicode character ... not set up.` | 编码问题 | 1. 使用 XeLaTeX 或 LuaLaTeX；2. 加载 `\usepackage[utf8]{inputenc}`；3. 检查特殊字符转义 |

### 5.4 使用方式

遇到报错时，按以下流程操作：

1. **复制报错原文**：完整复制 `.log` 文件末尾 20-30 行，或 Overleaf 红色报错框内容。
2. **对照错误码表**：在 5.1-5.3 节中查找对应错误码。

## 六、常见坑与反模式

### 6.1 反模式对照表

| 反模式 | 典型表现 | 正确做法 |
|--------|----------|----------|
| **报错信息截断** | 只复制报错第一行，忽略后续上下文 | 提供 `.log` 文件末尾 20-30 行，或 Overleaf 红色报错框完整内容 |
| **无 MWE 直接提问** | 贴出 200 行完整论文代码 | 先尝试精简到最小可复现示例，去掉无关章节和宏包 |
| **忽略宏包版本** | 不提供 `\listfiles` 输出 | 在问题描述中附带宏包版本信息，便于排查版本兼容性 |
| **盲目升级宏包** | 报错后直接升级所有宏包 | 先定位具体错误，再针对性调整宏包版本或选项 |
| **混用编译器** | 本地用 pdfLaTeX，Overleaf 用 XeLaTeX | 明确说明使用的编译器类型，确保环境一致性 |

### 6.2 常见坑位详解

**坑位 1：`\usepackage` 顺序不当**

- **表现**：宏包加载顺序导致选项冲突或命令覆盖。
- **示例**：`\usepackage{hyperref}` 放在 `\usepackage{cite}` 之前可能导致引用链接失效。
- **建议**：将 `hyperref` 放在导言区最后加载。

**坑位 2：浮动体位置参数滥用**

- **表现**：`[h]` 参数导致图表堆积在页面顶部或底部。
- **示例**：连续多个 `\begin{figure}[h]` 可能导致浮动体无法放置。
- **建议**：使用 `[htbp]` 组合参数，或使用 `\FloatBarrier` 强制分隔。

**坑位 3：中文文档编译引擎选择错误**

- **表现**：使用 pdfLaTeX 编译中文文档出现乱码或报错。
- **示例**：`! Package inputenc Error: Unicode character 你 (U+4F60) not set up.`
- **建议**：改用 XeLaTeX 或 LuaLaTeX，并加载 `ctex` 宏包。

**坑位 4：参考文献样式与引用命令不匹配**

- **表现**：`natbib` 报错或引用格式不符合期刊要求。
- **示例**：使用 `\citep` 但 `\bibliographystyle` 设置为 `plain`。
- **建议**：确认期刊要求的引用样式，选择对应的 `.bst` 文件。

**坑位 5：图片格式与编译器不兼容**

- **表现**：PDFLaTeX 无法编译 EPS 图片，或 XeLaTeX 无法编译某些格式。
- **示例**：`! LaTeX Error: Cannot determine size of graphic in figure.eps.`
- **建议**：PDFLaTeX 使用 PDF/PNG/JPG，XeLaTeX 支持更多格式，但需确认宏包支持。
