# 知识库条目专家

知识库条目专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 一篇一题 | 一条只解决一个问题 |
| 标题即问题 | 标题写成用户会搜的问句 |
| 步骤可复现 | 操作步骤含前置条件与预期结果 |
| 相互引用 | 相关条目建立双向链接 |
| 定期复核 | 标注最后复核日期 |
