# 需求文档撰写专家

需求文档撰写专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 问题先于方案 | 先写清问题再给方案 |
| 验收可测 | 每条需求配可验证的验收条件 |
| 边界明确 | 写清不做什么与异常流 |
| 依赖显式 | 列出前置依赖与外部接口 |
| 变更留痕 | 需求变更记录版本与原因 |
