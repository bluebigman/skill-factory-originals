## 三、标准流程

### 3.1 前置条件

| 条件项 | 要求 | 检查方法 |
|--------|------|----------|
| 输入格式 | 纯文本或 Markdown 列表 | 确认文件可正常打开 |
| 编码格式 | UTF-8 编码 | 避免乱码 |

| 输入大小 | 单次不超过 1000 条任务 | 超出需分批处理 |

### 3.2 执行步骤

**步骤 1：准备输入文件**

将待处理文件放入当前工作目录，确认命名规范。示例：

```
项目目录/
├── tasks.md          # 待转换的任务清单
└── output/           # 输出目录（可选）
```

**步骤 2：单样本试运行**

选取 1-2 条任务进行测试转换，核对输出格式：

```
输入：买牛奶、写周报、修复登录bug
输出：
## 待办
- [ ] 买牛奶
- [ ] 写周报
- [ ] 修复登录bug
```

**步骤 3：批量执行**

确认格式无误后，对全量数据执行转换。保留原始文件备份：

```bash
cp tasks.md tasks.backup.md
```

**步骤 4：校验结果**

抽查输出条目，核对关键字段与源数据一致：

| 检查项 | 方法 | 通过标准 |
|--------|------|----------|
| 条目完整性 | 对比源文件与输出 | 无遗漏、无多余 |
| 状态正确性 | 检查状态标记 | 状态归类准确 |
| 格式规范性 | 预览 Markdown 渲染 | 看板结构清晰 |

### 3.3 输出规范

**标准输出格式：**

```markdown
## 待办
- [ ] 任务描述

## 进行中
- [ ] 任务描述

## 已完成
- [x] 任务描述
```

**优先级标记：**

| 优先级 | 标记 | 示例 |
|--------|------|------|
| 高 | ⚠️ | `- [ ] ⚠️ 修复生产环境bug` |
| 中 | 无标记 | `- [ ] 更新文档` |
| 低 | 📌 | `- [ ] 📌 整理旧文件` |
