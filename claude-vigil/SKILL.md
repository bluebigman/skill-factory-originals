本技能用于将用户提供的原始数据（文本、文件、URL）转换为结构化的、可复用的输出结果。它面向学习、参考、数据整理等非生产性场景。

| 维度 | 说明 |
|------|------|
| **核心用途** | 将非结构化或半结构化数据，按用户指定的格式整理为结构化条目 |
| **输入类型** | 用户直接粘贴的文本、本地文件（.txt/.csv/.json/.md）、可访问的 URL 内容 |
| **输出类型** | Markdown 表格、JSON 数组、CSV 格式文本（由用户指定） |
| **处理能力** | 单条处理、批量处理（需用户提供多行/多文件输入） |
| **置信度标注** | 对提取的每个关键字段标注置信度（高/中/低），低置信度字段以 `[需核实:字段名]` 占位 |

### 能做与不能做

**能做：**

1. 解析输入内容，识别其中的关键信息（如名称、日期、数值、分类等）
2. 按用户指定的字段结构重组数据
3. 对不确定的字段值给出置信度提示，不强行编造
4. 支持批量输入（多行文本、多个文件、多个 URL）
5. 输出格式可定制（Markdown 表格 / JSON / CSV）

**不能做：**

1. 不能访问需要登录或付费墙后的 URL 内容
2. 不能处理加密文件或二进制格式（图片、PDF 扫描件等）
3. 不能对数据进行语义理解之外的推断（如预测趋势、生成建议）
4. 不能保证提取字段 100% 准确——所有提取结果均需人工复核
5. 不能替代专业工具进行数据清洗或数据库操作

**适用对象：**

- 需要快速整理零散笔记、网页摘录的学习者
- 需要将多来源数据汇总为统一格式的研究人员

## 三、标准处理流程

### 前置条件

1. 输入数据已就绪（文本已复制、文件已放入工作目录、URL 可访问）
2. 用户已明确输出格式（若未指定，默认输出 Markdown 表格）
3. 用户已明确目标字段（若未指定，使用默认字段：`名称`、`类型`、`摘要`、`来源`、`日期`）

### 执行步骤

**步骤 1：接收输入**

- 确认输入来源（文本/文件/URL）
- 确认输入规模（单条/批量）
- 确认输出格式（表格/JSON/CSV）

**步骤 2：解析内容**

- 读取输入内容，识别信息类型（文本段落、列表、表格、链接等）
- 提取候选关键信息（实体、日期、数字、专有名词）

**步骤 3：字段映射**

- 将提取的信息映射到目标字段
- 对每个字段值评估置信度：
  - **高置信度**：信息明确、无歧义
  - **中置信度**：信息存在但需上下文推断
  - **低置信度**：信息模糊或缺失 → 输出 `[需核实:字段名]`

**步骤 4：生成输出**

- 按用户指定格式组装结果
- 每条记录附带 `confidence` 字段（JSON）或置信度列（表格）

**步骤 5：自查与交付**

- 检查字段完整性（是否有遗漏字段）
- 检查格式正确性（是否符合用户指定格式）
- 检查置信度标注（低置信度字段是否已标注）
- 交付输出，并附处理说明（处理条数、耗时、注意事项）

## 四、置信度门控机制

本技能遵循“不编造”原则。当遇到以下情况时，使用占位符而非猜测值：

| 情况 | 处理方式 |
|------|----------|
| 字段值无法从输入中提取 | 输出 `[需核实:字段名]` |
| 字段值存在多种可能解释 | 输出最可能的值，置信度标为“中”，并在备注中说明 |
| 输入内容过短或信息不足 | 停止处理，向用户请求补充信息 |
| 输入内容与目标字段完全不匹配 | 提示用户调整字段定义或更换输入 |

**置信度定义：**

- **高**：字段值直接从输入中明确提取，无歧义
- **中**：字段值通过上下文推断得出，或存在轻微歧义
- **低**：字段值无法确定，已使用占位符
