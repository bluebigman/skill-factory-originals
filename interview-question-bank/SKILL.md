# 面试题库生成 Skill（interview-question-bank）

## 一、能力边界（一页纸速查卡）

本 Skill 用于将一份岗位描述（JD）转化为结构化的面试题库。它不替代面试官的专业判断，而是提供系统化的出题框架与评估参照。

| 能力维度 | 支持范围 | 不支持范围 |
|---------|---------|-----------|
| JD 解析 | 提取职责、硬技能、软素质、经验年限、职级信号 | 无法理解 JD 中的隐含文化或团队风格 |
| 题型生成 | 行为面试题（STAR）、专业技能题、压力测试题 | 不生成代码笔试题、系统设计题（可生成相关提问点） |
| 评估配套 | 每题附考察点、参考答案要点、1-5 分评分标准 | 不提供绝对正确答案（开放式问题） |
| 难度分级 | 基础 / 进阶 / 高级 三档，按职级自动匹配 | 无法感知候选人实际临场表现 |
| 批量生成 | 支持多岗位批量处理（循环调用） | 不支持并发异步操作 |
| 输出格式 | Markdown / JSON / 纯文本 | 不支持 PDF、Word 渲染 |

**适用对象**：HR 招聘专员、技术面试官、业务部门负责人，以及需要快速搭建面试框架的用人经理。
