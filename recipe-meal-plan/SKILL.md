# 一周膳食规划 Skill 使用指南

本 Skill 协助你根据用餐人数、口味偏好和预算范围，生成一周七天（早、中、晚）的完整食谱方案，并附带对应的采购清单与热量估算。目标是为日常家庭备餐或单人伙食提供可执行的参考框架。

| 口味适配 | 支持常见口味标签：清淡、重口、辣、少油、高蛋白、素食等 |
| 预算控制 | 根据总预算（元/周）分配三餐成本，自动调整食材档次 |

## 三、标准流程

### 3.1 前置条件

在开始生成前，请确认以下信息（至少提供人数和预算）：

- [ ] 用餐人数（必填）
- [ ] 周预算范围（必填）
- [ ] 口味偏好（可选，默认家常）
- [ ] 是否需要热量统计（可选）
- [ ] 特殊忌口或偏好（可选）

> 若信息不足，Skill 会使用默认值，并在输出中标注 [需核实:字段]。

### 3.2 执行步骤

**Step 1：信息收集**

用户提供人数、预算、口味。示例输入：

```
3 人，预算 450 一周，要辣，不要猪肉
```

**Step 2：预算分配**

按早:中:晚 = 2:4:4 的比例分配每日预算（可根据口味微调）。

示例（3 人，450 元/周，日均 64 元）：
- 早餐：约 13 元
- 午餐：约 26 元
- 晚餐：约 25 元

**Step 3：生成一周菜单**

输出格式如下：

```
【第 1 天】
- 早餐：小米粥 + 水煮蛋 + 凉拌黄瓜（约 350 千卡）
- 午餐：青椒肉丝 + 米饭 + 紫菜蛋花汤（约 650 千卡）
- 晚餐：番茄炒蛋 + 清炒时蔬 + 杂粮饭（约 550 千卡）
```

**Step 4：生成采购清单**

按类别汇总：

```
【蔬菜类】青椒 500g、番茄 1kg、黄瓜 2 根、时令绿叶菜 1.5kg
【肉类】猪瘦肉 800g、鸡蛋 12 个
【主食】大米 3kg、小米 500g、杂粮米 500g
【调味料】食用油、盐、生抽、辣椒酱（按需补充）
```

**Step 5：热量统计（如需要）**

输出日均总热量范围，并标注每餐估算值。

### 3.3 输出规范

- 菜单按天编号，每天包含早、中、晚三餐
- 每餐包含：菜名 + 主食 + 汤/饮品（如有）+ 估算热量（如启用）
- 采购清单按食材类别分组，标注建议采购量
- 所有输出使用中文，菜名使用常见叫法
