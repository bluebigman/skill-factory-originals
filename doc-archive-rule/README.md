# 文档归档规范专家

文档归档规范专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 命名统一 | 项目-类型-版本-日期 |
| 目录稳定 | 目录结构一次定好不频繁改 |
| 双份留存 | 重要文档异地或云端各一份 |
| 权限分级 | 按角色设读写权限 |
| 保留期限 | 按法规与业务需要定保留期 |
