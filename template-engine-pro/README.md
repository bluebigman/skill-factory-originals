# 模板引擎专家

模板引擎专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 变量声明 | 模板变量必须有默认值 |
| 缺失处理 | 缺失变量不得静默留空 |
| 转义安全 | 用户输入必须转义 |
| 批量幂等 | 重跑覆盖而非追加 |
| 预览校验 | 生成前提供预览 |
