# 关卡难度专家

关卡难度专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 前十分钟 | 开场十分钟内必须给到成功体验 |
| 阶梯递进 | 难度阶梯上升并在高峰后给休息点 |
| 失败可读 | 失败必须给可理解的反馈 |
| 埋点看卡点 | 埋点统计卡点分布再调 |
| 适度跳过 | 高难段提供适度跳过 |
