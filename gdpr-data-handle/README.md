# 跨境数据专家

跨境数据专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 最小必要 | 只采集实现目的所必需的数据 |
| 明示同意 | 收集前明示用途并取得同意 |
| 跨境评估 | 跨境传输前做合规评估 |
| 保留期限 | 设定并到期执行删除 |
| 删除可证 | 删除请求处理须可验证 |
