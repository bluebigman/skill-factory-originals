# 地图可视化专家

地图可视化专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 分级设色 | 按数值分级而非连续插值 |
| 色盲友好 | 避免仅靠红绿区分 |
| 图例齐全 | 图例、单位与范围必须标注 |
| 投影统一 | 同一组图统一投影与范围 |
| 不误导 | 视觉面积与数值关系不得夸大 |
