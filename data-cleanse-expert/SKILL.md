# agent-resources 技能文档

## 一、能力边界速查卡

本技能用于将三类输入（URL、本地文件、原始文本）转换为结构化数据，支持批量操作与多种输出格式。

### 1.1 能做什么

| 能力项 | 说明 | 示例 |
|--------|------|------|
| URL 抓取 | 发起 HTTP GET 请求，提取网页正文 | `https://example.com/article` |
| 文件读取 | 读取本地文本文件（默认 UTF-8） | `./data/input.txt` |
| 文本解析 | 直接处理传入的文本内容 | `"第一行\n第二行"` |
| 批量处理 | 一次处理多个输入项 | 10 个 URL 列表 |
| 格式输出 | JSON / CSV / 纯文本三种序列化 | `--format json` |
| 行级清洗 | 去除空行、首尾空白、脚本样式标签 | 自动执行 |

### 1.2 不能做什么

| 限制项 | 说明 |
|--------|------|
| 不支持 POST/PUT 请求 | 仅支持 GET 方法 |
| 不执行 JavaScript | 动态渲染页面无法获取完整内容 |
| 不处理二进制文件 | 仅限文本类文件（.txt/.md/.csv/.html 等） |
| 不进行语义分析 | 仅做结构拆分，不判断内容含义 |
| 不自动重试 | 失败后需调用方根据错误码自行处理 |

### 1.3 适用对象

- 需要从网页中快速提取正文的开发者
- 需要批量清洗文本数据的运维人员
- 需要将非结构化数据转为表格形式的数据分析师

## 三、标准操作流程

### 3.1 前置条件

| 条件 | 要求 |
|------|------|
| 运行环境 | Python 3.8+ |
| 依赖库 | requests（仅 URL 抓取时需要） |
| 输入数据 | 至少提供一个 URL、文件路径或文本内容 |
| 网络权限 | 抓取 URL 时需能访问目标站点 |

### 3.2 执行步骤

#### 步骤 1：确定输入类型

根据输入数据格式选择处理通道：

| 输入类型 | 判断依据 | 处理通道 |
|----------|----------|----------|
| URL | 以 `http://` 或 `https://` 开头 | `fetch_url()` |
| 文件路径 | 以 `/`、`./`、`../` 开头或包含 `.` 后缀 | `read_file()` |
| 原始文本 | 其他情况 | `parse_text()` |

#### 步骤 2：执行数据获取

**URL 抓取流程：**

1. 发起 GET 请求，设置 `timeout=10` 秒
2. 检查响应状态码：
   - `200`：继续处理
   - `404`：返回错误码 `E404`
   - `500`：返回错误码 `E500`
   - 其他：返回错误码 `E1001`
3. 提取 `<body>` 标签内部 HTML
4. 移除所有 `<script>` 和 `<style>` 标签及其内容
5. 按段落标签（`<p>`、`<div>`、`<h1>`-`<h6>`）拆分文本

**文件读取流程：**

1. 使用 `os.path.exists()` 验证文件存在
2. 使用 `os.access()` 验证文件可读
3. 按指定编码（默认 UTF-8）读取全部内容
4. 按换行符 `\n` 拆分为行数组

**文本解析流程：**

1. 直接接收文本内容
2. 按换行符拆分为多条记录
3. 去除每行首尾空白字符

#### 步骤 3：数据清洗

对所有输入类型统一执行：

1. 去除空行和纯空白行
2. 去除每行首尾空白字符
3. 合并连续空白为单个空格

#### 步骤 4：序列化输出

根据 `--format` 参数选择输出格式：

| 格式 | 结构 | 适用场景 |
|------|------|----------|
| `json` | `{"records": [...], "skipped": [...], "confidence": 0.95}` | 程序间数据交换 |
| `csv` | 每行一条记录，逗号分隔 | Excel 导入 |
| `text` | 每行一条记录，纯文本 | 快速预览 |

#### 步骤 5：批量处理（可选）

当输入为数组时：

1. 按 `batch_size`（默认 10）分批处理
2. 每批独立执行步骤 2-4
3. 失败项记录到 `skipped` 数组，不中断整体流程

### 3.3 输出规范

**成功输出示例（JSON 格式）：**

```json
{
  "records": [
    {"index": 0, "content": "第一段有效内容"},
    {"index": 1, "content": "第二段有效内容"}
  ],
  "skipped": [3, 7],
  "confidence": 0.95,
  "total": 9,
  "processed": 7
}
```

**字段说明：**

| 字段 | 类型 | 说明 |
|------|------|------|
| `records` | Array | 处理成功的记录列表 |
| `skipped` | Array | 处理失败的索引列表 |
| `confidence` | Float | 置信度评分（0-1） |
| `total` | Integer | 输入总条数 |
| `processed` | Integer | 成功处理条数 |

## 五、错误码体系

### 5.1 错误码速查表

| 错误码 | 含义 | 提示话术 | 修正步骤 |
|--------|------|----------|----------|
| `E001` | 输入为空 | "未检测到有效输入，请提供 URL、文件路径或文本" | 检查输入参数 |
| `E1001` | HTTP 请求失败 | "网络请求异常，请检查网络连接或目标地址" | 确认 URL 可访问，稍后重试 |
| `E404` | 资源不存在 | "目标资源不存在（404）" | 检查 URL 拼写，确认资源是否已移除 |
| `E500` | 服务器错误 | "目标服务器返回 500 错误" | 稍后重试，或联系目标站点管理员 |
| `E2001` | 文件不存在 | "指定的文件路径不存在" | 使用 `os.path.exists()` 检查路径 |
| `E2002` | 文件不可读 | "文件存在但无法读取，请检查权限" | 使用 `os.access()` 检查读权限 |
| `E2003` | 编码错误 | "文件编码无法识别，请指定编码格式" | 使用 `--encoding` 参数指定编码 |
| `E3001` | 输出格式错误 | "不支持的输出格式，可选：json/csv/text" | 检查 `--format` 参数 |
| `E9001` | 内部错误 | "发生未预期错误，请查看日志" | 收集错误信息，反馈给开发者 |

### 5.2 错误处理流程

```
遇到错误
  ↓
记录错误码和上下文信息
  ↓
根据错误码查表
  ↓
执行修正步骤
  ↓
重试（最多 2 次）
  ↓
仍失败 → 记录到 skipped 数组
```

## 六、FAQ 与反模式对照

### 6.1 常见问题

**Q1：抓取的网页内容不完整？**

可能原因：目标页面使用 JavaScript 动态渲染内容。

解决方案：
- 确认页面是否为静态 HTML
- 检查是否被访问限制机制拦截
- 考虑使用无头浏览器方案（超出本技能范围）

**Q2：CSV 输出中内容包含逗号导致列错位？**

解决方案：
- 使用 JSON 格式替代
- 在内容字段外层加引号转义

**Q3：批量处理时部分 URL 超时？**

解决方案：
- 增加 `batch_size` 值减少并发压力
- 对超时 URL 单独重试
- 检查目标站点是否有访问频率限制

**Q4：文件读取乱码？**

解决方案：
- 确认文件实际编码
- 使用 `--encoding gbk` 或 `--encoding utf-8-sig` 指定

**Q5：输出结果中混入导航栏/页脚内容？**

解决方案：
- 使用更精确的 CSS 选择器（需扩展技能）
- 在输出后结合业务规则二次清洗

### 6.2 反模式对照表

| 反模式 | 问题 | 推荐做法 |
|--------|------|----------|
| 忽略 `skipped` 数组 | 数据缺失不自知 | 每次处理完检查 `skipped` 长度 |
| 不设超时时间 | 请求挂起导致流程卡死 | 始终设置 `timeout=10` |
| 盲目重试所有错误 | 对 404 重试无意义 | 仅对 `E1001` 和 `E500` 重试 |
| 直接拼接 HTML 字符串 | 标签未清理干净 | 先移除 `<script>`/`<style>` 再拆分 |
| 假设所有文件都是 UTF-8 | 中文文件常为 GBK | 先检测编码或显式指定 |

## 使用（Usage）

```bash
python run.py <命令> [参数]    # 执行核心功能
python run.py --selftest      # 运行自检
python run.py --dry-run       # 预览模式
python run.py --verbose       # 详细输出
```

## 常见问题（FAQ）

**Q: 支持中文文件吗？**
A: 支持，内置 utf-8/gbk/gb18030 多编码容错。

**Q: 运行报错怎么办？**
A: 工具内置异常降级，错误会有明确提示；可先用 --dry-run 预览。

**Q: 如何确认功能正常？**
A: 运行 --selftest，全部通过即核心功能正常。
