## 一、能力边界速查卡

### 1.1 能力清单

| 维度 | 说明 |
|------|------|
| **核心能力** | 将 HTML 网页、JSON/CSV 数据文件转换为字段规整的结构化记录 |
| **输入要求** | 文件需放置于当前工作目录，文件名遵循统一前缀（如 `input_*.html`） |
| **输出格式** | Markdown 表格 + JSON 行（每行一条记录），附采集日志 |
| **失败处理** | 单条失败不中断整体流程，生成 `failed_items.json` 记录原因 |

### 1.2 边界声明

**能做：**
- 标准 HTML 表格、列表、JSON 数组的字段提取
- 批量文件顺序处理（建议单批 ≤ 500 个文件）
- 字段类型校验（字符串/数字/日期）
- 输出文件自动命名（`output_YYYYMMDD_HHMMSS.json`）

**不能做：**
- 无法处理需要登录态或验证码的页面
- 不执行 JavaScript 渲染后的动态内容抓取
- 不进行数据去重或语义清洗（仅做格式转换）
- 不保证源数据本身的准确性

**适用对象：**
- 静态网页中的表格/列表数据
- 导出的 JSON/CSV 数据文件
- 需要批量格式化的结构化文本
