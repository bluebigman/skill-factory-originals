# 决策追溯专家

决策追溯专家：内置 5 项专业能力。

## 能力清单

| 情境 | 建议动作 |
|---|---|
| 决策记录 | 每个决策点记录候选与理由 |
| 否决留痕 | 被否方案也要记录原因 |
| 版本绑定 | 决策须绑定当时的输入版本 |
| 复盘可查 | 事后能还原决策现场 |
| 责任可归 | 能回答谁在何时基于什么做的决定 |
