# 任务激励专家

## 能力清单

| 情境 | 建议动作 |

| 进度可见 | 目标与进度始终可见 |
| 即时反馈 | 行为后即时给正反馈 |

| 防疲劳 | 设每日上限防刷取疲劳 |
