# 智能出题 Skill 使用指南

本 Skill 面向教师、教研员、培训讲师及自学者，提供按知识点、难度、题型批量生成试题的能力。所有生成内容均附带答案、解析与置信度标识，便于人工复核后投入使用。

## 一、能力边界（一页纸速查卡）

### 本 Skill 能做什么

| 能力项 | 说明 |
|--------|------|
| 知识点出题 | 输入知识点名称（如"一元二次方程"），生成对应试题 |
| 难度控制 | 支持 `easy` / `medium` / `hard` 三档难度 |
| 题型覆盖 | 选择题（单选/多选）、填空题、简答题 |
| 批量生成 | 一次请求可生成多题，支持多知识点混合 |
| 答案解析 | 每题附带答案、解析、易错点提示 |
| 置信度标识 | 每题标注 `high` / `medium` / `low` 置信度 |

### 本 Skill 不能做什么

| 限制项 | 说明 |
|--------|------|
| 不保证绝对正确 | 所有题目需人工复核，尤其 `medium` / `low` 置信度题目 |
| 不提供教学承诺 | 不保证使用后成绩提升或教学效果达标 |
| 不生成超纲内容 | 仅基于输入知识点出题，不自行扩展知识范围 |
| 不替代教材 | 生成内容为练习材料，不构成完整教学方案 |
| 不支持图片/公式渲染 | 输出为纯文本 Markdown，复杂公式需自行排版 |

## 三、标准流程

### 前置条件

1. 明确知识点名称（必填）
2. 明确题量（必填）
3. 明确难度（选填，默认 `medium`）
4. 明确题型（选填，默认混合题型）
5. 明确特殊要求（选填，如生活场景、干扰项、易错点）

### 执行步骤

**第一步：提交请求**

将需求按以下格式描述：

```
出 [题量] 道 [题型] 题，知识点：[知识点名称]，难度：[easy/medium/hard]
附加要求：[可选，如"结合生活场景""包含干扰项""解析含易错点"]
```

示例：

```
出 15 道选择题，知识点：勾股定理，难度：medium
附加要求：结合建筑场景，选项需包含 2 个干扰项
```

**第二步：接收输出**

输出结构如下：

```
## 试题清单

### 元信息
- 知识点：勾股定理
- 题量：15
- 难度：medium
- 题型：选择题

### 题目 1
**题干**：...
**选项**：
A. ...
B. ...
C. ...
D. ...
**答案**：B
**解析**：...
**置信度**：high
```

**第三步：人工复核**

- 检查 `confidence` 字段
- `high`：可直接使用，建议抽查
- `medium`：需人工核对答案与解析
- `low`：建议重新生成或大幅修改

**第四步：二次编辑（可选）**

对生成结果进行修改：

- 调整题目表述
- 修改难度
- 补充或修正解析
- 增加或删除选项

### 输出规范

| 必含项 | 说明 |
|--------|------|
| 标题 | 试题清单 |
| 元信息 | 难度、题量、题型 |
| 题干 | 每道题的完整表述 |
| 选项 | 选择题必含，至少 4 个选项 |
| 答案 | 明确标注正确选项或答案内容 |
| 解析 | 解题思路、步骤、易错点 |
| 置信度 | `high` / `medium` / `low` |

| 禁止项 | 说明 |
|--------|------|
| 绝对化表述 | 如"一定正确""绝对无误""100% 准确" |
| 收益承诺 | 如"保证提分""确保掌握" |
| 无关闲聊 | 与出题无关的内容 |

## 四、置信度门控

### 置信度判定标准

| 置信度 | 判定条件 | 使用建议 |
|--------|----------|----------|
| `high` | 知识点明确、答案唯一、解析逻辑清晰 | 可直接使用 |
| `medium` | 存在多种解法、或答案有争议可能 | 需人工核对 |
| `low` | 知识点模糊、或答案不确定 | 建议重新生成 |

### 信息不足时的处理

当输入信息不足以生成可靠题目时，输出中会以 `[需核实:字段]` 占位，不编造内容。

示例：

```
**题干**：已知 [需核实:具体数值] ，求 [需核实:求解目标] 。
```

此时请补充缺失信息后重新请求。

## 六、FAQ 反模式

### 常见坑 1：知识点过于宽泛

**错误示范**："出 10 道数学题"

**问题**：知识点不明确，生成结果可能偏离预期。

**正确做法**："出 10 道一元二次方程求根的选择题，难度 medium"

### 常见坑 2：忽略置信度检查

**错误示范**：直接使用所有生成题目，不检查 `confidence` 字段。

**问题**：`medium` / `low` 题目可能存在错误。

**正确做法**：对非 `high` 置信度题目进行人工复核。

### 常见坑 3：要求绝对正确

**错误示范**："请确保所有题目 100% 正确"

**问题**：本 Skill 不提供绝对正确保证，且此类表述违反输出规范。

**正确做法**："请标注每道题的置信度，我会人工复核"

### 常见坑 4：超纲出题

**错误示范**："出 10 道量子力学的题"（但实际教学范围是初中物理）

**问题**：生成内容与教学进度不匹配。

**正确做法**：明确限定知识点范围，如"出 10 道初中物理力学基础题"

### 常见坑 5：忽略二次编辑

**错误示范**：生成后直接用于考试，不做任何修改。

**问题**：题目可能不完全符合教学风格或考试要求。

**正确做法**：对生成结果进行二次编辑，调整表述、难度和解析。
