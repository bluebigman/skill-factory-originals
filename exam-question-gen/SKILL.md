## 一、能力边界与适用对象

### 1.1 本 Skill 能做什么

| 能力项 | 说明 | 示例 |
|--------|------|------|
| 按知识点出题 | 接收知识点名称列表，为每个知识点生成题目 | `知识点：一元二次方程、函数图像` |
| 按难度出题 | 支持 简单 / 中等 / 困难 三档，可指定比例 | `难度：3:5:2`（简单:中等:困难） |

| 难度系数与区分度 | 每题自动标注预计难度系数（0~1）与区分度（0~1） | `难度系数：0.65` |

### 1.2 本 Skill 不能做什么

| 限制项 | 说明 |
|--------|------|
| 不做主观题评分 | 简答题仅提供参考答案与采分点，不提供自动评分 |
| 不保证题目原创性 | 题目为模板化生成，可能与其他题库存在相似 |
| 不支持非文本内容 | 无法生成图片题、音频题、实验操作题 |
| 不处理超纲内容 | 仅基于输入的知识点名称生成，不自动扩展知识边界 |
| 不提供教学建议 | 仅出题与解析，不包含教学策略建议 |

## 三、标准流程

### 3.1 前置条件

| 条件 | 要求 | 默认值 |
|------|------|--------|
| 知识点 | 至少 1 个，最多 10 个 | 无（必填） |
| 题型 | 至少 1 种，最多 5 种 | 默认：单选+填空 |
| 数量 | 每题型至少 1 道，最多 50 道 | 默认：每题型 3 道 |
| 难度 | 简单/中等/困难 三档，或比例（如 3:5:2） | 默认：中等 |
| 输出格式 | json / markdown / text / csv | 默认：markdown |

### 3.2 执行步骤（分步编号）

#### 步骤 1：解析输入

读取用户输入，提取 5 个关键字段：

| 字段 | 解析规则 | 示例 |
|------|----------|------|
| `knowledge_points` | 按顿号、逗号、分号分割 | `勾股定理, 二次函数` |
| `question_types` | 映射为枚举值：`single` / `multiple` / `fill` / `short` / `judge` | `单选+多选` → `["single","multiple"]` |
| `counts` | 按题型指定数量，或统一数量 | `每题型 5 道` → `{"single":5,"multiple":5}` |
| `difficulty` | 单值或比例 | `中等` 或 `3:5:2` |
| `output_format` | 枚举：`json` / `markdown` / `text` / `csv` | `json` |

#### 步骤 2：题目生成

按以下顺序生成题目：

1. 遍历知识点列表
2. 对每个知识点，遍历题型
3. 对每个题型，按数量与难度生成题目
4. 每道题生成时，附带以下元数据：
   - `difficulty_coefficient`：0~1 之间的浮点数（简单≈0.2~0.4，中等≈0.5~0.7，困难≈0.8~0.95）
   - `discrimination_index`：0~1 之间的浮点数（建议值，简单题≈0.3，中难题≈0.6~0.8）
   - `knowledge_tag`：对应知识点名称

#### 步骤 3：结果校验

生成后检查：

- 每个知识点是否都有题目
- 题型数量是否满足要求
- 难度比例是否与输入匹配（允许 ±10% 浮动）
- 每道题是否包含答案与解析

#### 步骤 4：输出

按指定格式整理输出，并在末尾附置信度说明。

### 3.3 输出规范

| 格式 | 结构说明 |
|------|----------|
| JSON | 数组对象，每个对象含 `id`、`type`、`knowledge`、`difficulty`、`question`、`options`（选择题）、`answer`、`explanation`、`difficulty_coefficient`、`discrimination_index` |
| Markdown | 按知识点分节，节内按题型分组，每题后附答案与解析 |
| 纯文本 | 每题连续输出，题目与答案用空行分隔 |
| CSV | 每行一题，列为：`题型,知识点,难度,题目,选项A,选项B,选项C,选项D,答案,解析,难度系数,区分度` |
