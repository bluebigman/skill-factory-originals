## 三、标准流程

### 前置条件

在发起请求前，请确认以下信息（缺失项将使用默认值）：

| 参数 | 必填 | 默认值 | 可选值 |
|------|------|--------|--------|
| 知识点 | ✅ | 无 | 任意字符串，多个用顿号/逗号分隔 |
| 题型 | ❌ | 单选+填空+简答 | 单选 / 多选 / 填空 / 简答 / 判断 / 全部 |
| 题量 | ❌ | 每题型 5 道 | 1~50 |
| 难度 | ❌ | 中等 | 简单 / 中等 / 困难 / 比例（如 3:5:2） |
| 输出格式 | ❌ | Markdown | JSON / Markdown / 纯文本 / Excel |
| 是否含解析 | ❌ | 含 | 含 / 不含 |

### 执行步骤

**第 1 步：解析输入**

从用户输入中提取以下字段：

```
知识点：逗号/顿号分隔的列表
题型：识别关键词（单选/多选/填空/简答/判断）
题量：识别数字或“每题型X道”
难度：识别“简单/中等/困难”或数字比例
格式：识别“JSON/Markdown/纯文本/Excel”
```

**第 2 步：构建出题参数**

将解析结果整理为结构化参数：

```json
{
  "knowledge_points": ["勾股定理", "二次函数"],
  "question_types": ["single_choice", "fill_blank"],
  "count_per_type": 5,
  "difficulty_ratio": {"easy": 3, "medium": 5, "hard": 2},
  "output_format": "markdown",
  "include_analysis": true
}
```

**第 3 步：生成题目**

按以下规则逐题生成：

1. 根据知识点匹配题目模板库
2. 按难度系数调整题目复杂度（简单=基础概念，中等=综合应用，困难=跨知识点/高推理）
3. 每道题生成后计算：
   - **难度系数**：0.1~0.9（0.1 最简单）
   - **区分度**：0.1~0.8（越高越能区分学生水平）
4. 生成参考答案与解析

**第 4 步：汇总输出**

按指定格式整理结果，并输出：

- 题目列表（含题号、题干、选项/空位、答案、解析、知识点标签、难度系数、区分度）
- 试卷结构建议（如适用）

## 四、置信度门控

当输入信息不完整或存在歧义时，系统**不会编造**内容，而是按以下规则处理：

| 情况 | 处理方式 |
|------|---------|
| 未指定知识点 | 输出提示：[需核实:knowledge_points] 请提供至少一个知识点 |
| 未指定题量 | 输出提示：[需核实:count] 将使用默认值 5 道/题型 |
| 题型识别不确定 | 输出提示：[需核实:question_types] 默认使用 单选+填空+简答 |
| 难度比例不明确 | 输出提示：[需核实:difficulty] 默认使用 中等 |

**规则**：任何含 `[需核实:...]` 的输出都不会被视为正式结果，需用户确认后重新生成。
