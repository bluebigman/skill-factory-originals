# 智能组卷 · 题目生成与难度调控 Skill

## 一、能力边界：一页纸速查卡

本 Skill 用于**按需生成结构化的练习题与试卷**。它不阅读教材，不解析图片，也不管理题库数据。它的核心能力是：根据你给出的知识点、题型、难度和数量，产出包含参考答案与解析的题目文本，并提供试卷结构建议。

| 能做 | 不能做 |
|------|--------|
| 根据知识点名称匹配预设的题目模板 | 从外部文件（PDF/Word）提取题目 |
| 按难度等级（简单/中等/困难）调整题目的综合度与推理深度 | 自动评估题目实际难度（需人工复核） |
| 为每道题生成参考答案与解析 | 保证题目完全原创或通过版权审查 |
| 提供混合难度比例的组卷建议（如 3:5:2） | 直接接入 LMS 或在线考试系统（需导出后导入） |
| 输出 JSON 格式，便于程序化处理 | 执行复杂的教育测量学分析（如 IRT 模型） |
| 通过错误码定位输入问题 | 生成包含图表、公式图片的富媒体题目（仅文本） |

**适用对象**：一线教师、教研员、在线教育内容运营、学习系统开发者，以及需要快速生成练习材料的个人学习者。

## 三、标准工作流程

### 前置条件

1. **明确知识点**：至少提供一个具体的知识点名称（如“光合作用”“勾股定理”）。若未提供，将默认使用通用基础知识点。
2. **（可选）指定题型**：如选择题、填空题、解答题、判断题。若不指定，根据知识点自动匹配最合适的模板。
3. **（可选）指定难度与数量**：若不指定难度，默认产出简单:中等:困难 = 3:5:2 的比例。若不指定数量，默认产出 5 道题。

### 执行步骤（分步编号）

**步骤 1 — 解析输入参数**  
从你的指令中提取四个关键参数：`知识点`、`题型`、`难度`、`数量`。  
示例：指令“生成 3 道关于‘二次函数顶点式’的中等难度选择题” → 参数提取为：`知识点=二次函数顶点式`，`题型=选择题`，`难度=中等`，`数量=3`。

**步骤 2 — 匹配题目模板**  
根据知识点和题型，从内置模板库中选择适用的模板。模板库包含以下基础题型：
- 概念辨析题（适用于简单难度）
- 计算/应用题（适用于中等难度）
- 综合推理题/跨知识点题（适用于困难难度）

**步骤 3 — 调整题目复杂度**  
根据难度系数对模板进行参数化调整：
- **简单**：直接考察定义、公式、单一概念。题干短，选项/答案直接。
- **中等**：需要两步以上推理，或结合 2 个知识点。
- **困难**：需要多步推理、跨章节知识迁移，或包含隐含条件。

**步骤 4 — 生成题目内容**  
按选定模板与参数生成题干。若为选择题，同时生成 4 个选项（含一个正确项）。确保题干无歧义。

**步骤 5 — 计算题目属性**  
为每道题生成后自动计算并附加：
- **预估难度**（简单/中等/困难）
- **预估区分度**（高/中/低，基于知识点覆盖范围与推理链长度）
- **预估用时**（分钟，基于题型与难度）

**步骤 6 — 生成参考答案与解析**  
提供答案及简要解析。解析需说明解题关键步骤或依据的知识点，字数控制在 50-150 字。

**步骤 7 — 按指定格式输出**  
默认输出 Markdown 列表。若要求 JSON 格式，则按以下结构输出：

```json
{
  "exam_paper": {
    "knowledge_point": "二次函数顶点式",
    "total_questions": 3,
    "difficulty_distribution": {"easy": 0, "medium": 3, "hard": 0},
    "questions": [
      {
        "id": 1,
        "type": "multiple_choice",
        "difficulty": "medium",
        "estimated_time_min": 3,
        "discrimination_index": "high",
        "stem": "已知二次函数 y = 2(x-3)^2 + 1，求其顶点坐标。",
        "options": ["A. (3, 1)", "B. (-3, 1)", "C. (3, -1)", "D. (-3, -1)"],
        "correct_answer": "A",
        "explanation": "顶点式 y = a(x-h)^2 + k 中，顶点为 (h, k)。此处 h=3, k=1。"
      }
    ]
  }
}
```

### 输出规范

- **默认格式**：Markdown 表格或列表，包含题号、题型、难度、题干、选项（如有）、答案、解析、预估用时。
- **可选格式**：JSON（如上所示）、纯文本列表。
- **试卷结构建议**：当请求组卷时，额外输出一个“结构建议”段落，展示各难度题目的推荐数量与分值占比。

## 七、渐进式披露：分层次阅读路径

### 速查卡（新手起步，30 秒上手）

1. 直接说：`出 3 道题，知识点是“自由落体运动”，中等难度。`
2. 得到 Markdown 格式题目列表。
3. 若想调整，加参数：`改成 5 道，题型用选择题，难度是简单和中等各一半。`

### 进阶使用路径（熟练用户）

1. **批量生成**：`生成 15 道题，知识点[“功”,“功率”]，题型[选择, 解答]，难度比例 3:5:2`。
2. **程序化处理**：`以 JSON 格式输出上述题目`。
3. **组卷建议**：在指令末尾追加 `并给出试卷结构建议`，将获得各难度题目的推荐分值与时间分配。
4. **自定义输出**：如需特定字段，明确列出，如 `输出 JSON，字段仅包含 id, stem, correct_answer`。
5. **排查问题**：若输出异常，查看返回的错误码（如 `E1003`），根据修正步骤调整输入。
