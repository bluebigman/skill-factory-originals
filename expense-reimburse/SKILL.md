## 三、标准流程

### 3.1 前置条件

| 条件项 | 要求 |
|--------|------|
| 输入形式 | 图片（JPG/PNG/PDF）或纯文本金额清单 |
| 图片质量 | 分辨率 ≥ 800px，票据文字清晰可辨 |
| 数量限制 | 单次 ≤ 20 张，超出需分批处理 |
| 数据安全 | 确保票据不包含敏感个人信息（如身份证号） |

### 3.2 执行步骤

**步骤 1：输入确认**

- 用户上传票据照片或粘贴金额清单
- 系统确认接收数量与格式

**步骤 2：自动识别**

- 提取每张票据的关键字段：金额、日期、商户名称、发票代码、发票号码、税号
- 识别过程基于光学字符识别（OCR）技术

**步骤 3：自动归类**

- 根据商户名称和票据类型，将费用归入以下类别之一：

| 类别代码 | 费用类型 | 示例 |
|----------|----------|------|
| TRV | 交通费 | 出租车、地铁、高铁票 |
| FOD | 餐饮费 | 餐厅、外卖 |
| HOT | 住宿费 | 酒店、民宿 |
| OFF | 办公用品 | 文具、打印 |
| COM | 通讯费 | 话费、网费 |
| MED | 医疗费 | 药品、诊疗 |
| EDU | 教育费 | 培训、书籍 |
| OTH | 其他 | 无法归类的费用 |

**步骤 4：置信度标注**

- 每个字段标注置信度等级：
  - **高**：识别结果与原始票据一致性 ≥ 95%
  - **中**：识别结果与原始票据一致性 80%-94%
  - **低**：识别结果与原始票据一致性 < 80%

**步骤 5：真伪初查**

- 校验发票代码格式（如 12 位数字）、发票号码位数（8 位）
- 校验金额合理性（非零、非负数）
- 校验日期合法性（非未来日期、非异常年份）

**步骤 6：输出结果**

- 默认输出 Markdown 表格
- 用户可指定 CSV 或 JSON 格式
