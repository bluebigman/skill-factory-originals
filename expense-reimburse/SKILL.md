**Step 2：解析输入内容**

- 识别关键信息字段：日期、金额、商家、发票号码、费用类别

- 提取过程中记录每个字段的置信度

**Step 3：按规则处理**

- 字段完整性检查：检查是否所有关键字段均已提取

### 用户常见疑问

**Q1：如何处理手写发票？**
A：手写发票识别率较低，建议优先使用打印发票。若必须处理手写发票，请确保字迹清晰，且最终结果中低置信度字段会标注 [需核实]。

**Q2：费用类别如何自动归类？**
A：根据商家名称和消费内容进行关键词匹配。例如：餐饮类商家 → 餐饮；打车平台 → 交通；文具店 → 办公用品。无法匹配时标注 [需核实:费用类别]。

**Q3：能否处理电子发票 PDF 文件？**
A：可以。PDF 文件需为文字版（非扫描件），系统会自动提取文本信息。扫描版 PDF 请先转换为图片格式。

**Q4：输出结果如何导出？**
A：默认输出 Markdown 表格，可指定切换为 CSV 或 JSON 格式。CSV 可直接用 Excel 打开，JSON 适合程序化处理。
